# 掌眼 · Zhangyan

**《掌眼》是一款围绕不完整证据展开、通过渐进理解推进的长线古董鉴定推理游戏。**

玩家旋转器物、选择调查，在逐渐显露的知识地图上梳理已有信息与关联，再决定何时收手。当前 V3 是支持中英文的桌面浏览器原型，围绕一件虚构瓷碗展开调查。

## 如何试玩

下载[单文件游戏](docs/project/evidence/v3-design/validation/workbench-hifi-v0/prototype.html?raw=1)，用电脑 Edge 或 Chrome 打开。GitHub 中的 HTML 文件页用于看代码，不能代替已经托管的试玩网址。

1. 拖动碗自由旋转，朝向玩家的部位会显示调查入口；滚轮缩放器物。
2. 选择部位或器物之外的方法。打开入口和阅读免费，执行具体调查才消耗一次机会；已经做过的同一次调查可免费回看。
3. 新信息飞入地图，镜头拉近落点，再拉远显示它与已有信息如何相接。
4. 点击信息、道路或判断回查依据；拖动、缩放地图查看其他位置。Escape可关闭浮层或取消选择。
5. 由玩家点击“收手，作出判断”。四项判断成立不等于所有问题都被调查。

右上角“中 / EN”切换界面语言。当前版本面向电脑浏览器。

## 玩法与设计

一份材料可以先到手，后来才显出它的意义。器物的历史固定，玩家对它的理解则随着调查逐步展开：旧照片是否对应眼前这只碗，档案记载能否得到实物印证，不会因为拿到材料就自动成为答案。

知识地图帮助玩家在长线推理中记住已有信息、回查依据，并看清一次调查接通了哪些关联。不同调查顺序不改变地图骨架；从已知内容延伸出的道路留下疑问，让玩家自行选择继续探索的方向，也可以带着尚未解决的问题收手。

## 当前内容

已实现：一件虚构外销瓷碗、22个调查手段、可旋转器物、材料回查、渐进知识地图、四项判断、历史和手动收手。估值、市场结算和完整来客系统属于未接回的历史／后续设想。
