# 掌眼 · 当前作品说明

《掌眼》是一款围绕不完整证据展开的古董鉴定游戏。玩家旋转器物、选择调查、沿逐渐显露的知识地图回查依据，再决定何时收手。

2026年9月14日，作者决定开发到此为止，后续转入作品集呈现。保留的游戏检查点为 `3fe5704`，离线页 SHA-256 前缀为 `4d6362a8`。这是作者确定的作品收尾点，不将此前的机器检查改写成普遍玩家体验已通过。

## 如何试玩

下载[单文件游戏](docs/project/evidence/v3-design/validation/workbench-hifi-v0/prototype.html?raw=1)，用电脑 Edge 或 Chrome 打开。GitHub 中的 HTML 文件页用于看代码，不能代替已经托管的试玩网址。

1. 拖动碗自由旋转，朝向玩家的部位会显示调查入口；滚轮缩放器物。
2. 选择部位或器物之外的方法。打开入口和阅读免费，执行具体调查才消耗一次机会；已经做过的同一次调查可免费回看。
3. 新信息飞入地图，镜头拉近落点，再拉远显示它与已有信息如何相接。
4. 点击信息、道路或判断回查依据；拖动、缩放地图查看其他位置。Escape可关闭浮层或取消选择。
5. 由玩家点击“收手，作出判断”。四项判断成立不等于所有问题都被调查。

右上角“中 / EN”切换界面语言。当前版本只做电脑尺寸；没有公开试玩地址。

## 这件作品展示什么

核心是长期推理的信息组织：作者真相固定，玩家知识逐步显露；取得证据和解释证据分开；不同调查顺序不改变地图骨架。道路帮助玩家理解新调查接通了哪里，同时保留自行选择调查和停手的空间。

已实现：一件虚构外销瓷碗、22个调查手段、可旋转器物、材料回查、渐进知识地图、四项判断、历史和手动收手。估值、市场结算和完整来客系统属于未接回的历史／后续设想。

本项目由作者在实习中独立主导游戏设计、交互方向与迭代判断，使用AI辅助编程和视觉探索。器物绘画贴图由GPT Image生成，案例中的历史影像、结构图和检测材料均为合成游戏材料，来源见[资产说明](docs/project/evidence/v3-design/validation/workbench-hifi-v0/src/assets/README.md)。

源码、实验与失败记录原地保留。公开作品集只需精选能说明设计决策的素材；[技术验证报告](docs/project/evidence/v3-design/validation/workbench-hifi-v0/VERIFICATION-NODE-LABELS-2026-09-13.md)保留各项检查的实际范围。
