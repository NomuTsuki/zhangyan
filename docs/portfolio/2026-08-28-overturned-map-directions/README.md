# 2026-08-28 · 三个被推翻的地图方向

候选跨页槽位:**process**(过程)。

叙事价值:重建玩家侧结构之前,先有三个方向被否掉,每一个都有**具体的、写下来的**否决理由。"带理由的失败"比最终成品更能说明设计判断——这一组的作用是证明最后那个结构不是第一个想法,而是第四个。

三个方向的否决理由各不相同,而且都不是"不好看":

1. **全部摆在器物轮廓上**(本目录截图)——它把**行动面与认知面合并**了。已得情报不该长在器物上;而且"承力路径""必要重大范围"这类跨部位的判断范围被摆成碗上一个点,会误导玩家以为自己查的是那一小块。截图中央标签互相重叠,是这个方向的另一项代价,肉眼可见。
2. **自上而下生长的依赖图**——有一个根节点让所有东西往下长,流向被固定成单向,与"地图没有起点、玩家可落在任意地标、路是双向的"直接冲突。仅"意义未定观察被后来的汇合接住"这个画法保留。
3. **心智地图与推理视图并列两张**——问错了问题。最终结构是**一张图加一个决策面**:图只增不减、装成果;决策面大小有界、只装当前需要判断的四类,已定案的子结构坍缩成公理离场。
