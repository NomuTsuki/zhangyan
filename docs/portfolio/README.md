## Proposed editorial focus

**A map that records what you know—and what still needs a connection.**

The strongest story is the relationship between the author's intent, the player's action and the map's response. Show an acquired observation, the question it leaves, and the later verification that connects it. Explain why spatial positions stay fixed even when discovery order differs.

For an iteration example, choose the shift from confusing dependency displays to stable roads with visible continuity. The latest small fixes can support that story, but individual icon and colour corrections need not become separate portfolio chapters.

## Provenance and restraint

All selected gameplay captures are from running HTML prototypes; each dated README records the build and capture conditions. The bowl texture and early visual studies use generated artwork. Include a compact authorship/tool note alongside the case.

Weekly reports, tool transcripts, long validation tables and the entire sequence of low-fidelity iterations remain available for provenance. Bring an item into the portfolio only when it explains a consequential decision. The author's decision to stop development is recorded separately from any claim about independent usability testing.
