# Project Compass

> 保存 V3 相对稳定的方向性判断。它是当前最优参考，不是不可质疑的命令。

最后复查：2026-08-22（文字／面板主导原型已按用户要求删除；当前先审清 Git 检查点与 UI／UX Skill 安装／退出边界）

## 项目目的

把《掌眼》收敛成一款首先能够完整交付“识物”体验的手机竖屏游戏：玩家面对一件具有固定客观真相和细分价值的器物，通过有成本的调查逐步形成、修正并检验判断，最后决定继续调查还是带着剩余不确定性收手，并为自己的一次挂牌选择承担独立市场结果。

V3 从 V2 的可运行、可回放底座继续，但不把 V2 平铺线索直接包装成拓扑，也不因为启动新版本就假装玩法已经完成。

## 目标用户或受众

- 近期直接验收者：项目作者、指导老师和后续无答案测试玩家；
- 作品集受众：需要看见完整成果、设计因果、实现能力和验证证据的评审者；
- 长期玩家画像仍需真人测试，不把“老师／评审能理解”冒充一般玩家成立。

## 核心价值或体验

玩家面前不是一道等钥匙的填空题，而是一个**可争辩的问题**。客观真相从开局固定；玩家在自然语言和轻量系统辅助下理解“我看见了什么、这些意味着什么、现在还可以验证什么”，并为相信什么、花多少代价和何时停手承担后果。

古董既要定性，也要定量：真／假／重修等身份与更细的状态、品质、客观价值共同构成真相。玩家不需要手算贝叶斯公式，但系统必须能解释判断为什么变化。

收手后，系统冻结它只凭本局证据能够负责的判断与估值；玩家自行报一次一口价；市场再按客观真相和固定渠道独立结算。系统估值、玩家挂牌价和市场结果三者不能互相改写。

## 成功标准

- 第一器物切片能从高度不确定走到足以做出有后果判断的完整一局，而不是只演示一张图；器物类别服从证据拓扑承载力，不预设漆器；
- 作者真相模型、作者证明图、玩家知识图、概率／行动层分账清楚，回放可复现；
- 存在替代路径或恢复路径，核心理解不会因一次随机失败永久消失；
- 玩家侧图能帮助记忆、理解关系和规划方向，但不泄露隐藏答案轮廓或唯一最优动作；
- 调查顺序有优劣但非最优合理路线仍可完成；后期继续调查与收手形成真实成本／风险张力；
- 第一陶瓷切片的开放证据网能够汇合成三档清楚结果：结果门只约束系统何时能负责地形成结论，不锁定调查顺序；结果 2 已是一局平庸但完整的胜利，结果 2—3 之间持续形成局部成果；
- 阶段主张是可停手的阶段成果而非自动终点；阶段未升级时，新增证据仍能改变同阶段价值或打开替代价值情景；
- 停手、系统估值、玩家一次挂牌和客观市场结算形成完整闭环，赚钱不自动证明推理正确；
- 首案由作者手工决定真相、证据语义、替代／恢复、停手张力与揭示顺序；自动化只分别验证结构可达、概率／价值不变量、种子回放、明显支配策略和界面边界，无答案玩家另行验证理解与趣味；
- 首案深挖同时存在正向、负向和只改变问题方向的发现；现实可信负责约束观察与因果，多个可信器物设定之间以玩家选择、停手张力和可解释价值分叉决定取舍；
- 最终作品集以完成成果为主，过程转折只保留一个轻量节点并与成果证据配对。

## 不可牺牲原则

- 客观真相不随玩家倾向、报价、UI 或角色认知改变；沿图移动的是证据、理解与选择；
- 原始事实、鉴定主张、候选真相、玩家信念和经济结果不能合成同一种节点；
- 关键线索不由单次随机失败永久删除；首切片的高成本行动可以改变调查机会、检测费用、精度或效率，但不改变器物品相；
- 玩家辅助负责降低记忆与表达负担，不替玩家自动选择答案或唯一下一步；
- 证据、自动规则、真人体验、平衡、文化准确性和视觉完成分别举证；
- 不把考据量当作游戏深度：无玩法作用的器物个性由作者直接决定或降为氛围，只有会改变玩家推理体验、难度、取舍、主题或核心边界的分叉才交还用户；
- V1、V2 冻结节点不移动、不覆盖；V3 设计材料必须区分 Draft、Approved、Implemented 与 Verified。

## 硬约束

- 标准 Web、2D、手机竖屏、普通响应式 H5 路线保持；
- V3 首次提交只含治理、设计文档与原始证据，不改产品代码；
- 内部目标候选为尽量在 `2026-08-26` 前形成完整识物版本、在 `2026-10-20` 前完成作品集文书；两者尚未形成经过资源估算的外部硬承诺；
- V3 只处理物品真相、玩家侧理解与既定经济终局；V2 的 NPC 认知、画像、关系状态、连续对话、D20、议价和人物评分不进入 V3；
- 第一器物采用 Hong Bowl 多阶段修复史的**虚构外销瓷大碗类比结构**，核心争议为“18 世纪末中国外销瓷基本成立，但重组／补绘程度与价值仍不清楚”；DEC-021 已固定“同器原片、多阶段修复、正负向深挖”的作者真相包，现实馆藏只作来源／素材锚点；DEC-022 已确认第一切片采用“开放证据网＋三档结论门”，门禁不锁行动。v0.2 的 12 个核心对象候选与三档骨架继续有效；限定领域复核后形成的 v0.3 把档案改为记录彼此、记录—现器、事件—物证三个持续更新的关系问题，以 G2 作为深档案注意力软转折，并收窄 X 射线、表面、材料／层序和静态陈列能力。首轮独立复核发现五个关系槽缺少争议投影和三阶段时间冲突探针，负责人补齐六槽“争议优先”与时间冲突回退后为 `40/40`；同一只读复核者独立重算六文件／六来源哈希、重跑 `40/40` 并重放冲突换序，Findings None，Verdict Pass。DEC-023 已批准“系统整理、玩家确认，文字首层、粗数按需，常驻方向、提示按需加深”的首轮玩家验证方向，具体布局、概率组件、提示文案与正式数值仍未批准；
- v0.3 作者规格已由用户通过 DEC-024 批准为玩家微循环输入；DEC-025 固定系统整理、玩家可选保存“当前倾向＋首要疑点”、焦点只重排注意力、中途快照不产生后果、收手时确认最终快照。三个同内容低保真分支虽通过 Routine 线路检查，但用户已否决其核心交互，并于 2026-08-22 要求删除五个未提交原型文件；项目只保留轻量失败记录。当前先审清 Git 检查点与 UI／UX Skills 的安装／退出边界，再讨论以渐进可视化地图组织玩家认知的具体语义；
- 正式产品代码仍须依次通过玩家微循环无答案真人测试、Experimental 数值模拟、整局低保真原型与无答案真人测试、V2 继承／技术审查，并由用户明确批准开工。当前只允许设计并制作与产品实现隔离、可丢弃的玩家微循环原型；
- 首案不混入其他器物旧片；现实资料是物理／检测／价值因果的可信护栏，不要求复刻现实馆藏，也不替游戏选择具体事故、区域或档案细节；
- 第一张真相拓扑按手工关卡打磨，不为未来生成器牺牲文化语义、证据因果、路线差异或停手体验；程序化真相／拓扑生成保持后期 `Unknown`；当前允许研究、设计并在产品实现外编写隔离的自动校验／作者辅助工具，但不允许生成器代写首案；
- 产品影响决定继续执行“本地现状＋原始来源＋真实实践”的调查门，证据饱和后停止。

## 明确非目标

- 当前不实现正式产品代码、五种拓扑、正式美术或完整自动化；隔离的校验器、模拟脚本和低保真原型只作为代码前验证工具；
- 当前不抽象通用器物语法，不自动生成器物真相、证据语义、价值因果或完整拓扑，也不把结构检查通过称为趣味成立；
- 当前不为没有调查、停手或价值作用的器物个性继续扩张考据，也不把这些细节反复上交用户；
- V3 不重启 NPC 认知、人物画像、连续对话、D20、受控误导、议价或人物评分体系；
- 第一器物不默认继承 V2 漆木盒、固定三真相、五热点、旧证据或数值；
- 当前不把 V2 的 5 个热点、21 条候选 evidence、固定三真相或 A／D／N 直接当成 V3 规格；
- 当前不接真实市场价格数据库、机器学习／POMDP 求解器、LLM 对话、登录、云存档或生产 API；
- 当前不制作最终作品集 PDF，不公开复用研究参考图，不 push、deploy 或发布。

## 重新讨论触发条件

- 用户重新打开 DEC-017 的阶段主张、手动停手、单次挂牌或三轨结算边界；
- 第一纸面拓扑无法形成完整一局，或只有唯一支配路线；
- 三档结果只能靠固定行动顺序成立，或结果 2 到结果 3 之间没有局部成果与理性停手点；
- 第一真相包派生后只产生坏消息／好消息单一路径，或某项高级检测／单份文档成为完整答案按钮；
- 为兼容未来生成器而把首案压成固定槽位、通用修复分或等价路线，或在两张通过验证的不同手工案例出现前要求实现程序化生成；
- 玩家图稳定泄题、仍让玩家迷失，或把推理变成任务清单；
- 成本、价格、阶段摘要与停止机制奖励无条件高估、无限调查或固定追逐高值尾部；
- 文化专家改变关键事实、证据关系或价值区间；
- 时间／美术／测试资源证明 `2026-08-26` 候选范围不可完成；
- Web 技术底座无法满足可视图、移动交互、回放或发布要求。
