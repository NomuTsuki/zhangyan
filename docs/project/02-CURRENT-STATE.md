## 已完成但尚未验证

- 当前等级阈值、议价容量、参考报价、NPC 状态权重和案件费用仍是工作参数，尚未证明平衡或有趣；
- 老师能否在没有解释公式的情况下理解“观察—取证—公开证据—议价—复盘”仍待真人试玩；
- 当前只有一个低级场教学案，不能代表中级场、高级场和厚尾价值体验已经成立；
- 高保真器物图仍是程序内联二维插画，不是最终正式美术资产；
- 精品、珍品局末写实器物讲解图只被记录为后续方向，本轮没有制作；
- 单文件可以离线展示，但公开托管、HTTPS、微信聊天内置浏览器和公众号链接实机仍未验证；
- Safari、320px 极窄屏、软键盘遮挡、真实设备 safe-area 尚未做专项验证。
- `npm audit --omit=dev` 报告当前 Next.js 服务端依赖链有 3 项高危公告；离线单文件不使用该服务端，但公开部署前必须升级并回归。

## 当前最大风险

最大的风险已从“代码能不能跑”转为“老师和玩家是否能读懂核心因果”：

1. 玩家是否理解证据公开会同时改变信息和价格；
2. 玩家是否能区分调查行动点与议价容量；
3. `D—SSS` 多维结果是否比旧 0—100 分更容易解释；
4. 系统谨慎报价会不会被误解成最优答案；
5. 当前工作参数是否让教学局过于容易或过于保守。

## 当前阻塞

- 本轮离线教师演示没有技术阻塞；
- 老师理解反馈是下一轮产品决策的必要输入，但不阻塞当前文件交付；
- 公开 H5 地址和微信内实机验证需要后续选择托管方式，不属于本轮离线演示范围。

## 当前边界

- 不迁移 Unity；
- 不制作微信小游戏工程；
- 不把高保真完成等同于玩法平衡或正式美术验收；
- 不接真实市场价格、登录、云存档、支付或长期经济；
- 不在老师初看前扩写第二案件。
