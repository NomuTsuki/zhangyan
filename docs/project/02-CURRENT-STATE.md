## 已完成且已验证

- 根目录 Git 仓库已经建立，保留此前原型提交历史；
- React 版与自包含单文件 HTML 均能完整演示首案；
- 调查和 NPC 交流不再是固定先后阶段：观察、开放询问、带证据追问、专项检测与折价共用 6 点行动预算；
- 买下和拒绝为零行动点终局动作，行动点耗尽后仍可完成一局；
- 证据簿只读，能从调查页和交易页打开并返回原页面；
- NPC 的压力、信任、成交意愿和控制感逐轮变化；同一态度重复使用仍会按历史和当前状态产生新结果；
- NPC 每轮按“状态 delta → 候选行为发散 → 硬过滤 → 分项评分与 seed 近分扰动 → Storylet 收敛 → 回应”处理，并保存完整轨迹；
- 物品隐藏真相与 NPC 认知档案分离，NPC 回应和底价不会读取物品真相；
- 规则样片支持赝品 20、旧胎重修真品 65、被低估珍品 130 三种隐藏真相；演示开价 80、折价 60、专项检测成本 `2 AP + 10价值点`；
- 结算同时输出客观净结果、界面可达的完全知情最优净结果、后悔值、客观分，以及只读玩家可见信息的判断质量；
- 同一次 NPC 回应生成的陈述信号与陈述卡已经去重，不会重复提高后验；
- 宽屏调试栏实时显示精确状态和规则进程；隐藏真相、底价、接受线和定价分项仅在局末解锁；
- 局末展示整局状态变化图、每轮 delta、候选评分、Storylet、客观公式、后验与判断公式；
- 生产构建、ESLint、差异格式检查与 20 项自动测试全部通过；
- 独立复审完成 100 局、511 个随机合法步骤的 TypeScript/独立 HTML 差分回放，核心状态与结算 0 漂移；
- 1280 × 900 桌面完整主路径与 390 × 844 手机布局已实测；手机无横向溢出且不显示开发调试栏。

## 最近获得的新证据

- 用户接受共享行动预算与客观结果/判断质量双层结算，并重申 NPC 需要“先发散、再收敛”的有限演绎结构；
- 完整循环证明观察与询问可以交叉进行，同时保持行动点单调下降和交易终局可达；
- NPC 真相隔离回归证明：相同可见历史在不同物品真相下会得到相同回应和判断质量，但客观结果不同；
- 死局回归证明：极端压力与低成交意愿只会在选中离场行为时结束，数值阈值本身不会制造“活动局但不能交易”的状态；
- 信息边界回归证明：局末前无法从调试栏精确反推底价，局末后仍可查看全部公式；
- 当前最大的未知已经从“规则能否闭合”转为“玩家能否理解、参数是否平衡、是否存在支配策略”。
