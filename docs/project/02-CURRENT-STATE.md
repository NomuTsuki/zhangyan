- 首轮价值分布和有限议价已经完成技术模拟，但参数尚未经过教师或玩家平衡验证；

## 已批准但尚未实现

- 信息结构扩展为物品真相、玩家后验、NPC 后验和共享信息四层；NPC 与推荐系统继续禁止读取隐藏真相；
- 玩家与 NPC 都不能故意捏造事实，但可以拒答、选择性披露，NPC 允许真诚但错误的记忆或判断；
- 客观证据被用于质询、对峙或共同检测后进入共享信息，双方分别更新认知，NPC 可能补充口供并重新估价；
- 快速降低不确定性的证据链更倾向要求共享关键信息，因此可能同时教育卖家；只公开利空不能成为跨 NPC 类型的通用最优解；
- NPC 初始开价只是有噪声的行为，可以高估、低估、给出区间或缺失；证据主要改变主观估值，关系状态主要改变谈判档位和让步；
- 急售、风险规避的 NPC 可以用更低的确定成交价格把鉴定和价格波动风险转移给愿意立即买断的玩家；
- 上述方向已写入 DEC-007，具体参数与玩法健康度进入 HYP-004 实验。

## 最近获得的新证据

- 用户确认 NPC 可以出现真诚但错误的记忆或判断，但不能故意捏造已知事实；
- 用户确认从模糊判断走向严谨判断应有不同路径，快速降低不确定性的路径通常需要公开关键证据并承担卖家重估风险；
- 用户确认选择性披露对不同专业背景与性格 NPC 应产生显著不同结果，行家或重视真诚的人物可能因片面披露降低信任与成交意愿；
- 用户确认玩家可通过立即、无条件买断等条件，为急售且风险规避的 NPC 接走高不确定性器物的价值波动风险；
- 用户确认长期价值结构需要低概率的极端赝品与极高价值珍品，且市场事件可以同时提高两端遭遇概率；
- 用户确认 NPC 初始开价由其认知与人物设定决定，允许外行高估赝品或低估珍品，但巨大错价应保持稀有；
- 用户把价格参考系统重新定义为不追逐高风险收益、只依据玩家可见后验的慎重辅助，并接受信息不足时保守报价可能无法成交；
- 用户提出讨价还价轮数应受 NPC 设定、演绎过程、背景信息与当前状态共同影响，但具体模型仍待讨论；
- 用户接受共享行动预算与客观结果/判断质量双层结算，并重申 NPC 需要“先发散、再收敛”的有限演绎结构；
- 完整循环证明观察与询问可以交叉进行，同时保持行动点单调下降和交易终局可达；
- NPC 真相隔离回归证明：相同可见历史在不同物品真相下会得到相同回应和判断质量，但客观结果不同；
- 死局回归证明：极端压力与低成交意愿只会在选中离场行为时结束，数值阈值本身不会制造“活动局但不能交易”的状态；
- 信息边界回归证明：局末前无法从调试栏精确反推底价，局末后仍可查看全部公式；
- 当前最大的未知已经从“规则能否闭合”转为“动态双边认知是否可理解、信息披露是否存在支配策略、风险转移是否会退化为赌博”。
- 10,000 局基准证明两端市场扰动可把赝品/珍品从 `25%/3%` 调至 `35%/10%`，同时把均值约 `123 → 205`、中位数约 `79 → 75`，说明中位数比均值更符合谨慎参考；
- Q线上限内阶梯议价没有免费提高成交率：与一次Q线报价同为 `30.7%` 成交，但平均成交价 `61.4 → 59.1`、成交后亏损 `9.0% → 7.6%`；
- 首轮参数实验暴露普通藏家两倍级错价过于频繁，这是当前最高价值的调参问题。
