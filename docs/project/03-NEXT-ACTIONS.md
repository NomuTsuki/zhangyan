## 完成标准

正式产品代码开工门需要同时满足：

- 第一纸面拓扑正确使用原始事实、鉴定主张、真相包、主张支持度和价值情景，不把它们压成同一种节点；
- 第一陶瓷切片的三档结果能由多种证据顺序建立，门本身不产生似然或锁行动；G2 能表达“重大重组成立但阶段未解”，G3 不要求清空全图；
- 第一陶瓷切片正常内容在充分建立 G2 后只会保持 G2、形成 G3，或以更多局部成果、成本和剩余未知停在 G2；永久 G2→G1 只作为通用防御／未来案件能力验证；
- 第一器物是经过独立结构复核、确定性演算、限定领域复核和用户批准形成的手工作者规格；自动校验只证明限定结构性质，不冒充趣味、深度或文化正确性；
- 第一器物有可追溯的领域来源，并因证据拓扑承载力被选择，而不是因为 V2 已有素材；
- 手动停手、冻结系统估值、玩家一次挂牌和客观市场结算能够判断一项调查何时有价值；
- 第一纸面拓扑能走完一局，至少有一条替代／恢复路径，核心理解不被随机永久锁死；
- 作者规格明确记录玩家侧不得泄露完整作者图、隐藏节点或隐藏真相路线；常驻层不指定唯一动作，只有玩家主动请求最强帮助时才点名基于本局已知信息的当前最优调查；玩家知识图由系统整理，玩家确认关注、判断与停手，具体表达已经过微循环原型与无答案真人测试；
- 高估、低估、首阶段就停、无限追逐高值尾部和只追熵下降都没有纸面上明显的无条件优势；
- 整局低保真原型与无答案真人盲测已经覆盖自由调查、三档成果、停手、估值、挂牌、市场和揭示；
- Experimental 数值有来源、集中权威、回退条件与验证记录，没有纸面上明显的无条件支配策略；
- V2 继承范围、V3 架构、产品工作树、接口、测试结构、实施计划和回滚方式明确；
- 文化事实、数值、UI、自动化、盲测和美术分别列出验证责任，且没有未解决的核心体验、范围或验证含义问题；
- 用户明确批准正式产品代码开工。

## 执行中停下规则

遇到会改变玩家选择、规则因果、三档含义、手动停手、作者图／玩家图边界，或要把举例升格为正式内容的新问题时立即停下，一次只与用户对齐一个问题。新产品数值、验证通过线、V2 未批准继承项、阻断性的独立／领域／真人结论，以及 H5 路线、产品范围或开工条件变化同样触发停下。纯机械修正、文档一致性和不改变行为的技术细节由项目处理并记录。

## 停放区

- **五种拓扑批量内容：** 第一拓扑通过纸面、自动与无答案玩家检查后扩展；
- **程序化真相／拓扑生成：** 第一张及一张结构不同的第二手工案例通过相同领域、自动与无答案玩家门后，才可提出只改变未锁定字段的受约束实验；这不是路线承诺；
- **正式美术与最终 PDF：** 核心交互与信息架构稳定后制作；过程资产最多保留一个转折节点；
- **公开发布：** 依赖安全升级、真实移动端／微信内验证和授权后再处理。

## V3 外边界

- V2 的 NPC 认知、画像、关系状态、连续对话、D20、洞察、议价、人物评分和行为仲裁不属于 V3，也不作为 V3 待办；若未来重开，需要在 V3 之外重新批准项目范围。
