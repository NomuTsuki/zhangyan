# Architecture / Design Challenge: 结算、议价资源与信息披露未完成对齐

Status: Resolved

日期：2026-07-27

## 观察

用户在首轮整合原型试玩中发现：

- 真实价值为 65、成交总价为 65 时，旧版结算可能给出 100 客观分；以 60 成交时也可能仍为 100；
- “完整说明事实”和“只强调不利部分”没有形成玩家能够理解的实质差别；
- 正式讨价还价不应继续消耗调查行动点，而应由 NPC 设定、性格、此前演绎与当前状态共同决定可议价次数；
- 风险转移只是部分人物与案件下可能有效的措施，不是核心玩法；
- 数值实验台和局末调试信息一次披露过多，妨碍理解和决策。

这些反馈说明，当前原型虽然能够稳定运行，但其中若干工作公式与交互方式尚未获得用户认可。

## 受影响的现有决定

- [DEC-003](../../decisions/DEC-003-integrated-investigation-loop.md)：检测、询问和对质共用调查预算的方向保留；正式议价被实现为也消耗该预算的扩展没有得到确认。
- [DEC-004](../../decisions/DEC-004-objective-outcome-and-judgment.md)：客观结果与判断质量分层保留；当前客观分公式、满分基准和胜利阈值需要重做。
- [DEC-007](../../decisions/DEC-007-dual-belief-and-strategic-disclosure.md)：四层信息与策略性披露方向保留；抽象披露按钮和风险转移的 UI 层级需要重新定位。
- [HYP-003](../../hypotheses/HYP-003-stateful-bargaining.md)：其中“正式报价继续消耗共享行动点”的假设已被用户明确否定。
- [HYP-004](../../hypotheses/HYP-004-dual-posterior-disclosure.md)：风险转移不能继续承担核心玩法验证职责。

## 证据

- 用户 2026-07-27 的首次整合原型试玩反馈；
- [EXP-009](../../evidence/EXP-009-first-player-alignment-review.md)；
- 当前结算使用玩家本局动态形成的买断线构造参考最优，可能把“当前路径无后悔”误写成“经营满分”；
- 当前两种披露方式公开同一证据、更新同一双方后验，差别主要是一个不易察觉的关系惩罚；
- 现有自动测试可以证明代码忠实执行这些规则，但没有覆盖用户提出的语义例子。

## 不处理的后果

- 玩家无法从分数理解自己究竟赚了多少、议价是否有效、判断是否合理；
- 自动测试会继续保护未经确认甚至已经被否定的规则；
- 调查资源与议价资源混在一起，人物差异难以真正决定谈判长度；
- 披露与风险转移可能被误解为系统指定的核心解法；
- 实验台继续增加参数会提高认知负担，而不是降低设计不确定性。

## 可选方案

1. 逐项修补现有分数、按钮和行动点公式。改动较快，但容易继续在未对齐的目标上调参。
2. 暂停玩法扩展，先用少量手算案例确认结算输出与资源边界，再重写规则、测试和 UI。速度稍慢，但能先建立共同语言。
3. 暂时删除所有评分和披露玩法，只保留鉴定与交易。最容易理解，但会丢失已经确认的双层结算和信息管理方向。

## 推荐

选择方案 2：

1. 玩家局末先只展示实际净收益、议价表现和判断质量；利润率、机会损失与完整公式暂留开发复盘，不立即合成总分；
2. 把调查行动点与议价资源分开，调试阶段同时显示精确值；
3. 暂时移除“完整/片面”抽象按钮，让玩家通过选择公开哪条证据形成选择性披露；
4. 将风险转移降为特定人物或案件中的可选交易条件；
5. 先由用户确认一张小型示例表，再把例子写成测试，最后修改原型。

## 需要用户拍板的问题

请在 [近期决策文档](../../../../近期开发对齐/05-请你填写的近期决策.md) 中回答两个阻塞项：

1. 局末先展示哪些独立结果，以及是否仍需要 0—100 客观总分；
2. 独立议价资源应如何计算、显示和消耗。

披露按钮是否暂时移除、风险转移如何降级已经给出默认建议，可在同一文档中补充意见，但不阻塞第一轮对齐。

## 解决结果

用户于 2026-07-31 完成近期决策文档并批准：

- 第一版取消 0—100 客观总分，采用物品品质、实际净收益、议价表现和判断质量共同形成 `D—SSS` 综合等级的方向；具体阈值通过后续平衡确定；
- 调查行动点与议价容量分离，调试阶段均显示精确值，第一版容量参数较宽松；
- 移除“完整说明 / 只强调部分信息”抽象按钮，以选择具体证据实现披露；
- 风险转移继续作为少数人物与案件下的特殊措施。
