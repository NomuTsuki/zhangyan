# Architecture / Design Challenge: NPC 受控误导与“人与物双重鉴定”边界

Status: Resolved

日期：2026-08-11

## 观察

当前 V2 玩家试玩版已经能完成调查、提交判断、交易和双轨结算，但实际体验仍主要围绕器物表单展开：NPC 的个性被“急售、谨慎、相信家族口述”等事实化摘要直接写在界面上，行动后的回复缩成小号状态提示，议价页则完全没有 NPC 台词或人物在场感。

只读数值复核同时发现，检查承担器物证据结构和评级封顶，询问虽然会更新陈述信号，却更强地改变 NPC 四状态、公开信息和价格，因此玩家把它理解为压价工具并非单纯的界面错觉。现有“证据链”也只是按来源与维度计数的平铺集合，没有串行前提、并行路径、中间结论或替代闭合路径。

用户提出将核心体验调整为：玩家既鉴定器物，也通过 NPC 的语言、动作和连续回应判断其知识与披露意图；在高杠杆互动后使用 D20 洞察检定获得额外但不定罪的观察；允许某些 NPC 基于自身认知进行受控误导；用非线性证据拓扑支撑真正的推理链。

## 受影响的现有决定

- Project Compass 的“证据优先于情绪读取”“物品真相、NPC 认知、NPC 陈述和 NPC 状态分层”；
- [DEC-005](../../decisions/DEC-005-separate-object-truth-and-npc-belief.md) 的真相／NPC 认知隔离及“主动欺骗”重开触发；
- [DEC-007](../../decisions/DEC-007-dual-belief-and-strategic-disclosure.md) 的“双方不能故意说出与自身已知信息相反的话”；
- [DEC-013](../../decisions/DEC-013-v2-player-trial-and-dual-track-scoring.md) 的公开人物特征与玩家可见接受概率模型；
- 手机竖屏关键体验、NPC 表现方向和评分边界。

## 证据

- [EXP-022](../../evidence/EXP-022-human-object-player-trial-audit.md) 记录了当前 UI、数值、证据结构、NPC 模型和研究审查；
- 当前 `ObservationTarget` 没有前置条件或 AND／OR 拓扑，评分只计算平铺来源与维度；
- 当前 NPC 行为模板携带作者配置的真相似然并直接参与器物后验，却没有先经过 NPC 可信度／意图推断；
- 当前议价结果没有人物台词，行动反馈使用 11px `.notice`；
- 两张 390×844 基线截图显示：调查页没有 NPC 立绘，议价页没有 NPC 本人或回复。

## 不处理的后果

NPC 会继续更像价格调节器而不是需要被理解的人；询问与器物推理脱节；玩家可能通过作者任意配置的“反应似然”猜器物；增加洞察骰只会把新的随机层叠在错误因果链上；继续扩写案件会放大内容语义错位和证据链过短的问题。

## 可选方案

1. 只放大 NPC 文案与立绘，维持现有无说谎、平铺证据和接受概率模型：成本最低，但不解决系统性问题。
2. 允许所有 NPC 自由说谎，并让洞察直接显示真假或隐藏状态：戏剧性强，但会破坏证据优先和认知隔离，也使 D20 取代玩家推理。
3. 建立“器物证据—NPC 主张—可观察表现—洞察观察”四层、双后验与三张证据图；只在独立 NPC 情境中受控允许误导，洞察只提供附加观察；玩家过程不显示接受概率。

## 推荐

采用方案 3。它保留 DEC-005 的隐藏真相隔离与 DEC-007 的有限认知核心，只局部放宽“绝不故意误导”；同时把 NPC 表现从事实标签改成可观察但多义的信号。必要线索不依赖随机成功，D20 只增加人物判断的深度。

## 需要用户拍板的问题

用户已经逐项确认：受控误导只先落在瓷器二道贩子情境；洞察只负责额外读取 NPC 表现；高杠杆节点自动检定且不耗行动点；显示骰面、`+2` 修正和 `DC 10/12/14`；自然 1／20 不自动成败；相关证据或已记录矛盾给予优势；人物表现不直接给出真假标签；游戏过程不显示接受概率；察人评分先单列而不进入总评。

## 解决结果

Challenge 已由用户批准的 [DEC-014](../../decisions/DEC-014-human-object-dual-appraisal.md) 解决。DEC-005 的真相隔离继续有效；DEC-007 的“绝不故意误导”条款仅在 DEC-014 定义的受控 NPC 情境内被局部取代；DEC-013 的 A／D／N 权重与双轨结算保留，但“公开人物事实标签＋过程中显示接受概率”被取代。
