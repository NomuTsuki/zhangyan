# DEC-002: 当前原型以可解释精确状态降低不确定性

Status: Active

日期：2026-07-22

最近复查：2026-07-23

## 当前决定

当前阶段显示压力、信任、成交意愿、控制感四项 0—100 精确 Mock 数值，供产品沟通和规则讨论；证据簿保持只读。原决定中“价格与交易数据暂不进入验证范围”的部分已由 [DEC-004](DEC-004-objective-outcome-and-judgment.md) 取代。

## 背景和问题

粗粒度箭头不足以支持用户与开发者讨论状态变化。证据簿内的“用此证据对质”又混淆了信息仓库与行动入口的职责。

## 考虑过的替代方案

1. 继续只显示箭头并允许证据簿直接行动；
2. 先显示精确 Mock 数值，同时将观察页固定为阶段行动枢纽。

## 选择理由

第二种方案能用最低成本暴露规则问题和导航歧义，又不会提前承诺正式数值平衡。

## 影响范围

- P2、P3、P4、P5 的导航与反馈；
- NPC 状态模型的下一步实现；
- 真实市场数据库与正式经济平衡仍被排除，但规则样片必须加入游戏内量化价值与交易成本。

## 当前信心

高，因为：用户明确指出交互问题并要求精确值；实现已通过自动测试。

## 重新讨论触发条件

- 试玩表明精确数值明显干扰核心体验；
- 规则引擎接入后需要区分玩家界面与调试界面；
- 玩法闭环稳定，进入正式表现设计阶段。
