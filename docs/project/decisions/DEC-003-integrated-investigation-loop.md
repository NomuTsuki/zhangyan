# DEC-003: 检测与询问交叉进行并共用行动点

Status: Active

日期：2026-07-23

## 当前决定

检测器物、询问 NPC、引用证据追问和对质属于同一个调查循环，共用一套只减不增的行动点。玩家可以在这些行动之间自由交叉，不再被强制拆成“先观察、后行动”的线性阶段。

证据链与 NPC 状态会随行动历史持续变化。没有证据也允许询问，但是否有效由问题、当前证据、NPC 状态和历史共同决定。态度只是行动的表达修饰项，不能再单独代表“玩家做了什么”。

证据簿继续保持只读信息仓库；交易不能再因某种态度或行动点耗尽而形成死局。

## 背景和问题

现有原型以“观察 → 证据 → 选择态度 → NPC 回应 → 交易”的单向流程展示一次规则结算。连续行动时，检测和交涉争夺同一决策预算的核心张力没有形成，重复选择态度也不能表达玩家在不同问题、证据和目标上的策略。

用户在 2026-07-23 明确修正此前“观察点与交涉点分离”的方向，要求检测和 NPC 交流交叉进行，并共同管理证据、NPC 状态和行动点。

## 考虑过的替代方案

1. 检测点和交涉点分开，继续采用线性阶段；
2. 保留一个行动点池，把检测、询问、对质和交易协商放入同一循环。

## 选择理由

第二种方案能让每次检测与询问形成真实机会成本，并支持“发现线索 → 询问 → 根据陈述再检查 → 用新证据追问”的核心推理体验。它也能让无依据询问保持可行但通常效率较低，而不是被界面禁止。

## 影响范围

- P2—P5 线性页面和阶段导航已经重构为可交叉返回的调查循环；
- `PlayerAction` 已包含行动类型、目标或问题、可选证据和表达方式；
- 规则输入已经从单次初始状态改为完整世界状态与行动历史；
- 自动测试已覆盖混合行动序列、点数耗尽和交易无死局；
- 现有三态度规则切片保留为计算实验，不再视为完整可玩循环。

## 当前信心

高，因为：用户直接确认了共享行动预算与交叉调查方向，且它解释了现有重复行动、流程死锁和策略贫乏三个系统性问题。

## 重新讨论触发条件

- 规则样片显示共享预算导致玩家无法形成任何可解释证据链；
- 试玩显示询问与检测在职责上仍然无法区分；
- 内容制作成本无法支持足够的观察目标与询问主题。
