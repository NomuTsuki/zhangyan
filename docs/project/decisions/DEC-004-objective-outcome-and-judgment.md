# DEC-004: 客观交易结果与判断质量分层结算

Status: Active

2026-08-10 取代说明：本决定的“客观结果与主观能力分层”原则继续有效；旧版由器物品质、净收益、议价与判断质量共同产生综合成果等级的部分，已被 [DEC-013](DEC-013-v2-player-trial-and-dual-track-scoring.md) 的“能力评级 + 客观经济结果”双轨结算取代。

日期：2026-07-23

## 当前决定

每个案件必须存在不依赖玩家认知的器物真相，以及可用于结算的量化价值。最终购买、折价成交、拒绝等结果需要根据真实价值、实际成交条件和额外成本产生客观得失。

结算同时保留第二层“判断质量”：评价玩家依据当时实际掌握的证据作出的选择是否合理。客观得失和判断质量不能互相替代，从而能够区分稳健成功、幸运蒙对、合理失手和完全看走眼。

2026-08-03 补充：判断质量在内部拆分为 `D / C / R / J`，分别承担决策合理性、后验确定性、证据链稳健度与合成判断。普通单条强证据的判断质量最高为 `S`，局部锚点证据最高为 `SS`；只有完成交叉验证，或发现能够锁定整案候选解释的决定性证据，才有资格进入 `SSS`。该上限不读取隐藏真相，仍只依据玩家当时可见的信息计算。

第一版不再输出 0—100 的客观总分。玩家结算先分别看到物品客观品质/价值、实际净收益、议价表现和判断质量，再用 `D / C / B / A / S / SS / SSS` 表达综合成果等级。物品客观品质为综合等级提供基础区间和上限；实际净收益、议价表现与判断质量决定该区间内的最终档位。低价值赝品即使判断和议价都很好，综合成果等级的工作上限约为 C，但判断质量仍可单独显示为高水平，避免把抽到低价值器物误写成玩家能力差。

等级阈值、各项权重和不同品质的上限只是待平衡参数，不在本决定中假装已经精确。开发复盘继续保留原始数值和公式，玩家主界面只显示少量可理解的分项与等级。

“送检后再议”不再作为无代价、自动获得答案的安全结局。首个规则样片把专项检测实现为需要 NPC 同意的非终局行动，工作成本为 `2 AP + 10价值点`，检测后仍需作出交易决定；该参数等待试玩调优。

## 背景和问题

此前仅按“风险是否被证据覆盖”评价交易，会把真实为赝品、小修真品或高价值珍品的案件压成同一种主观合理性判断，也会让拒绝或免费送检成为几乎无条件安全的策略。

用户要求本局成功同时包含客观事实意义上的得失，并允许早期发现关键证据所带来的运气，以及理解线索、继续补证所带来的策略差异。

## 考虑过的替代方案

1. 只评价证据使用和风险控制，不计算器物真实价值；
2. 只按最终赚亏判胜负，不评价玩家当时是否有合理依据；
3. 同时输出客观交易结果与基于可见信息的判断质量。

## 选择理由

第三种方案既保留“掌眼”作为买对、买值或避损的客观目标，又不会把幸运猜中误写成高水平判断，也不会掩盖在信息不足下作出合理选择但结果不佳的情况。

## 影响范围

- 案件配置需要包含隐藏事实、结算价值、开价或交易条件；
- 结算规则需要记录实际支付、检测成本、失去的机会和最终持有物；
- 复盘需要分别展示客观结果和判断依据；
- 下一版结算需要删除旧 0—100 客观分及胜利阈值的玩家展示，改为分项结果与等级制；
- 自动测试应先验证等级顺序、品质上限、净收益单调性和判断质量独立性，再进行权重平衡；
- DEC-002 中“价格与交易数据暂不进入验证范围”的部分被本决定取代；真实市场价格数据库仍不在当前范围。

## 当前信心

结构与等级制方向高、具体平衡低。用户确认取消第一版 0—100 总分，并提出由物品品质、实际净收益、议价表现和判断质量共同决定 `D—SSS` 综合等级。具体档位边界与权重尚未验证。

## 重新讨论触发条件

- 量化价值被玩家误解为真实市场报价或文化价值的唯一尺度；
- 双层结果让玩家无法理解本局到底是否胜利；
- 送检、折价或拒绝出现无条件支配其他策略的情况。
