# DEC-005: 物品真相与 NPC 认知档案分离

Status: Active

日期：2026-07-23

## 当前决定

物品客观真相、NPC 对物品的认知和 NPC 的交易底线属于三个不同层次：

- 物品真相决定观察结果、检测结果、真实价值和客观结算；
- NPC 认知档案决定其知道、误解或不确定的内容，以及可生成的陈述；
- NPC 底价和行为只读取认知档案、当前四状态与历史，不读取物品隐藏真相。

判断质量同样不能读取隐藏真相，只能使用玩家已见的物证、检测和 NPC 陈述信号。同一次回应生成的结构化陈述信号与证据簿陈述卡属于同源信息，只计权一次。

## 背景和问题

如果 NPC 回应或底价直接按物品真相分支，NPC 会表现得像全知者，玩家还可以通过对话或报价反推出本应隐藏的客观事实。如果判断分使用隐藏真相，则“幸运猜中”和“有据判断”无法区分。

## 考虑过的替代方案

1. 每个隐藏真相同时绑定一套 NPC 知识、回应与底价；
2. 只隐藏文字，不隔离运行时数据；
3. 将物品真相、NPC 认知和玩家可见信息建模为独立层。

## 选择理由

第三种方案既允许同一物品真相搭配不同卖家故事，也能保证剧情演绎来自 NPC 的有限认知而非系统泄题，并为后续案件复用提供清晰边界。

## 影响范围

- `CaseDefinition` 分别保存 `truthVariants` 与 `npcProfile`；
- 对话 Storylet、候选行为和接受线不得读取 `truthVariantId`；
- 后验和判断质量只读取物证、检测与结构化陈述信号；
- 调试侧栏的隐藏真相和定价门控在局末前必须脱敏；
- 复盘将“物品客观真相”和“NPC 当时认知”分开展示。

## 当前信心

高，因为：该边界已经由跨三个真相的回归测试和差分回放验证，且直接修复了 NPC 全知、判断串线与同源证据重复计权风险。

## 重新讨论触发条件

- 后续案件需要 NPC 确实知道真相并主动欺骗；
- 多 NPC 对同一器物持有不同知识；
- 认知档案需要从静态配置升级为可发现、可改变的信念模型。
