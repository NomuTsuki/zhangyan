# DEC-006: 厚尾价值先验与保守后验参考报价

Status: Active

2026-08-10 取代说明：厚尾价值、案例生成时固定真相、NPC 认知与隐藏真相分离的原则继续有效；后验 Q20/“谨慎参考报价”玩家入口已被 [DEC-013](DEC-013-v2-player-trial-and-dual-track-scoring.md) 取代。V2 改为展示期望价值、Q10—Q90 与不确定性，报价由玩家自行输入。

日期：2026-07-23

## 当前决定

《掌眼》的器物价值不采用“围绕一个普通价格小幅波动”的单峰模型。不同器物类别拥有不同的价值先验，常规品占主体，同时保留低概率的极端赝品与极高价值珍品；极端结果必须在案件生成时确定，并留下可被调查但不直接明示的证据。

NPC 开价、底价和还价行为来自 NPC 自己的认知、专业度、性格、动机、市场背景与当前状态，不直接读取器物隐藏真相。因此外行可能高估赝品，也可能低估珍品，但这类巨大错价保持为低概率事件。

市场日报等背景事件可以改变某类器物的遭遇构成，使赝品与珍品两端同时更常出现；事件是玩家可见但需要通过多案摸索其含义和可靠性的背景信号，不是直接公布概率或答案。

价格参考系统定位为性格慎重、只读取玩家可见信息的局部辅助。它不以追逐高风险高收益或最大化平均收益为目标，不读取隐藏真相，也不保证客观必赚；它应使用不易被极端高价尾部抬升的稳健后验统计量，给出保守参考，并允许因信息不足而报得过低、无法成交。具体采用后验中位数还是更低分位数，留给参数实验验证。

## 背景和问题

当前规则样片只用 20、65、130 三个固定真相和固定折价 60 验证闭环，无法表达古董市场中“多数普通、少数极差、极少数价值悬殊珍品”的长期惊喜，也无法让 NPC 专业度与错误认知形成双向错价。

用户希望稀有极端结果像随机词条一样制造欣喜或懊悔，但仍需让演绎推理能够排除部分尾部风险，避免玩法退化成纯抽奖。用户同时把参考报价重新定义为信息不对称下的谨慎工具，而不是知道答案的最优解。

## 考虑过的替代方案

1. 每类器物只使用单一固定价值或窄幅分布；
2. 使用平均值最大化长期期望收益；
3. 让 NPC 开价直接跟随真实价值；
4. 使用类别先验、低概率极端层、独立 NPC 认知与保守后验参考。

## 选择理由

第四种方案同时保留客观真相、运气、可学习证据和人物差异。平均值容易被极少数天价珍品拉高，不符合谨慎参考系统的性格；NPC 定价与真相分离则延续 DEC-005 的信息边界，并为低买高卖、被骗和合理放弃提供一致来源。

## 影响范围

- 案件配置需要逐步增加器物类别、真相层级、价值先验与市场状态；
- NPC 档案需要明确专业度、主观估值误差、加价习惯、急迫度和谈判耐心；
- 后验系统需要区分器物价值分布与 NPC 接受线分布；
- 交易 UI 将同时保留 NPC 当前开价与系统保守参考，但二者都不是客观真值；
- 局末复盘继续分开显示客观得失与当时依据下的判断质量；
- 当前阶段只做最小参数实验，不扩建真实市场价格数据库或长期经济系统。

## 当前信心

方向高、具体参数低至中。价值两端、NPC 错价与谨慎参考由用户直接确认，并与 DEC-004、DEC-005 一致；首轮混合分布、日报倍率和 Q20 已完成技术模拟，但普通藏家两倍级错价达到 `34.8%`，不符合“巨大错价低频”的方向，必须继续调参。所有参数仍未经过教师或玩家试玩。

## 重新讨论触发条件

- 极端随机结果压过证据推理，使玩家只能靠运气；
- 保守参考价成为无脑支配策略，或长期几乎无法成交；
- 市场事件只能通过刷新或背概率利用，不能形成可学习信号；
- 单次极端收益击穿后续长期经济；
- 玩家把参考价误解为系统泄露的真实价值。
