# DEC-009: 二维器物插画定位，文字承担鉴定事实

Status: Active

日期：2026-07-31

## 当前决定

当前案件的古董不使用真实照片或 3D 渲染，采用细节精致、非写实的二维插画风格。

插画负责：

- 展示器物整体形态、材质气质和可观察位置；
- 通过正面、底部、接口等视角及热点定位建立空间对应；
- 在局部观察时提供构图强化的裁切、示意轮廓和位置高亮。

文字负责：

- 准确陈述细纹、标记、锁扣结构、胶痕等观察事实；
- 区分“看到什么”“当前意味着什么”“还可以核验什么”；
- 承担证据簿中的可复查记录，避免玩家从插画像素猜测并不存在的微观事实。

低价值首案不制作高成本写实器物图。后续精品、珍品案件可在结算后增加一张写实风格器物讲解图，用于文化知识和真实特征讲解；该资产暂不进入当前实现范围。

## 背景和问题

团队初步讨论认为，真实照片或 3D 会显著提高素材与一致性成本，而细纹、标记和锁扣等鉴定信息也很难仅靠一张风格化插画稳定表达。若把关键事实藏在画面像素里，会使玩法退化为找茬，并造成可访问性和理解偏差。

## 选择理由

- 保留二维 H5 的视觉辨识度和制作可控性；
- 让位置探索与证据判断各自使用合适媒介；
- 文本证据可以精确、可测试、可复盘，也便于后续专家校订；
- 美术成本随器物价值和内容重要度分级投入，不在低价值首案过度制作。

## 影响范围

- 高保真首案使用内联 SVG 或等价二维插画，不依赖远程图片；
- 每个观察热点必须同时具备空间反馈和文字观察卡；
- 不能要求玩家仅凭插画辨认微观纹理；
- 证据文本成为规则与 UI 的权威事实来源；
- 写实结算讲解图进入精品、珍品内容资产待办，不计入本轮完成标准。

## 当前信心

高。该方向由用户同步团队已有讨论，并与当前周期、美术能力和文字推理核心一致。具体插画风格仍可在后续正式美术阶段迭代。

## 重新讨论触发条件

- 玩家无法通过二维视角和热点建立器物空间认知；
- 文字卡过长，导致观察反馈失去节奏；
- 后续专家内容要求必须从真实图像直接识别某类核心特征；
- 正式美术资源证明照片或 3D 能以更低总成本达到同等一致性。
