# DEC-013：V2 独立玩家试玩版与能力/客观结果双轨结算

> 2026-08-14 V2 终态：独立玩家 HTML、空白报价、后验估值、A／D／N 与客观结果双轨，以及首批手机展示壳中隐藏人物事实标签和实时接受概率已经实现；察人分 `P`、新议价高效区、人物双重提交和认知审计没有实现。未实现部分随 DEC-014 归档，只有被 V3 新 Decision 明确采用后才生效。

## 当前决定

V2 新增独立、自包含的 `掌眼_V2_玩家试玩版.html`。它不替换 V1 canonical 或既有教师演示，不包含教师指南、开发侧栏、模式开关、四阶段流程条、公式溯源或原型解释。

每局由稳定局号选择漆器、瓷器或书画案例及其案例内真相。进入交易前，玩家必须提交“最可能真相 + 55%/75%/90% 置信档位”；提交后调查锁定。玩家报价保持空白，不再由系统提供 Q20 或“谨慎报价”。

玩家估值显示后验期望、Q10—Q90 和归一化后验熵。证据少首先扩大不确定区间，不再直接降低物品的期望价值。NPC 继续只读取自身认知、已共享证据与公开状态；玩家可见议价评分只读取公开要价/还价、公开人物特征和玩家估值，不读取隐藏真相或隐藏底价。

结算拆为两条互不反向修改的轨道：

- 能力评级：鉴定 `A`、决策 `D`、议价 `N`；有议价时为 `0.45A + 0.30D + 0.25N`，无议价时为 `0.60A + 0.40D`；
- 客观经济结果：真实价值、成交价、检测费用、净结果与事后错失价值，只陈述发生了什么，不产生或修改能力等级。

旧“器物品质 + 净收益 + 议价 + 判断质量”的综合成果等级，以及后验 Q20 自动参考报价，被本决定取代。DEC-004 的“主观能力与客观结果分层”原则、DEC-006 的厚尾价值与 NPC/真相分离原则继续有效。

## 选择理由

证据少不等于物品价值低；把二者混合会系统性诱导玩家低报。能力与赚亏也不能互相替代，否则好运会被写成能力，合理但失手的决策会被惩罚。显式鉴定承诺、主观后悔与公开接受概率让评分能够评价玩家当时可做出的判断，同时保留事后经济事实。

## 影响范围

- 三案例内容、案例本地真相标识、稳定局号与版本化回放；
- `AppraisalAction`、`PlayerValuation`、`AbilityBreakdown`、`ObjectiveOutcome`；
- 独立玩家 UI、单文件构建与玩家表面禁词扫描；
- 旧权威基线只比较旧字段；新增 V2 字段由新规则测试保护，不重录历史 fixture。

## 尚未证明

- 三案的文化与器物知识准确性；
- 长期经济平衡、等级阈值合理性和一般玩家趣味性；
- 真实微信、Safari、公开 HTTPS 托管与正式美术表现。
