# DEC-014：人与物双重鉴定、证据拓扑与洞察附加层

Status: Archived

日期：2026-08-11

> 2026-08-14 V2 终态说明：本决定中的手机人物／器物同屏外壳、占位人物气泡、行动模式与只读案卷已部分实现；真正的证据拓扑、双方人物认知、连续 NPC、D20、受控误导和新议价体系均未实现。V2 在这些候选落地前结束。本决定作为 V3 的历史设计输入归档，只有被 V3 新 Decision 明确 Adopt／Borrow 后才成为 V3 当前规格；详见 [DEC-015](DEC-015-v2-freeze-and-v3-bootstrap.md)。

> 以下保留 V2 当时的批准文本与措辞，用来解释历史因果，不代表 V3 已重新批准或正在实施。

## 2026-08-13 批准澄清：五个责任区与双向人物认知

用户批准用以下边界澄清本决定；它不新增两个孤立系统，也不改变“先做漆器客观真相与证据拓扑”的当前阶段：

- 原五项改称五个按依赖排列的**开发责任区**，不是五套一一对应的程序或引擎；
- 玩家认知同时包含“怎样理解器物”和“怎样理解 NPC”；NPC 认知同时包含“怎样理解器物”和“怎样理解玩家”；
- “器物双后验”继续指玩家与 NPC 对同一器物分别形成的后验；“双向人物认知”指双方怎样理解对方；“双重双后验”只作为“双方都在辨物、也都在识人”的人类可读简称，不要求四台自动概率引擎；
- 两个认知方向可以共用证据格式、可见性、更新工具、置信表达、回放和审计，但必须分开账本、可见信息和答案；
- 真人玩家的内心不由规则自动定义。玩家侧保存人物可见线索和明确提交的人物判断；NPC 侧才需要根据玩家已表现的行动维护可错的内部判断；
- NPC 对玩家的首轮判断只覆盖专业度、成交认真度和沟通策略，不建立“玩家真实人格”、善恶值或无限递归的“我认为你认为我……”；
- 器物估值、对对方的认识、局内关系状态和成交意愿必须分别记账，因此允许“更信任玩家，但器物估值上升、要价上涨、成交意愿下降”同时成立；
- NPC 纺锤是当前情境下的候选行为仲裁器；小型状态机只管理交谈、戒备、议价、离场等宏观阶段，不把所有人物参数排列组合展开成巨大状态机。

统一领域词义见仓库根目录 [CONTEXT.md](../../../CONTEXT.md)。

## 当前决定

V2 玩家试玩版的下一轮核心工程不再只是移动端界面修补，而是把体验重构为“同时面对器物与 NPC”：玩家既要根据器物证据判断真相，也要根据 NPC 的主张、表现和回应判断其知道什么、相信什么以及准备透露什么。

本决定局部修订 DEC-005、DEC-007 与 DEC-013，但不推翻其主体：隐藏器物真相继续与 NPC 认知隔离；能力评级继续与客观经济结果分开；A／D／N 权重暂时不变。

### 玩家界面与任务层级

- 主基线为 `390×844` 手机竖屏；调查和议价均保持器物与 NPC 同场，而不是进入无人物的计算器页面；
- 器物位于左侧前景，NPC 半身立绘位于右侧；回复使用锚定人物的漫画气泡。正式美术未就绪时使用中性矢量占位，并预留姿态、表情与说话状态；
- 检查放大时器物成为主体，但保留窄幅 NPC 轮廓及即时回应；
- NPC 正文不低于 16px，主要触控目标不低于 44px；拒绝、还价、接受和离场均必须有角色化台词与视觉反馈；
- 不再把“急售、诚意、谨慎、戒备”等隐藏人物事实写成玩家标签。玩家只看到入场动作、措辞、停顿、视线、姿态、回应速度和还价方式；同一表现必须允许至少两种隐藏原因；
- `细看／询问`是行动模式，`案卷`是默认关闭的只读抽屉，`形成判断`是独立提交动作，不再组成四个平级流程；
- 案卷包含证据／推理图、带关联洞察记录的对话历史、参考知识；关闭后恢复原场景与上下文；
- 顶部不再出现“来客／查验／交易／复盘”流程条、教师或开发说明、公式溯源及原型解释。

### 四层信息与双重推断

规则明确区分：

1. 器物事实证据：观察或检测得到的事实；
2. NPC 事实主张：NPC 实际说出的命题；
3. 可观察表现：语气、动作、停顿等多义信号；
4. 洞察观察：成功检定后追加的、不直接定罪的观察。

玩家侧同时拥有器物推断与人物判断两条账：器物后验可以根据玩家可见证据计算；人物侧保存可见表现、洞察观察和玩家明确提交的判断，系统不得把参考推断冒充为真人玩家内心。NPC 主张不能再以作者指定的行为似然直接乘入器物后验；它必须先经过 NPC 知识、可信度和披露意图判断，再与器物证据共同推断。洞察只更新人物判断，不直接改写真伪。

NPC 的行为、台词、报价和底线不得读取隐藏器物真相或玩家未表现的内心状态。共享的客观证据双方都不能否认，但可以因专业度和既有认知而作出不同解释。

### 三张证据图

案件将分别配置：

1. 获取／解锁图：什么前置观察、知识或对话让某个行动可用；
2. 推理图：前提、中间结论、AND／OR／`atLeast` 条件、并行佐证与反证；
3. 对话披露图：当前话题、已公开证据和人物情境如何解锁追问及回应。

公共条件接口采用 `node / all / any / atLeast`。验证器必须拒绝循环、缺失引用、不可达节点和没有完整证明路径的案例。依赖感知的精确枚举／小型因子模型替代同源线索的朴素连乘。

- 每个真相至少有一条纯器物路径和一条器物＋对话混合路径；不允许纯对话闭合器物真相；
- 单一操作、单次检测或单条台词不能独立闭合真相；
- 纯器物路径约消耗 5—6 AP，混合路径约消耗 4—5 AP，但公开证据可能反向教育卖家并影响价格；
- 每案目标为 8—10 个有意义的可检查位置，使用分层放大热点，并提供等价文字入口；
- 专项检测是强终端证据，但缺少根部或独立前提时不能单独闭合；
- 证据图框架在参考簿中预先可见，案例节点随调查揭示；完成有效路径允许提交 90% 置信，但局末前不直接揭示真相。

### NPC 知识、连续对话与受控误导

新增计划接口：

- `NpcScenarioDefinition`：坦率、选择性披露、潜在误导等人物情境；
- `NpcKnowledgeLedger`：NPC 已知命题、私人观察、信念与置信度；
- `NpcUtterance`：内部记录所表达命题、NPC 对命题的认知关系和披露意图；
- `PerformanceCue`：玩家实际可见的语言与动作表现；
- `NpcAppraisalAction`：玩家对 NPC 知识程度、披露倾向和置信度的提交。
- `NpcPlayerModel`：NPC 仅根据已观察到的玩家行为，对玩家专业度、成交认真度和沟通策略形成的可错临时判断。

对话采用确定性的“主题入口＋上下文追问”作者图，不使用 LLM 或自由文本。NPC 无论洞察成败都必须完整回复；询问用于验证主张、取得来源信息、理解人物和影响谈判，不得无因果依据地直接改写器物真相后验。NPC 对玩家的判断可以影响关系、注意方向和行为候选，但不能证明玩家善恶，也不能直接改写器物真相。

只有 NPC 对某命题具有高置信自身信念，却有意作出相反断言时，才属于蓄意误导；知识不足导致的错误只能记为误判。首轮仅瓷器二道贩子提供坦率／选择性披露／潜在误导三种独立情境，且人物情境由稳定种子独立选择，不与器物真相绑定。漆器与书画首轮不加入蓄意误导。

### D20 洞察附加层

- 每案设置 3—5 个作者标记的高杠杆机会，自动触发、每个机会一次且不消耗 AP；
- 默认公式为 `d20 + 2 >= DC`，DC 分为 10／12／14；
- 相关已共享证据或案卷中已经记录的矛盾给予优势，掷两颗 d20 取高值；优势不叠加；
- 自然 1／20 不自动失败或成功；
- 玩家看到骰面、修正值、DC 和成败，可跳过动画；减少动态效果时直接显示结果；
- 成功追加诸如“她先重复了一遍问题，才回答落款来源”的暧昧观察，不显示“正在说谎”或四状态数值；
- 失败只表示没有形成可靠额外判断，不生成虚假确定结论，不删除正常回复或核心线索；
- 稳定骰由 `seed + opportunityId` 复现；开发调试支持 `normal / forceSuccess / forceFailure`、修正值覆盖和 DC 偏移，但这些控件不得进入玩家 HTML。

长期洞察 build、重掷资源和角色成长不在首轮范围；当前只保留可局外调参的修正值、DC 和模式。

### 行动资源、鉴定、议价与评分

- 调查共享 8 AP：集中检查 1，有效询问／追问 1，专业检测 2＋费用；洞察、提交判断和终局交易 0；
- 交易前依次提交器物真相＋55%／75%／90%，NPC 知识程度、NPC 披露倾向，以及人物判断共享置信档；提交后锁定调查；
- NPC 知识轴为“有限了解／掌握部分关键线索／掌握核心情况”，披露轴为“坦率／选择性披露／误导”；
- 正式报价包含金额，以及一条可选的已共享证据理由；NPC 必须以人物台词和表现回应；
- 玩家过程中不显示精确或定性接受概率。议价评分在局末使用规则集公开先验和已发生的公开回应建立基准，不读取隐藏真相、隐藏底价或当前 NPC 隐藏画像；规则不得通过解析中文表现文案取得参数；
- 议价分 `N` 使用宽容高效区：玩家报价效用达到同轮公开最优效用的 90% 即得满分；局末展示高效区而非唯一最优金额；
- 察人分 `P` 分别对知识轴与披露轴计算三分类 Brier 校准分后取平均，单列显示，首轮不进入总分或封顶；
- A／D／N 总评保持 DEC-013：有议价 `0.45A + 0.30D + 0.25N`，无议价 `0.60A + 0.40D`；
- 鉴定分的证据结构改为图闭合：无支持 0、只有前提 50、形成中间结论但路径不完整 75、一条完整路径 90、完整路径加独立交叉支持 100；校准仍占 75%，结构占 25%；
- 决策分继续使用当时玩家可见后验、主观效用和以 `max(10, Q90-Q10)` 归一的后悔值；
- 客观经济结果继续单列真实价值、成交价、费用、净结果和事后错失价值，不反向修改能力评级。

### 种子、回放与版本边界

`createSeededSession` 使用不同稳定键分别选择案例、器物真相、NPC 情境、允许事件和洞察骰，避免变量意外绑定。回放新增 `npcScenarioId`、规则／案例／洞察配置版本、NPC 鉴定提交、完整 NPC 台词、表现、洞察记录和图节点变化。

旧 V2 回放若版本不兼容，应明确标记为历史规则并拒绝载入，不建立第二套并行生产权威。V1 canonical、教师版和历史证据完全不变。

## 实施检查点

1. 文档、Challenge、Decision、Evidence、当前页面哈希和两张手机基线截图；不改产品；
2. 漆器手机同屏场景、NPC 占位立绘、漫画气泡、正确任务层级与案卷外壳；提交 390×844 状态截图给用户确认；
3. 漆器客观真相与证据拓扑；同时标注谁能看见、能否共享、公开该信息会向对方暴露什么，但不在本批计算人物认知；
4. 玩家认知：接入器物推断、人物可见线索和玩家明确提交的 NPC 判断，不把系统参考值展示成玩家内心；
5. NPC 认知：接入器物知识账本和 `NpcPlayerModel`，只读取 NPC 实际看见的证据与玩家行为；
6. NPC 底层画像：用少数完整人物包定义能力、目标排序、风险态度、处境和互动敏感性，先验证同一证据下两种不同但合理的反应；
7. NPC 局内状态与行为：分开关系状态、成交意愿、宏观阶段状态机、纺锤仲裁和 Storylet，形成连续对话与人物化议价；
8. 上述因果链稳定后再接入 D20、宽容议价效用区、器物＋人物双重提交与局末认知审计；
9. 移植瓷器与书画案例，完成三案、回放、单文件与全量验证；
10. 更新项目记录；是否 commit、push、merge 或部署继续需要独立授权。

每个视觉检查点在继续下一批前由用户查看真实 390×844 截图。自动测试或无溢出不等于视觉、交互或趣味性获批。

## 背景和问题

当前试玩版的器物估值和双轨评分已修复“证据少就低估价值”的错误，但 NPC 仍主要是公开标签、一次性引语和价格参数。检查与询问在数值职责上明显分化，证据又没有真正拓扑；直接叠加立绘或 D20 只会美化错误模型。

用户希望完整体验由“古董证据链＋连续深度对话＋DND 式洞察＋议价＋古董题材”构成，同时明确要求先查证而不是把灵感直接当成事实。只读审查和外部研究支持把洞察限制为附加信息、把必要线索从随机门槛中移出，并把证人可信度与器物真相分开建模。

## 考虑过的替代方案

1. 只修手机布局和 NPC 字号；
2. 保留平铺证据，但为每次互动增加 D20 和真假提示；
3. 先重建证据、人物认知和显示边界，再逐案接入表现、洞察和议价。

## 选择理由

第三种方案能保留确定性回放、器物双后验与证据优先原则，同时以双向人物认知增加人物戏剧性。多义表现避免“看一眼表情就定罪”，而三图分层避免把线索取得、逻辑成立和 NPC 是否披露混成一个不可维护系统。分批以漆器为竖切能在扩写三个案例前暴露手机任务流和内容成本。

## 影响范围

- 玩家 UI、NPC 投影、调查／对话／议价动作和统一案卷；
- 案件内容类型、证据推断、人物知识、种子和回放；
- 鉴定结构分、议价分与新增察人分；
- DEC-005、DEC-007、DEC-013 的局部修订；
- 三案固定回放、分布、手算评分、HTML 禁止表面和多视口验证。

## 当前信心

系统边界为高，具体人物文案、证据内容和最终数值为中低。边界已经过代码审查、外部资料和用户逐项确认；文化准确性、内容制作量、长期平衡和真人趣味仍未验证。

## 重新讨论触发条件

- 首个漆器切片无法在 12—18 分钟内提供至少一条纯器物路径和一条混合路径；
- 玩家把表现或洞察稳定误读为“系统已告诉我真假”；
- NPC 情境与器物真相发生统计绑定或行为读取隐藏真相；
- 连续对话和证据图的内容成本超出剩余周期；
- 察人评分、议价高效区或 8 AP 产生明显支配策略；
- 文化专家校订改变真相、证据语义或可成立的证明路径；
- 用户改变手机同屏人物／器物的关键体验方向。
