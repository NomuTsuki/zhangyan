# DEC-017：V3 第一切片采用阶段主张、手动停手与单次一口价挂牌

Status: Active

日期：2026-08-14

## 当前决定

V3 图上的中间节点采用**鉴定主张**语义：它是能够被本局已取得证据支持、削弱或反驳的命题，可以与其他主张形成粗细包含、互斥、替代和汇合关系。此前讨论中的“节点 2／4”只用于解释，不是正式拓扑编号、固定流程或全局阶段数。

玩家开局已经持有器物。玩家通过选择调查方向、放弃其他方向以及决定何时停止，和确定性规则共同形成本局证据账本；系统根据该账本派生当前最可辩护的阶段主张和本局证据估值。系统不读取真人玩家未表达的内心判断，也不让玩家靠自报高档主张直接改变估值。

阶段主张成立是一个可以平庸获胜并主动停手的检查点，不自动结束游戏。玩家可以继续补齐更细主张；若继续调查后没有建立更高主张，仍可回到此前稳定主张收手，但已花费的行动机会和检测费用不退。首切片取消器物物损：所有调查消耗调查机会，专业检测另付金钱；器物品相不因调查按钮改变。

玩家选择停止时，系统冻结 `FrozenInferenceSnapshot`，至少包括本局证据、阶段主张状态、剩余不确定性和本局证据估值。该估值只描述“在本局已经取得的证据下，系统现在能够为怎样的价值判断负责”，不是客观真值、市场接受区间、成交保证或玩家挂牌价。

停止后进入单一固定渠道的**一口价挂牌**：

- 系统只展示冻结的本局证据估值；
- 玩家自行提交一个挂牌价，可以高于、低于或落在系统估值内，系统不设硬上限；
- 每局只有一次挂牌和一次市场结算，不允许改价重试；
- 首切片不提供主动长期持有玩法；挂牌期满未成交时器物仍归玩家，但本局没有后续调查或再次挂牌；
- 内部与玩家文案使用“成交／挂牌期满未成交”，不把固定价挂牌未成交称为“流拍”。

市场结算与本局推理严格分离。市场读取固定客观真相、固定渠道的市场模型、玩家挂牌价和可复现 seed，不读取系统估值。由此允许：系统区间内仍未成交、系统区间外仍成交、玩家低估后快速成交或高估后卖不出去；这些差异在局末用于并列说明推理质量、报价选择和客观结果，不能互相改写。

首切片保留最长 60 秒的挂牌反馈压缩：`0—20s` 表示明显低于市场预期、`20—40s` 表示处于市场预期内、`40—60s` 表示偏高但仍可接受、满 60 秒表示挂牌期满未成交。分档结果由客观市场规则确定；档内具体秒数只允许使用固定 seed 做表现变化。60 秒和三等分是玩家反馈节奏，不是假装现实古董市场会在一分钟内完成交易；其可玩性仍需后续验证。

市场结果出现后，局末才揭示完整客观真相、作者完整拓扑和玩家本局路线叠图，包括已发现、错过和主动放弃的分支；不标注唯一最优路线。首切片不设置取得成本或传统利润口径，经济结果至少并列展示实际成交金额、调查／检测成本与价值实现程度；未成交表示没有实现现金、成本已经支付、器物仍保留。

## 为什么这样决定

这套闭环让三种责任保持分离：

1. 系统为本局证据推理负责；
2. 玩家为调查路线、停手时机和挂牌价负责；
3. 市场按客观真相与市场条件给出结果。

因此赚钱不能自动证明判断好，亏钱也不能自动推翻当时合理的推理。玩家继续调查的代价来自已经花掉的机会和费用，而不是为了制造惩罚而永久损坏器物。

## 考虑过的替代方案

1. 达到阶段主张后自动结束；拒绝，因为会移除玩家的停止决策。
2. 玩家自报主张或报价直接决定可实现价值；拒绝，因为高报会成为支配策略。
3. 系统估值同时充当市场接受区间；拒绝，因为会把本局推理、客观真相与经济结果合并。
4. 同局允许改价或重复挂牌；首切片拒绝，因为会稀释一次性经济承诺。
5. 调查同时产生永久器物损伤；首切片拒绝，相关代价统一进入调查机会和检测费用。
6. 结果前展示完整拓扑或市场真实价值带；拒绝，因为会提前泄露真相与成交答案。

## 对既有记录的影响

- 解决 [DEC-016](DEC-016-v3-design-stage-bootstrap.md) 中“中间节点语义”和“第一切片经济终局”两个 Unknown；其余 V3 启动边界继续有效。
- [定量真相、信息价值与收手研究](../evidence/v3-design/2026-08-14-quantitative-truth-value-of-information-and-stopping-research.md) 中“物损可以作为首切片状态变量”的候选不采用；价值分布、信息价值和手动收手原则继续作为研究依据。
- V2 的玩家手填 `appraise`、NPC 议价、Q20 参考报价、取得成本和综合成绩不自动进入 V3。本决定只 Borrow 后验估值、双轨结果与确定性回放的结构。

## 影响范围

- 第一张纸面拓扑必须能标出阶段主张、证据依赖、稳定停手点、继续调查费用和回退关系；
- 后续状态模型需要分开保存客观真相、证据账本、主张投影、本局估值、玩家挂牌价与市场结果；
- 玩家界面在结果前不得显示完整作者图、客观市场价值带或预测成交秒段；
- 局末需要并列而非合并展示推理快照、玩家挂牌、市场结果和完整路线；
- 具体阶段概率门、估值区间摘要和市场接受宽度另由 Experimental 数值决定与纸面／模拟／真人验证处理。

## 当前信心

产品语义高：用户已经逐项确认阶段检查点、手动停手、成本保留、取消物损、系统估值／玩家挂牌／客观市场三轨分离、单次挂牌、60 秒结果顺序和局末完整揭示。

具体数值与可玩性低至中：尚无第一张纸面拓扑、策略枚举、移动端表现原型或无答案玩家证据。60 秒节奏和市场接受带不能由本决定自证好玩或真实。

## 重新讨论触发条件

- 第一张纸面拓扑无法形成至少一个可信阶段停手点和一个有代价的继续分支；
- 系统估值被玩家稳定误解为市场保证，或挂牌价只报区间上沿成为支配策略；
- 75% 等阶段门、估值摘要或市场宽度的模拟暴露严重跳变、锁死或无差异；
- 无答案玩家无法分辨“系统估值”“玩家挂牌价”和“客观市场结果”；
- 60 秒等待只形成空耗、焦虑或可跳过动画，而没有承诺感；
- 用户改变首切片的持有、出售渠道、重试或物损边界。
