# DEC-018：V3 暂定阶段阈值、证据依赖与估值投影政策

Status: Experimental

日期：2026-08-14

## 当前决定

V3 第一张纸面拓扑使用一套**可追溯、可回退、尚未验证玩法表现**的数值政策。它只把研究结论收敛成可以演算的默认值，不把任何百分比称为现实古董鉴定标准，也不授权产品代码实现。

### 1. 阶段主张的唯一概率来源

真相包后验 `P(h|E)` 是本局概率的唯一权威。粗主张 `C` 的支持度为所有能推出该主张的真相包后验之和：

`P(C|E)=Σ_{h⇒C}P(h|E)`

主张状态只读地从后验、当前局证明规则和反证规则派生；它不拥有第二套概率，也不反向修改后验。

### 2. 首轮进入、保留、质疑和退出

- 普通主张首次进入 `established` 的默认后验赔率为 `3:1`，即 `support≥0.75`；同时必须通过作者为该主张声明的本局 `proofRule`，并且没有未解决阻断反证；
- `3:1→75%` 只表示首轮暂把“错误建立”的体验损失看作“错误延后”的 3 倍，不是现实行业常数；不按拓扑深度自动加门槛；
- 开局先验不能单独建立主张；本局必须实际取得 `proofRule` 所需的证据；
- 主张建立后，只要 `support≥0.50` 且未被硬逻辑反驳，就保留该阶段锚点；这里首轮暂把“错误保留一个已失效锚点”和“错误丢弃一个仍成立锚点”的损失设为 `1:1`，派生 `50%` 退出线。它只是迟滞校准默认，不是现实标准；
- `contested` 是叠加状态，只由未解决硬反证、必要证明冲突或证明有效性争议触发，不设 `60%` 或其他全局自动质疑线；
- `support<0.50` 或硬逻辑反驳时退出当前锚点，落回最近仍成立的父级／粗级主张；重新进入必须再次达到 75% 并通过证明与反证门。

### 3. 证据依赖先于结构检查

- 每个观察用唯一 `observationId` 保证只更新一次；
- 共享来源、痕迹、仪器或推断前提的观察归入 `inferenceUnitId`，通过联合似然、共同潜变量或证据组级更新处理；
- `proofRule` 用于表达本局必要维度、替代证明组和反证关系，不能补救已经发生的朴素独立相乘；
- 不设全局“至少两条／两组证据”或“领先竞争者 15 个百分点”默认。第一器物按真实证据关系逐主张配置。

### 4. 估值一般式与职责边界

固定市场上下文 `M` 下，本局证据估值使用：

`p(V|E,M)=Σ_h p(V|h,E,M)P(h|E)`

只有真相包已穷尽全部价值相关属性、且给定 `h` 后新证据与价值条件独立时，才简化为 `Σ_h p(V|h,M)P(h|E)`。

因此，阶段没有升级时，证据仍可以改变真相包权重，或改变同一真相包内部的修复程度、品相等价值分布。阶段跨越改变的是系统报告映射 `f` 的主要锚点，不是给价值 `y` 乘系数。

- 不存在 `stageMultiplier`；
- 价值分布是非负分布，可包含零实现价值点质量；不强制一种全局分布族；
- 调查机会和检测费用只进入成本与局末结果，不从器物估值中扣除；
- 系统估值不读取隐藏客观真相、玩家挂牌价或未来市场结果；
- 市场结算不读取系统估值。

### 5. 首轮玩家估值投影

- 后台保存完整分布，不只保存一个上下界；
- 当前已经建立主张的主要报告使用 **50% 最高密度区域**，明确命名为“若当前阶段判断成立时的典型价值带”；多峰时允许拆成多段；
- 完整本局证据混合的 **80% 最高密度区域**作为次级证据摘要，也允许多段，不能称为市场接受区间或全部可能范围；
- 一个独立高价值情景若有本局直接证据支持且后验质量至少 **5%**，即使未进入 80% 摘要也单独显示；这只是首轮 UI 降噪值；
- 玩家首层最多同时看到 **3 个**价值情景，后台不删除其余分支；
- 阶段跨越只改变主要情景、标题、顺序和强调层级，其他情景与反证仍保留；
- 条件典型带旁必须同时给出阶段文字、支持理由和仍未解决的反证。普通玩家默认不显示精确后验进度条，作者／调试视图保留完整数值。

这套投影明确拒绝用 `Q90` 或 `Q95` 机械触发上探，也拒绝用一条连续区间跨过多峰分布中的低概率空谷。

## 选择理由

这套政策把用户提出的两种变化分开：

1. **连续或平滑更新：** 新证据改变真相包后验以及真相包内部价值分布；
2. **阶段性跳变：** 一项主张达到建立条件后，系统改变主要报告锚点和信息层级。

所以跳变是“系统现在愿意为什么判断负责”的变化，不是凭空抬高价格。微弱证据也可以在阶段升级前形成较弱的高价值情景。

同时，迟滞只保护已经取得的阶段成果，不掩盖反证：50% 是概率退出线，`contested` 则由可解释的反证语义触发。这样避免把数值边界闪烁误装成真实鉴定过程。

## 明确拒绝的继承与候选

1. V2 的 `55%／75%／90%` 是玩家手报置信档，不是 V3 系统后验阶段线；
2. V2 的平铺似然朴素相乘不能处理同源证据依赖；
3. V2 的 `Q10–Q90`、Q20 保守报价、费用扣减和 8% 重估触发不进入 V3；
4. 早期研究候选 `60% contested`、全局两组证据、15 个百分点竞争领先、70%／90% 连续双层区间，经独立反例审查后不采用；
5. 不把 60 秒挂牌分段说成现实古董市场规律；它只是一局结果反馈节奏。

## 当前验证状态

**已证成的只是结构边界：** 损失不对称会改变决策阈值；相关证据不能朴素独立计权；后验混合可以多峰；单一分位区间可隐藏小质量高值分支或跨越概率空谷；估值不等于实际成交。

**尚未验证：** 75%／50% 的节奏，50%／80% 两层摘要，5% 情景可见线，最多 3 个情景，第一件器物的证据与价值参数，以及任何趣味、公平、支配策略和玩家理解结论。

## 下一证据与重新讨论触发

下一步先把参数放入第一张完整器物纸面拓扑，做确定性场景枚举；不直接写产品代码。随后另行披露并批准 Critical 模拟／试玩合同，至少检查：

- 极端先验、重复／相关证据、必要证据缺失和硬反证；
- 阶段建立、质疑、退出、回退和重新进入轨迹；
- 同阶段组件内价值移动与低质量高值情景；
- 多峰价值的分段显示；
- “首阶段就停、永远追尾、固定报典型带上沿、固定报证据摘要上沿”四类候选支配策略；
- 玩家能否区分系统估值、玩家挂牌和客观市场结果。

出现下列任一情况时重开相应参数，而不是重开已批准的三轨职责边界：

- 阶段长期建立不了、过早建立、反复闪烁或过久不退；
- 高价值情景长期被隐藏，或反过来诱导玩家无条件追尾；
- 条件典型带被稳定理解为市场保证；
- 移动端最多三个情景仍过载或丢失关键不确定性；
- 第一拓扑的文化／物证结构无法用当前 `proofRule` 表达。
