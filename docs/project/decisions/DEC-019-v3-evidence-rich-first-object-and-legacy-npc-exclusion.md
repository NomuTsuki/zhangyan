# DEC-019：V3 第一器物按证据拓扑承载力筛选，并停止继承旧内容壳与 NPC 逻辑

Status: Active

日期：2026-08-14

## 当前决定

V3 第一切片不再预设漆器，也不沿用 V2 的“民国漆木首饰盒”作为默认内容壳。第一器物先按它能否承载完整玩法来筛选，再决定具体品类、年代、地区与个案：它应提供多个可检查方面，允许证据依赖、替代／恢复路线、阶段性鉴定主张、同一身份内的状态／修复／品质价值分叉，以及有意义的继续调查或收手选择。

漆器仍可作为候选，但只能与陶瓷、钱币、钟表、绘画／书法、金属器等其他候选一起接受来源与玩法适配审查，不能因为 V2 做过漆木盒就获得优先权。

V2 的漆木盒名称、固定三真相、五个观察热点、旧物证、似然、价格、行动预算和卖家内容停止向 V3 继承。V2 可运行、可回放的技术底座仍按 DEC-015 保留；任何内容或机制只有被 V3 新 Decision 明确 Adopt／Borrow 后才进入当前规格。

V2 的 NPC 认知、底层画像、局内关系状态、连续对话、说谎／洞察、D20、议价、人物评分与 NPC 行为仲裁不属于 V3。若未来第一器物需要来源材料，它只能先作为固定文档、标签、照片或其他可核验的器物证据进入；不能借此恢复 NPC 认知或对话系统。上述人物系统若未来重开，应属于 V3 之后另行批准的项目范围，而不是 V3 停放功能。

## 背景和问题

此前“第一漆器”和旧胎／重修例子帮助团队讲清事实、鉴定主张、候选真相、同阶段价值移动与停手，但它们没有经过漆器领域取证，也从未被批准为第一器物的正式真相包。继续沿用会让纸面拓扑为旧内容服务，并可能把 V2 的 NPC 与议价依赖带回 V3。

用户在第一纸面拓扑启动门明确选择“重新选器物”，并补充：器物类型不是目标，能够承担多检查节点和已经批准的推理／停止逻辑才是目标；旧壳应停止，V2 中许多 NPC 逻辑不应出现在 V3。

## 考虑过的替代方案

1. 沿用漆木首饰盒与旧胎重修冲突，只重做证据和数值；拒绝，因为内容壳本身会继续约束设计，并给未查证的 V2 事实不必要的惯性。
2. 沿用漆木盒但简化成现代仿制／旧物二分；拒绝，因为容易退化成单一决定性检测和真假填空题。
3. 开放器物类别，先做证据拓扑承载力筛选，再由用户批准最终器物；采用。

## 选择理由

先筛选器物可以让内容服从玩法需要，而不是让玩法合理化旧素材。它也能更早暴露候选是否只能依赖一项专家检测、是否缺少替代路线、是否无法在同一身份下产生价值差异，或是否必须依靠 NPC 口述才能成立。

停止继承 NPC 逻辑则让 V3 保持为一款能够独立完成的“识物”游戏：玩家与确定性系统围绕固定器物真相、证据和市场后果作出选择，不需要人物模拟替未完成的器物结构提供复杂度。

## 影响范围

- `第一器物` 取代 `第一漆器` 成为当前规范用语；用户随后选择陶瓷／瓷器，并由 [DEC-020](DEC-020-v3-first-ceramic-object-and-core-dispute.md) 批准 Hong Bowl 修复史的虚构类比结构与核心争议；该决定当时尚未补足真相包，后续 [DEC-021](DEC-021-v3-first-ceramic-objective-truth-package-and-gameplay-first-authorship.md) 已向前固定作者客观真相；
- 第一纸面拓扑暂停起草，先形成候选器物筛选研究；研究只能推荐，不能自动批准最终器物；
- DEC-016 中“NPC 方向可能在申请季后作为 V3 后续重开”的口径被本决定替代；其物品侧优先、V2 冻结与 V3 Design 边界继续有效；
- DEC-017 的阶段主张、手动停手、单次挂牌与三轨结算继续 Active；DEC-018 继续 Experimental；
- V2 的 NPC 相关 Decision 与代码只保留历史／冻结证据身份，不构成 V3 backlog；
- 项目罗盘、系统图、当前状态、下一行动、领域语境和 overview 需要移除“第一漆器”默认与“NPC 在 V3 停放待重开”的当前态表述。

## 当前信心

范围边界高：用户已经明确选择重新选器物、排除旧壳与 V2 NPC 逻辑，并选择陶瓷／瓷器作为当前研究家族。候选研究已经完成，用户随后通过 DEC-020 批准 Hong Bowl 修复史的虚构类比结构与核心争议，并通过 DEC-021 的直接确认／委托边界形成作者客观真相包。移动体验、文化准确性、玩法与市场数值仍未验证。

## 重新讨论触发条件

- 用户明确要求某项 V2 内容或 NPC 系统进入 V3；
- 所有非漆器候选都无法同时满足领域准确性、证据拓扑与交付成本，而漆器出现明显更优的来源基础；
- 第一器物的完整证据链必须依赖一个可互动人物而无法改写为固定、可核验来源；
- 候选筛选标准无法区分“资料很多”与“能形成有选择的一局”。
