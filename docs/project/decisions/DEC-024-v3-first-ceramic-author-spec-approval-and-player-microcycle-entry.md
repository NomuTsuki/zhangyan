# DEC-024：批准第一陶瓷切片作者规格并进入玩家知识工作台微循环

Status: Active

日期：2026-08-21

## 当前决定

用户批准第一陶瓷切片当前冻结的作者侧体验与边界，允许它作为玩家知识工作台微循环的输入。

批准对象是：

- [三档作者模型 v0.3](../evidence/v3-design/2026-08-21-first-ceramic-three-result-author-model-v0-3.md) 所定义的客观候选、G1—G3、档案关系与领域能力边界；
- [具体一局 v0.1](../evidence/v3-design/2026-08-21-first-ceramic-concrete-session-v0-1.md) 所展示的纯物证 G2、G2 后深档案软转折、继续／停手与经济终局；
- [确定性作者侧场景演算 v1](../evidence/v3-design/2026-08-21-first-ceramic-deterministic-author-scenarios-v1.md) 保存的首轮 Fail、修复与最终独立 `40/40` Pass；
- [限定领域复核闭环 v0](../evidence/v3-design/2026-08-21-first-ceramic-limited-domain-review-closure-v0.md) 对检测能力和档案关系的收窄。

上述文件保持冻结，不因本决定改写其字节或验证哈希。用户批准是单独的阶段事件，不反向把结构 Pass 扩张成玩家、趣味、数值、实物可达性或产品实现 Pass。

下一责任区切换为玩家知识工作台微循环：用同一段已批准内容制作两至三个低保真表达分支，比较事实、当前解释、开放问题、调查方向和按需粗概率怎样组织。系统整理玩家已知内容，玩家保留关注、判断、继续与停手责任；作者完整图、隐藏证明门、精确边权和唯一最优动作不进入局中投影。

## 2026-08-23 后续澄清

上段“唯一最优动作不进入局中投影”继续约束常驻地图、普通提示以及读取隐藏真相的唯一通关路线。后续 [DEC-026](DEC-026-v3-progressive-player-knowledge-map-and-current-best-hint.md) 只在玩家主动请求的最强帮助层开放一个按**本局当前已知信息、可用资源与成本**计算的当前最优调查；它不是作者答案，也不保证结果。该澄清不改变本决定批准的作者规格或产品代码开工门。

## 批准不包含

- 具体 UI 布局、视觉风格、组件或最终交互；
- 概率采用区间、十格图还是近似百分比；
- 真人测试参与者、样本量、通过线或测试执行；
- DEC-018 的 Experimental 数值、市场参数或正式平衡；
- 正式产品代码、V2 技术继承、Git 推送、部署或发布。

## 选择理由

- 作者合同已经完成静态结构、确定性执行和限定领域映射三类不同检查，可以安全地成为玩家投影的固定输入；
- 冻结作者输入后再比较玩家表达，能把“作者规则错误”和“玩家没看懂”分开诊断；
- 单独记录用户批准可以保留已验证文件的哈希与失败史，不用为状态变化重写证据；
- 先做微循环而不是整局，能更早发现系统是否替玩家推理、提示是否泄题，以及确认操作是否只是空按钮。

## 当前信心

高：作者侧结构和进入玩家微循环的权限已经明确。玩家表达是否清楚、有能动性且不泄题仍是 Unknown，必须由低保真比较和无答案真人测试回答。

## 重新讨论触发条件

- 玩家分支只能通过泄露作者槽位或隐藏门才能讲清；
- 玩家确认无法改变关注、暂存判断、行动或停手，只剩装饰性按钮；
- 玩家原型暴露作者合同中新的因果冲突、硬门或纯物证 G2 回退；
- 领域证据要求重开客观事实、检测能力或档案关系；
- 用户改变 G1—G3、开放调查、手动停手或作者图／玩家图边界。
