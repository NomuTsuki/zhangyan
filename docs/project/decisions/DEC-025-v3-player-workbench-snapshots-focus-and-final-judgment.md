# DEC-025：玩家知识工作台采用可选快照、注意力焦点与局末最终判断

Status: Active

日期：2026-08-21

## 当前决定

玩家知识工作台负责自动整理本局已经取得的事实、系统当前能够辩护的解释、仍未闭合的问题和可用调查方向。玩家不手工搭图，也不需要在每次调查后确认系统更新。

玩家可以在任意时刻保存一份中途快照。快照只记录两件事：

- **当前倾向**：从系统根据当前证据列出的两至三条可辩护解释中选择，也可选择暂不判断或保留异议；
- **首要疑点**：指定自己当前最想验证的问题。

首要疑点只改变事实、问题和调查方向的醒目顺序，不隐藏内容、不锁行动，也不改变系统后验。中途快照不评分，不改变提示强度、调查结果、系统估值或市场结果；玩家可以修改快照并保留历史轨迹，也可以完全不保存快照继续调查。

玩家选择收手时必须确认一份最终快照。只有这份最终快照进入判断质量反馈与局末复盘；确认最终快照仍不反向改变客观真相、系统后验、系统估值或市场结算。

## 采用理由

- 系统承担记忆与整理负担，但不替玩家决定相信什么、关注什么或何时停手；
- 可选快照让玩家在真正有判断变化时留下轨迹，避免每次探测后的强制确认退化为形式操作；
- 焦点只重排注意力，保留开放调查和直觉行动；
- 中途快照与数值后果隔离，避免玩家为了讨好评分系统而表演判断；
- 最终快照使局末复盘有一个明确的玩家承诺对象，同时不把收手变成自动结论。

## 本决定不包含

- 三个低保真表达分支中的最终布局选择；
- 粗概率使用区间、十格图还是近似百分比；
- 最强按需提示具体到问题、行动类别还是单项行动；
- 真人测试合同、通过线、正式 UI、正式产品代码、数值、经济参数或部署。

## 原型合同

首轮低保真比较必须使用同一个 G2 软转折片段，并在三种表达中保持完全相同的事实、解释、行动和信息权限。分支只能比较信息组织，不得用内容差异制造优劣。

三个分支分别是：

1. 鉴定更新流；
2. 三域鉴定台；
3. 文字摘要＋按需关系图。

该首轮合同已经历史执行并关闭：三个分支虽通过 Routine 线路检查，但随后被用户否决为核心交互方向，五个未提交原型文件已于 2026-08-22 按用户要求删除。本文继续 `Active` 的只有可选快照、注意力焦点与收手最终判断责任；三分支布局与“文字首层”不再是当前方向。

## 重新讨论触发条件

- 快照被证明只是无意义的确认按钮，玩家无法用它表达真实判断；
- 焦点排序事实上隐藏内容、限制行动或形成系统命令；
- 中途快照必须影响系统后验、提示或市场才能让循环成立；
- 最终快照阻止玩家在证据有限时凭直觉收手；
- 原型必须泄露作者完整图、隐藏证明门或唯一最优行动才能被理解。
