# DEC-026：玩家知识图采用渐进显影地图，最强按需提示给出当前最优调查

Status: Active

日期：2026-08-23

## 当前决定

V3 第一切片的玩家知识图不采用作者完整拓扑的缩略版，也不再以文字面板或 TODO 列表作为主骨架。它采用一张由本局已知信息逐步显影的**可视化进度地图**：系统负责整理，玩家从地图上看见自己已经调查过什么、哪些事实开始连通、哪些解释仍在竞争、哪里还有值得探索的未知，再自行决定调查、相信、继续或收手。

### 地图的基本语法

- **地点**承载本局已经获得信息的来源，而不是等待玩家填入的隐藏答案槽；具体地点类型由首案内容和后续原型映射决定，不在本决定中固定；
- **道路**有两种必须明确区分的状态：一是已由当前证据建立、玩家已经走通的关系；二是从已知内容伸向迷雾的探索前沿，只表示“现在有理由往这个问题继续查”，不表示隐藏关系已经成立；
- **地标**是当前证据足以辩护的局部 Finding，或 G1／G2／G3 阶段性综合判断；它们是阶段成果，不是自动终点，也不限制后续行动；
- **足迹**保存玩家实际走过的调查历史，包括有效推进、重复、阴性、不可读、未决和已被排除的路线；
- **罗盘**保存玩家的当前倾向、首要疑点或关注焦点。它只改变信息与调查方向的醒目顺序，不改变系统后验、不隐藏内容，也不锁定行动。

“器物上的物理地点”和“抽象推理关系”因此不是二选一：地点承担信息来源，关系形成道路，阶段成果形成地标，玩家历史形成足迹，注意力形成罗盘。作者图仍负责真相与证明；玩家图只投影本局已经获得、允许知道且目前可辩护的内容。

### 黑暗与显影

- 纯黑只表示“玩家尚未取得这里的任何信息”；
- 一次调查只要实际发生，该地点就不得重新变回纯黑。重复信息、阴性结果、不可读结果、区分力不足和暂时不懂其意义，都会留下持久的到访与局部显影；
- “已经看见但尚未理解”仍属于已显影、意义未定，不得伪装成未探索；具体视觉表现为 `Unknown`；
- 探索覆盖只能增加，解释的可信度则可以上升、下降、分叉或被推翻。

### 竞争解释与历史

- 当前证据仍能辩护的竞争路线同时保留在主地图上，不得因系统当前存在领先解释而删除其他仍成立的路线；领先解释是否以及怎样获得视觉强调仍为 `Unknown`；
- 新反证只按对象、区域、时间、材料层和量词作用域改变相应关系，不按“票数”抹除事实；
- 一条路线被真正排除后，可以退出当前解释层，但必须在足迹／历史层留下可回看的死路；原始事实与已发生调查不消失；
- 局中不显示 12 个作者候选世界、隐藏节点数量、真实边权、证明门或尚未被本局证据触及的作者答案轮廓。

### 第一器物的稳定 G2 地标

[DEC-027](DEC-027-v3-first-ceramic-stable-g2-and-post-g2-fallback.md) 进一步限定第一器物的地标变化：G2 由充分证据建立后保持为首案稳定的全局里程碑；后段档案关系、局部 Finding、道路和 G3 前沿仍可增强、受质疑、改道或被排除。若深挖没有形成 G3，地图保留更大的已探索覆盖、失败路线和已付成本，玩家以更丰富的 G2 收手；它不把 G2 擦回 G1。候选路线在 G2 建立前被排除而仍停在 G1，不属于阶段降级。

这项补充只固定状态责任，不决定稳定地标、死路或未形成 G3 的具体视觉表现。

### 探索前沿与逐级帮助

常驻地图只给出**问题级探索前沿**：哪里仍未闭合，以及为什么当前证据使它值得调查。前沿只能从玩家本局已知内容中尚未闭合的问题生长，不能先描出作者隐藏节点的轮廓；具体前沿类型与视觉形态不在本决定中固定。

玩家展开一个前沿时，系统可以进一步说明能回答它的行动类别。玩家仍可忽略这些方向，去调查任何当前可用的位置；前沿不是任务清单、行动门或唯一通道。

只有玩家主动请求最强一层帮助时，系统才点名一个**当前最优调查行动**：

- 它只使用本局已经取得的证据、当前可用行动、剩余调查机会和检测费用，不读取作者隐藏真相；
- 它表示在当前信念下预期净决策价值最高的可执行行动，不保证会得到正向、新颖或可读的结果；
- 结果可以是推进、重复、阴性、不可读或意外转向，取得结果后系统重新计算；
- “最优”面向当前仍需作出的判断——区分仍存解释、改变阶段判断、继续／收手或本局证据估值——并扣除调查机会与费用，不等于原始熵下降最大，也不替客观市场结果负责；
- 当前只批准上述排序原则。效用换算、具体权重、并列时如何点名一个行动、玩家已选焦点怎样限定排序范围和数值校准仍为 `Experimental / Unknown`，须在后续数值模拟合同中决定。

## 对既有决定的澄清

- DEC-023 的“系统整理、玩家确认、粗数按需、常驻方向、提示按需加深”继续有效；其中“文字首层”收窄为地图上的就地解释，文字不再承担玩家认知结构的主骨架；
- DEC-025 的可选中途快照、注意力焦点与收手最终快照继续有效；它留下的“最强按需提示到哪一层”问题由本决定解决；
- DEC-016、DEC-024 和早期研究中“唯一最优动作不进入玩家投影”的边界继续约束常驻地图、普通提示和隐藏真相唯一路线。本决定只在玩家明确请求的最强帮助层开放**按当前已知信息计算的当前最优行动**，不是作者答案或保证正确的唯一通关路径；
- DEC-018 的阶段、价值与成本数值仍为 Experimental；本决定没有批准新的权重、阈值、价格或成本。
- DEC-027 将永久 G2 降级排除在首案正常内容之外，但不删除通用系统面对真正矛盾输入时的防御性降级能力。

## 证据门分类

- **Adopt：** 信息来源地点、两态道路、地标、足迹与罗盘耦合成玩家地图；探索覆盖单调而解释可信度可逆；最强按需帮助点名当前最优调查；
- **Borrow：** 用渐进披露逐级增加提示具体度；用信息的预期决策价值而非单纯信息增益排序调查；用发现记录和空间关系帮助玩家形成自己的解释；
- **Reject：** 直接投影作者完整图、只按器物物理部位组织全部认知、只用抽象推理图／TODO 列表、常驻唯一行动箭头、读取隐藏真相的“最优解”、结果保证和只追熵下降；
- **Unknown：** 正式视觉语言、移动端布局、前沿数量、显影动效、粗概率组件、行动排序权重与并列规则，以及这一表达是否被无答案玩家正确理解并觉得有能动性。

## 选择理由

- 地图把“我走过哪里、现在知道什么、证据指向哪里、还缺什么”放在同一个可视结构中，修复旧原型把玩家变成信息中间件的问题；
- 两态道路把已经成立的关系与值得尝试的方向分开，既能温和引导，又不会把迷雾画成隐藏答案轮廓；
- 显影历史单独保存探索覆盖与解释可信度，使重复、阴性和暂时无解的检查仍然有局部效用；
- 最强提示由玩家主动请求，并按当前信息的净决策价值计算，能在玩家明确求助时真正回答“现在做什么最好”，同时不把系统当前判断冒充客观真相。

## 本决定不包含

- 新版低保真原型、正式 UI、视觉风格、美术、动效或产品代码；
- 概率使用区间、十格图还是近似百分比；
- 具体首案行动分数、权重、并列规则、调查成本或市场参数；
- 微循环真人测试合同、通过线、测试执行、V2 技术继承、Git 提交／推送、部署或发布。

## 当前信心

高：地图语义、黑暗／显影不变量、竞争路线保留、探索前沿边界和最强按需帮助的产品责任已经由用户逐项确认。中等：这些语义能否在手机竖屏上形成清楚而有审美质量的交互。低／Unknown：数值排序、具体布局、玩家理解、趣味与平衡，必须由后续原型、模拟和无答案测试分别举证。

## 重新讨论触发条件

- 玩家地图只有预先描出隐藏地点或证明门才能产生探索前沿；
- 重复、阴性、不可读或暂时无意义的调查必须被擦回纯黑；
- 显著性排序事实上隐藏仍可辩护的竞争路线或限制玩家行动；
- “当前最优调查”必须读取客观真相、保证结果、成为常驻命令，或只靠熵下降才能计算；
- 行动排序无法与手动停手、本局证据估值、调查机会和费用保持一致；
- 低保真或无答案测试表明玩家仍看不见自己的路径、误把探索前沿当答案槽，或认为系统已经替自己完成判断。
