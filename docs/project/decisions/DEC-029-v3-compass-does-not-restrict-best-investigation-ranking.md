# DEC-029：罗盘不限定“当前最优调查”的排序范围，只破平并标注越界

Status: Active

日期：2026-08-24

## 当前决定

补齐 DEC-026 未决的“玩家已选焦点怎样限定排序范围”。三条规则同时成立：

- **罗盘不进入价值计算，也不缩小排序的定义域。** 最强按需层的“当前最优调查”始终在**本局当前全部可用行动**上按预期净决策价值排序。玩家的倾向、疑点或关注焦点不改变任何行动的分数，也不把任何行动排除在候选之外。这与 DEC-026 “罗盘只改变醒目顺序、不改变系统后验、不隐藏内容、不锁定行动”是同一条边界的延伸，不是新的例外。
- **严格并列时优先点名罗盘覆盖的行动。** 这解决 DEC-026 遗留的“并列时如何点名一个行动”。只在**分数严格相等**时生效，因此不需要“接近并列”的容差，不引入任何未批准数值。并列之外罗盘对结果无影响。
- **被点名行动落在罗盘之外时，必须显式标注它不在玩家当前关注的方向上。** 系统不得静默给出一个与玩家自述焦点无关的行动，让玩家误以为那就是自己问题的答案。标注是义务；措辞不在本决定中固定。

### 推到切片验证的部分

越界标注之外，系统是否**同时**再给一条“你关注方向内的最优行动”作为第二条，不在纸上定。它的差别不在语义层——两种做法给出的排序完全相同——而在读起来是否啰嗦、是否削弱“点名一个行动”的干脆感。按 DEC-028 第二节的先例，这类问题在可丢弃切片中做变体验证。

## 背景和问题

DEC-026 第 53 行把“玩家已选焦点怎样限定排序范围”留为 `Experimental / Unknown`，`03-NEXT-ACTIONS.md` 第 16 条把它记作可玩切片的最后一项语义前置条件。

它必须在切片前定案，而不能像粗概率呈现形式那样推迟：它改变系统**说出口的内容**，属于语义层。粗概率是同一结论的不同读法，罗盘范围是不同结论。

## 考虑过的替代方案

1. **本决定（采用）**：不限定 + 严格并列破平 + 越界标注。
2. **罗盘限定范围（否决）**：最强提示只在罗盘覆盖的对象、区域或问题内排序，系统绝不替玩家改变议题。否决理由：玩家按下最强帮助的时刻，往往正是焦点已经错了的时刻——卡住的常见原因就是在错误的方向上反复投入。这个模型会在此刻静默附和错误焦点，把玩家锁死在自己的盲区里，而系统全程不吭声。它也与 DEC-026 “不隐藏内容”摩擦：虽不改后验，却收窄了提示的定义域，效果上等于对玩家隐藏了更有价值的行动。
3. **软权重（否决）**：全局排序，给焦点内行动一个加成。否决理由：需要一个权重和一个“接近并列”阈值，两者都是当前未批准的产品数值，且这个影响发生在玩家看不见的地方——玩家无法分辨被点名的行动是真的最优，还是因为自己恰好关注了它。可解释性下降换来的好处，严格并列破平已经拿到了。

## 选择理由

- 最强帮助的产品责任是“在当前已知信息下，现在做什么最好”，而不是“在你以为的问题里，现在做什么最好”；后者在玩家最需要帮助时最没用；
- 不引入任何未批准数值：严格相等是可判定的，不需要容差；
- 不扩张罗盘的既有定义。罗盘仍然只管醒目度与破平，不管价值；
- 越界标注把“系统认为你可能看错了方向”这件事交回玩家判断，而不是由系统代为决定议题——与“证据≠结论”“玩家手动停手”同源；
- 唯一被牺牲的是干脆感，而那是表达问题，切片里看得见。

## 影响范围

- 关闭 DEC-026 第 53 行的焦点作用域未决项，并顺带关闭其“并列时如何点名一个行动”未决项；
- 不改变 DEC-026 的罗盘定义、地点／道路／地标／足迹语义，也不改变 DEC-028 的地标汇合语义；
- 使 `03-NEXT-ACTIONS.md` 第 16 条完成，可玩地图切片不再有未决的语义前置条件；
- 不批准：效用换算、具体权重、行动分数、调查费用、正式 UI、美术方向、产品代码、真人测试执行。DEC-026 与 DEC-018 中这些项仍为 `Experimental / Unknown`。

## 当前信心

中等偏高（语义层）。三个模型的取舍由 DEC-026 已批准的边界和“玩家求助时焦点常已出错”这一结构性推论支撑，不需要数值即可判定。

低／未验证（体验层）。越界标注是否被玩家读作“系统在纠正我”而产生被支配感、一条还是两条读起来更好、标注措辞是否引发误解，全部**待真人验证**，只能由无答案测试举证。

## 重新讨论触发条件

- 无答案测试表明越界标注让玩家感到被系统支配或被否定，而不是被提醒；
- 严格并列在实际内容中几乎不发生，使破平规则成为空文（此时“并列时如何点名”需要另一个答案）；
- 玩家把罗盘理解成“我要系统只看这里”的过滤器，因而认为标注是系统不听话；
- 出现无法在不引入权重的前提下表达的焦点语义需求；
- 全局排序在实际行动规模下无法在合理时间内计算，被迫用焦点剪枝。
