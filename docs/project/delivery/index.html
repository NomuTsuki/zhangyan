从观察一只碗，到形成自己的判断

一件虚构外销瓷大碗的鉴定工作台。旋转器物，选择调查，沿着逐渐接通的知识地图回查依据，再决定是否带着剩余未知收手。

打开鉴定工作台 ↗试玩说明与演示路线电脑浏览器 · 本地打开 · 无须安装

先自由走一小段

  1. 拖动器物旋转，朝向你的部位会显示调查入口。
  2. 点入口查看方法。查看免费，执行“做这一步”才占一次调查机会。
  3. 看新材料飞入地图，等镜头拉回，观察道路接通了哪里。
  4. 点信息、道路或右侧判断，回看它的依据；是否继续调查由你决定。

要快速检查本轮修订，可在“表面”先做试窗，再做区域综合。完整示范路线包含结论，放在单独的说明文件中。

这一版的范围
