## 三分钟收尾复测

变化：区域综合先取得试窗记录，完成后可回查点位材料；取消选择保留已有调查提示。
本页对应 2026-09-12 构建，基于已推送的 `14a54a2`，本轮尚未再次提交。
对照旧版：此前开局可直接综合并扣费；完成调查后也可能再次显示开局提示。

1. 打开新局，点碗上的“表面”，查看“把开过的小窗连成片”：是否能看清缺少试窗记录，且不能执行？
2. 做“在表面开几个小窗看层次”：地图是否先出现点位，再延伸范围疑问，综合方法是否变为可用？
3. 做区域综合，等镜头拉回，再“展开这份材料”：能否看到道路接通，并回查本局试窗点位？
4. 把地图缩到 20%，拖动，再点“全览”恢复：是否出现卡死或闪烁？也可在调查动画中试一次缩小。
5. 回看第一步，再返回当前，最后收手：记录、调查机会及画面是否对应，没有回到开局或重复扣费？

只需反馈遇到的问题；方便时用“是／否／看不出来”描述对应现象。
本轮不验收经济结算、来客、手机布局或正式数值；全览小字可放大阅读。

## 展示较完整地图的 16 次路线

此路线含结论，用于作者或导师演示，不要求新玩家照做。
每一行是一次具体调查。转动、打开入口、查看材料和缩放均不扣调查机会。

| 次序 | 左侧入口 | 执行手段 |
|---|---|---|
| 1 | 整只碗 | 看整体形制与胎釉 |
| 2 | 底足与修足 | 看底足与修足 |
| 3 | 更早的影像 | 找更早的影像 |
| 4 | 没被改动的特征 | 核对那些没被改动过的特征 |
| 5 | 事故记录 | 查有没有出过事的记录 |
| 6 | 事故记录 | 看事故记录说的是不是这只碗 |
| 7 | 事故记录 | 拿事故记录去对这只碗 |
| 8 | 后期处理记录 | 查后来还有没有人动过 |
| 9 | 后期处理记录 | 看后期记录说的是不是这只碗 |
| 10 | 后期处理记录 | 拿后期记录去对这只碗 |
| 11 | 材料化验 | 化验要紧几处的底子 |
| 12 | 材料化验 | 查各层的先后顺序 |
| 13 | 表面与层次 | 在表面开几个小窗看层次 |
| 14 | 表面与层次 | 把开过的小窗连成片 |
| 15 | 结构与陈列 | 看它结不结实、能不能摆出来 |
| 16 | 经手记录 | 追它经手过谁 |

第4、7、10、16次分别成立年代与类别、重大修复、修复顺序、连贯说明。默认22次机会，完成后余6次。
要看清生长过程，每次等镜头和道路结束后再做下一次；最后点全览看结构，点一项判断回查材料。
四项成立后仍由玩家决定是否收手，也不代表所有分支已经调查。

当前案例最少16次：既有必要条件证明给出16次下界，本次只增加试窗前置，不能产生更短路线；本轮两条合法16次路线和三个尺寸浏览器流程再次成立。
22个手段中，跨时点比较可使用两个不同材料基底，共23种执行组合，因此默认22次并非“全部材料都能取得”的承诺。
