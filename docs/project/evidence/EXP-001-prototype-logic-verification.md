# EXP-001: 原型导航与状态可见性验证

日期：2026-07-22

## 测试了什么

验证证据簿是否只读、行动是否只从观察页推进、可用按钮是否显示手型指针，以及四项 NPC 精确 Mock 值是否在 React 与单文件 HTML 中一致。

## 方法

修改两套原型后运行生产构建、Node 自动测试和 ESLint。测试对证据簿渲染片段、按钮 CSS、收录证据返回逻辑和关键状态数值做静态断言。

## 观察结果

- 生产构建通过；
- 2 项自动测试全部通过；
- ESLint 通过；
- 证据簿中不再出现行动入口，返回后可由观察页“行动”继续；
- 压力、信任、成交意愿、控制感以一致的 0—100 Mock 数值显示。

## 对决定或假设的影响

- 支持 DEC-002：当前导航职责和精确状态展示已经实现并验证；
- 对 HYP-001 只提供“Web 可承载当前交互”的局部支持，不足以决定最终引擎。

## 结论的局限

- 尚未进行真实手机与用户点击测试；
- NPC 数值来自配置 Mock，不是规则引擎计算结果；
- 未比较 Unity 或微信小游戏构建的实际成本与性能。
