# EXP-003: 玩家界面与调试表面分离验证

日期：2026-07-22

## 测试了什么

验证精确 NPC 数值、seed、公式原因、Storylet 条件和规则进程能否移出手机玩家界面，在桌面空白区域形成独立调试侧栏，同时保持手机 H5 简洁可用。

## 方法

- React 与单文件 HTML 均改为“手机画布 + 桌面右侧调试栏”；
- 走完观察接口、收录证据、发起行动和 NPC 回应主路径；
- 在 1280 × 900 检查两栏位置、信息归属与调试栏实时更新；
- 在 390 × 844 检查调试栏隐藏、手机宽度和横向溢出；
- 运行生产构建、5 项自动测试与 ESLint。

## 观察结果

- 手机 P5 只保留阶段变化、前后陈述、当前推断和操作按钮；
- 桌面右栏独立显示当前页面、证据、行动点、态度、六步规则处理链、四项精确数值和完整原因；
- 1280 × 900 下手机画布宽 430、调试栏宽 350，互不覆盖；
- 390 × 844 下调试栏为隐藏状态，页面宽度与视口一致；
- 浏览器无警告或错误，构建、5 项测试与 ESLint 全部通过。
- 已保存并发布为 Sites 第 8 版，沿用现有老师演示地址。

## 对决定或假设的影响

- 明确开发可解释性不等于把全部内部信息暴露给玩家；
- 后续新增模拟器、回放与参数调整工具应继续扩展独立调试表面，不挤占手机游戏界面。

## 结论的局限

- 当前调试栏只面向桌面演示，没有开关、导出或手动改值能力；
- 尚未通过老师或外部玩家确认手机 P5 的信息是否足够。

## 下一步

保持当前信息边界，继续把温和与强硬分支接入规则接口，再用试玩观察玩家是否理解三种态度差异。
