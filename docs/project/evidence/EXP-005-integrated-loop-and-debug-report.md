# EXP-005: 交叉调查、纺锤 NPC 与局末报告验证

日期：2026-07-23

## 测试了什么

验证首案能否在一套共享行动预算内交叉执行观察、询问、证据对质、专项检测和折价，并确保 NPC 状态逐轮演化、所有路径可结算、客观结果与判断质量互不串线，最终在独立 HTML 中输出完整状态变化图和公式。

## 方法

- 将规则实现为纯 `WorldState + PlayerAction → WorldState` 回合解析，并保留完整 `TurnRecord`；
- 配置 3 个隐藏真相、独立 NPC 认知档案、5 个观察目标、3 类问题、专项检测与交易条件；
- 对共享行动点、重复行动、幸运证据、送检成本、零行动点终局、折价、NPC 离场、Storylet 一次性、真相隔离、同源陈述去重和双层结算编写回归测试；
- 运行生产构建、20 项自动测试、ESLint 与 Git 差异格式检查；
- 在 1280 × 900 桌面视口完成“观察接口 → 收录证据 → 带证据追问 → 折价成交 → 复盘”主路径；
- 在 390 × 844 手机视口检查玩家界面、调试栏隐藏和横向溢出；
- 独立执行 100 局、511 个随机合法步骤的 TypeScript/单文件 JavaScript 差分回放。

## 观察结果

- 所有成本行动从同一 6 AP 扣除，买下和拒绝保持零 AP 可用；
- 重复询问会根据当前状态与历史产生新回应，不能免费刷同一个 Storylet 或证据；
- 数值阈值不会单独制造离场死局，只有候选行为实际收敛为离场时才终结；
- 相同 NPC 档案和可见历史在三个物品真相下产生相同回应、状态与判断质量，客观结果按真实价值不同；
- “修复说法发生变化”陈述卡和其结构化信号只计权一次；
- 局末报告能显示每轮 NPC 四状态、AP、delta 公式、候选分项、seed 扰动、Storylet、后验、客观净值、可达 oracle、后悔值和双评分；
- 局末前隐藏真相、底价、接受线、报价差额和定价候选分项均不会在调试栏泄漏；
- 20 项自动测试全部通过；差分回放 0 漂移；桌面与手机主路径无运行错误和横向溢出。

## 对决定或假设的影响

- 支持 [DEC-003](../decisions/DEC-003-integrated-investigation-loop.md)：检测与交流可以交叉并共用行动点；
- 支持 [DEC-004](../decisions/DEC-004-objective-outcome-and-judgment.md)：客观结果与判断质量可以分别计算且保持可解释；
- 支持 [DEC-005](../decisions/DEC-005-separate-object-truth-and-npc-belief.md)：物品真相、NPC 认知和玩家可见信息必须隔离；
- 当前最大未知从规则可行性转为玩家理解度与参数平衡。

## 结论的局限

- 参数只经过自动回归与开发者主路径验证，尚未经过目标用户试玩；
- 单文件演示默认固定为旧胎重修真品，三真相主要用于规则回放；
- TypeScript 与独立 HTML 客户端仍是两份实现，长期存在维护漂移风险；
- 当前器物知识和价值点是玩法样例，不代表真实市场鉴定结论。
