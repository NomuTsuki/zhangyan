# EXP-006: 厚尾价值、保守报价与有限议价数值实验台

日期：2026-07-23

## 测试了什么

验证一类器物能否用五档厚尾价值混合、市场两端扰动、分层证据信号、独立 NPC 认知和有限议价形成可复现的批量结果，同时检查风险分位、成交后亏损、NPC 行为可达性与终局死锁是否被正确区分。

## 方法

- 制作独立开发侧 HTML 数值实验台，不把参数、隐藏状态或系统进程塞入手机玩家 UI；
- 以“漆木首饰盒”为单类样本，配置五个品级、常态/真假货源流入两组先验、三档证据质量、三类 NPC 和四种报价策略；
- 各品级内部使用截断对数正态分布，市场事件重配品级权重；
- 对当前证据阶段的全部信号组合进行精确枚举：弱证据 `5` 组、弱+中证据 `25` 组、弱+中+强证据 `125` 组，再按后验最高品级归组；
- 固定 seed `20260723` 批量运行 10,000 局，分别统计后验分位覆盖、正上限利润缓冲覆盖、成交率、成交后亏损、成交价、净结果、珍品漏买、NPC 回应和死锁；
- 将玩家接受开价、接受还价与离开从 NPC 的接受、还价、拒绝、离场统计中分离；
- 运行生产构建、ESLint、26 项自动测试，并在 1600px、1280px 与 390px 三种视口实测页面。

## 观察结果

- 常态先验为赝品 `25%`、珍品 `3%`，市场事件改为赝品 `35%`、珍品 `10%`；先验均值由约 `123` 升至 `205`，中位数由约 `79` 变为 `75`，证明两端增厚时均值会被珍品长尾抬高，而中位数仍保持谨慎；
- 常态、关键证据链、普通藏家、Q20、10,000 局基准下：
  - Q20 全样本经验覆盖率 `79.9%`，接近目标 `80%`；
  - 中位保守收购上限 `38`，`21.3%` 的局上限为 `0`；
  - Q线一次报价成交率 `30.7%`、成交后亏损 `9.0%`、平均成交价 `61.4`；
  - Q线上限内阶梯议价成交率同为 `30.7%`，成交后亏损降至 `7.6%`，平均成交价降至 `59.1`，说明多轮议价不是免费提高成交率，而是以额外轮次换取有限降价；
  - Q50 风险报价成交率 `65.9%`，成交后亏损 `35.4%`，与Q20形成清楚风险差；
- 125 个高证据信号组合全部进入概率计算，归组概率和为 `100%`；原先只展示“五组完全一致信号”的误导口径已经移除；
- 状态空间枚举能触发 NPC 接受、还价、拒绝和离场；AP 为 `0`、`1`、`4` 的回归均为 `0` 死锁；
- 风险分位覆盖只描述 `P(真实价值 ≥ Qα | 器物证据)`，不能替代“已成交样本中的亏损率”；NPC 开价会产生选择偏差，因此两项已在界面和测试中分开；
- 当前普通藏家参数仍不满足“巨大错价低频”：常态下开价低于真值一半或高于两倍的局占 `34.8%`，市场事件下约 `42.6%`。实验台将其保留为黄色警报，而没有通过改标签掩盖。

## 对决定或假设的影响

- 支持 [DEC-006](../decisions/DEC-006-heavy-tail-value-and-conservative-reference.md) 的结构方向：混合分布、市场重配、稳健分位和 NPC 独立认知可以同时实现；
- [HYP-002](../hypotheses/HYP-002-mixture-value-and-market-events.md) 从 `Untested` 进入 `Testing`：统计结构与信息边界已通过技术验证，但玩家能否学习日报和证据导向尚未验证；
- [HYP-003](../hypotheses/HYP-003-stateful-bargaining.md) 从 `Untested` 进入 `Testing`：有限轮数、状态更新、行为可达与零死锁已验证，但尚未接入正式可玩循环，也未经过玩家理解度测试；
- 新暴露的最高价值参数问题是 NPC 两倍级错价过于频繁，需要先确认“低频”的参考范围，再调整私有信号噪声与锚定波动。

## 结论的局限

- 当前只有一类器物，价值点是游戏实验量纲，不代表现实古董报价；
- 所有数值均为工作假设，尚未经过教师或玩家试玩，不应视为正式平衡结果；
- NPC 开价仍作为独立交易信号展示，尚未进入玩家的器物价值后验；因此实验台会主动报告逆向选择，而不承诺Q20成交后亏损不超过20%；
- 尚未验证多案学习、长期经济、极端珍品对累计货币的冲击和第二类器物的分布差异；
- 浏览器验证覆盖布局、交互与日志，不等于正式移动设备兼容性验收。

## 下一步

先由用户审阅数值实验台，并确认两倍级错价的目标频率、默认风险分位和 NPC 开价是否应作为玩家后验的可见似然。确认后再调参复跑；只有实验参考线稳定，才把一类器物和三类 NPC 接入教师演示 HTML。
