# EXP-007: 双后验与有代价的信息公开实验台

日期：2026-07-24

## 测试了什么

验证开发侧能否在不读取隐藏真相的前提下，同时维护玩家后验、NPC 后验和共享信息，并让私下观察、选择性公开、共同检测、NPC 口供、人物差异、事件驱动重新估价与立即买断风险转移进入同一个可复现的纯规则实验。

## 方法

- 在现有自包含 `掌眼_数值实验台.html` 中保留旧定价实验作为基准，新增独立“实验二”；
- 使用 1 类漆木器物、5 个价值档位、8 条有限证据、3 个证据族、3 条 NPC 私有记忆；
- 配置外行急售者、重真诚藏家、精明行家三类 NPC，将专业度、真诚敏感度、开放度、风险厌恶、急迫度和锚定噪声分账；
- 固定 seed 比较全部保密、全部公开、只公开利空、按信息价值披露、立即买断转移风险五类自动代理；
- 同一批案件同时用于五类代理，另生成三类 NPC 的配对矩阵；
- 对确定性、后验归一、来源去重、隐藏真相隔离、终局可达和风险转移接口编写 Node 回归测试。

## 观察结果

- 已实现：单局双方后验、证据/口供轨迹、行动点、NPC 主观中位价值、开价/接受线、正式重估原因和客观结算均可在开发页读取；
- 已实现：共享证据只按 ID 对双方各计权一次；NPC 已知的私人记忆公开后只更新玩家，不会让 NPC 重复学习；
- 已实现：关系状态只改变谈判档位和接受条件，客观证据只改变价值后验；只有关键共享信息、后验中位数明显变化或档位跨越才允许正式重新估价；
- 已验证：`node --test tests/numeric-lab.test.mjs` 共 `8/8` 通过，两个页面脚本均通过语法检查；
- 已验证：默认 `seed 20260724`、重真诚藏家、4,000 组配对案件中，五类代理终局率均为 `100%`，死锁 `0`，重复来源 `0`，隐藏真相替换不改变相同可见历史下的决策；
- 首轮参数：全部保密、全部公开、只公开利空、按信息价值披露、立即买断的平均净结果约为 `+15.6 / +10.3 / +18.8 / +16.7 / +4.7`；
- 首轮参数：只公开利空在外行急售者和重真诚藏家上领先，按信息价值披露在精明行家上领先；没有跨三类人物都领先的单一策略；
- 首轮参数：立即买断成交率在外行急售者、重真诚藏家、精明行家中约为 `57.9% / 36.6% / 25.3%`；
- 默认单局展示为重修真品，客观值 `75`；玩家公开一条共享信息后，NPC 主观 Q50 `70 → 25`、开价 `125 → 65`，最终未成交，能显示“玩家获得信息/关系改善但仍选择不买”的完整轨迹。

## 对决定或假设的影响

- [HYP-004](../hypotheses/HYP-004-dual-posterior-disclosure.md) 从 `Untested` 进入 `Testing`：信息结构和技术边界已经成立，但策略平衡与玩家理解尚未验证；
- [DEC-007](../decisions/DEC-007-dual-belief-and-strategic-disclosure.md) 的四层信息结构已经在开发实验中落地，尚未接入正式玩家循环；
- 首轮结果支持“人物差异可以使策略翻转”，但也暴露只公开利空在两类人物上偏强、行家仍有较高买断成交率，需要继续调参而非直接接入演示。

## 结论的局限

- 自动代理是一步启发式，不代表真实玩家，也不能证明玩法可理解或有趣；
- 当前只有一类器物、一套先验和三类 NPC，尚未覆盖低级场、中级场、高级场的不同风险结构；
- “同一可见历史替换隐藏真相”的回归只证明代码接口没有读真相，不等于所有未来 Storylet 都天然安全；
- 本轮完成脚本和静态结构验证，但本地 `file://` 页面未能在受控浏览器中完成截图验收；此前旧实验的多断点视觉结论不能自动外推到新增模块；
- 当前数值为工作参数，不是平衡结论。

## 下一步

先由用户审阅实验二的单局轨迹、五策略表和 NPC 矩阵。重点讨论：

1. 只公开利空在外行与藏家上是否过强；
2. 按信息价值披露是否应通过更高口供价值或更低机会成本获得更清楚优势；
3. 精明行家 `25.3%` 的立即买断成交率是否应继续压低；
4. 单局轨迹是否足以解释“公开事实会同时教育卖家”；
5. 确认后再调参并做一次真实浏览器多断点视觉验收，最后才选择最小路径接入教师演示 HTML。
