# EXP-008: 双后验最小玩家循环整合与结构验证

日期：2026-07-24

## 测试了什么

验证 EXP-007 中的双后验、有代价信息公开、动态重新估价和风险转移，能否进入首案低保真玩家循环，而不破坏隐藏真相隔离、行动点边界、证据去重、证据簿职责和交易终局可达性。

## 方法

- 在现有漆木首饰盒首案中加入物品真相、玩家私有证据、NPC 私有认知和共享证据四层信息；
- 将普通观察设为玩家私有信息，只有带证据询问、对峙或共同检测才可能把客观证据转为共享信息；
- 允许玩家以中性或只强调利空的方式使用证据；披露方式只改变关系反应，不篡改事实或双方后验；
- 让 NPC 依据自身私有信号、共享证据、专业度、风险偏好、急迫度和当前关系状态形成动态开价、普通接受线和无条件买断线；
- 在玩家交易页同时提供当前报价、玩家可见后验生成的谨慎参考、普通自定义报价、无条件买断、共同检测和拒绝；
- 同步实现 React 页面和自包含单文件 HTML，并以规则测试、单文件静态检查、构建与桌面主路径操作检查验证关键边界。

## 观察结果

### 已实现

- 普通观察只增加玩家私有证据，不自动教育 NPC；证据簿继续是只读仓库；
- 首次用客观证据询问时，该证据进入共享集合，NPC 更新后验并可触发正式重新估价；重复使用同一来源不会重复计权；
- NPC 自己说过的话可以帮助玩家判断，但不会作为“新共享物证”反向更新 NPC；
- 共同检测消耗 `2 AP + 10价值点`，结果自动共享；普通自定义报价和无条件买断分别使用动态普通线和买断线；
- NPC 正式重估只在共享证据、后验或谈判档位发生实质变化时触发，并保存旧价、新价和原因；
- 手机玩家画布只展示证据归属、卖家公开回应和公开价格变化；双方精确后验、定价分项与公式保留在宽屏开发调试栏；
- 局末复盘加入公开行为、证据迁移、价格变化和成交结果的因果时间线。

### 已验证

- 私下检查不会改变 NPC 后验或当前报价；
- 首次共享“现代胶痕”会更新 NPC 后验并把演示报价从 `80` 调至 `65`，随后共享“旧木胎氧化层”可使报价从 `65` 调至 `70`；
- 只强调利空与中性披露共享同一事实、得到同一后验，但会按 NPC 专业度和真诚敏感度产生不同关系 delta；
- 共同检测的行动点与货币成本、零行动点终局、动态普通报价、无条件买断、来源去重、双方后验归一、隐藏真相隔离和确定性回放均有自动回归覆盖；
- `npm test`（含生产构建）通过 `34/34`，`npm run lint` 与 `git diff --check` 通过；
- 自包含 HTML 的集成入口、证据簿只读、动态报价与买断行动具有静态回归覆盖；桌面浏览器已走通“私下观察 → 公开证据 → 重新估价 → 交易/买断 → 复盘”主路径；
- 普通报价 `55` 成交时，结算给出机会损失 `5`、客观分 `94`，证明完全知情基准不再把玩家的实际成交价当作最优基准而自动满分；
- `390 × 844` 视口下开发调试栏为隐藏状态，页面 `scrollWidth = clientWidth`，无横向溢出。

## 对决定或假设的影响

- [DEC-007](../decisions/DEC-007-dual-belief-and-strategic-disclosure.md) 的四层信息结构已经从开发实验进入低保真玩家循环；
- [HYP-004](../hypotheses/HYP-004-dual-posterior-disclosure.md) 继续保持 `Testing`：技术边界和最小交互路径得到支持，但真实玩家是否理解披露代价、是否出现支配策略、动态报价是否可信仍未验证；
- 当前最高价值动作从“选择一条路径接入教师演示”变为“让用户直接试玩已接入的最小路径，并据此修正信息层级、参数和行为反馈”。

## 结论的局限

- `80 → 65 → 70` 是首案工作参数和固定演示证据顺序，不是平衡结论；
- 玩家循环目前只展示一个 NPC 档案和一类器物，不能证明人物矩阵中的策略翻转已被玩家感知；
- 自动测试证明规则边界闭合，不证明游戏有趣、文案易懂或报价跳变符合玩家直觉；
- 本轮只验证了桌面关键路径与 `390 × 844` 手机边界，尚未覆盖更多设备、浏览器和真实触控行为；
- React 规则与单文件 HTML 仍是两份实现；当前有结构和关键规则回归，但尚未形成持续的完整差分回放。

## 下一步

让用户直接试玩自包含 HTML，至少比较“私下保留证据”“公开现代胶痕后普通议价”“继续公开旧木胎证据”“使用无条件买断”四条选择。记录玩家是否能解释证据归属、价格跳变、普通接受线与买断线的区别，再决定优先改文案、参数还是分支内容；在此之前不扩展第二案件或正式美术。
