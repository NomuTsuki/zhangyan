# EXP-009: 首轮整合原型的数值与规则对齐审查

日期：2026-07-27

## 测试了什么

通过用户实际试玩和代码只读审查，检查玩家是否能够理解当前结算、披露选择、行动资源与风险转移的意义，并核对自动测试究竟覆盖了哪些结论。

## 方法

- 用户自由试玩当前自包含 HTML，并报告具体结算与交互困惑；
- 复查 TypeScript 结算、披露、行动点和 NPC 议价相关规则；
- 审查现有 34 项自动测试和数值实验台的 8 项测试；
- 用 `真实价值65 / 成交价65` 与 `真实价值65 / 成交价60` 手算当前公式族；
- 对照 DEC-003、DEC-004、DEC-007、HYP-003 和 HYP-004，区分用户确认方向与 Codex 自行填入的工作参数。

## 观察结果

- 旧版结算把当前路径动态形成的最低买断线当作参考最优时，65/65 和 65/60 都可能因“机会损失为 0”获得 100 分；这评价的是当前路径后悔值，不等于经营结果或全局议价效率。
- 当前未提交工作区已经调整过部分参考线，因此不同路径可能不再复现相同分数；但其满分基准、归一化方式和胜利阈值仍是 Codex 自行设定，尚未完成设计对齐。
- “完整说明事实”与“只强调不利部分”会公开同一条证据并更新相同后验；后者主要增加人物相关的关系惩罚。在首案“现代胶痕”主路径中，取整后两者甚至可能完全相同。
- 用户此前批准的是检查、询问、证据对质和共同检测共享调查预算；Codex 后续把正式报价和买断也放入该预算，越过了已确认边界。
- 风险转移来自用户提出的条件性策略，但 Codex 在实验台、玩家 UI 和试玩主路径中给予了过高权重。
- 当前自动测试主要验证信息隔离、来源去重、状态原子性、确定性回放、终局可达与实现一致性；它们没有证明评分定义正确、数值平衡、玩家理解或玩法有趣。
- 部分测试已经把旧的共享议价行动点、动态买断线和抽象披露惩罚写成必须保持的行为，因此规则重新对齐后需要改写，而不是机械保持通过。

## 对决定或假设的影响

- DEC-004 的双层结算结构仍有价值，但当前客观分公式不能继续作为已验证方案；
- HYP-003 中“正式报价继续消耗调查行动点”的部分应被替换为独立议价资源；
- HYP-004 继续验证双后验和证据公开，但风险转移降为条件性机制；
- 进入 [CH-002](../challenges/resolved/CH-002-settlement-bargaining-and-disclosure-alignment.md)，在用户确认前暂停继续扩充数值实验台和玩家规则；该挑战已于 2026-07-31 解决。

## 结论的局限

- 当前只有一名核心用户的一轮试玩反馈，还不能评价不同玩家群体的理解差异；
- 用户看到的 100 分可能来自旧提交、自包含 HTML 镜像或不同状态路径；本证据确认公式的概念问题，但没有把该截图对应的完整行动轨迹唯一复现；
- 尚未确定新的总分公式、议价资源公式或正式披露交互；
- 本轮没有修改或重新运行玩家规则，因此不构成新方案验证。
