# EXP-011: H5 入口与器物美术方向确认

日期：2026-07-31

## 证据来源

- 用户确认《掌眼》高保真教师演示采用“当代雅集式鉴定工作台”规格；
- 用户同步团队对器物表现的初步讨论；
- 用户转述指导老师对最终打开方式的明确答复。

## 获得的信息

1. 古董不采用真实照片或 3D 风格，使用细节精致的二维插画；
2. 插画难以可靠承担细纹、标记、锁扣等精确事实，因此鉴定结论仍以文字呈现；
3. 老师希望后续在游戏结算后出现一张真实画风的古董讲解图，但当前低价值首案不需要制作，优先留给精品、珍品；
4. 最终产品是“和公众号链接的网页一样”的普通 H5，通过微信内的网址打开，而不是微信小游戏。

## 直接影响

- 高保真首案的器物视图采用“二维插画定位 + 局部示意 + 文字证据”；
- 当前不制作写实结算讲解资产；
- 标准 Web/H5 路线获得入口层面的支持，不再为微信小游戏或 Unity 预留当前工程负担；
- 最终公开交付仍需补做 HTTPS 托管与微信内实机验证。

## 边界

本记录确认的是载体和表现方向，不代表正式美术风格、文化准确性、域名、托管服务或微信平台扩展能力已经验收。
