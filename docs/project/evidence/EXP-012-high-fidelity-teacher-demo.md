## 真实浏览器路径

浏览器：系统 Chrome
入口：生成后的自包含 HTML，经本地静态服务打开

### 桌面 `1440 × 1000`

完成路径：

1. 来客页接下器物；
2. 切换到开盒视图并选择接口；
3. 检查接口，获得“现代胶痕”；
4. 收进证据簿并返回调查；
5. 打开证据簿，确认内容区只读；
6. 在“修复历史”询问中公开“现代胶痕”；
7. 看到卖家回应和 `80 → 65` 正式重估原因；
8. 进入交易，提交 `50` 点正式报价；
9. NPC 还价至 `58`，议价容量 `5 → 4`，调查行动保持 `4 / 6`；
10. 确认返回调查控制已移除，但买下和拒绝仍可用；
11. 以 `58` 点买下，进入 A 级复盘；
12. 局末展开开发复盘，显示真实价值 `65`、品质 A 和精确状态。

观察结果：

- 开发栏默认收起；
- 局末前展开开发栏，隐藏真相仍显示为“尚未解锁”；
- 开发栏是玩家画布的兄弟区域，不进入玩家手机 UI；
- 阶段切换后焦点分别落在“调查”“证据结果”“交易”“复盘”主区域；
- 非法报价 `65` 紧邻显示“报价需低于卖家当前要价 65 点”，提交按钮禁用；
- 证据簿打开后聚焦关闭按钮，`Escape` 后返回证据簿入口；
- 浏览器控制台 0 error、0 warning。

### 手机 `390 × 844`

观察结果：

- `scrollWidth === clientWidth === 390`；
- 教师说明与开发栏的可见盒均为 `0 × 0`；
- 当前可见的 `button`、`input`、`select` 和按钮角色均没有小于 `44 × 44px` 的目标；
- 玩家画布铺满视口，无页面级横向滚动；
- 桌面开发信息不在手机可见界面中。

### 无鼠标键盘激活

使用焦点与 `Enter`、方向键、字符输入完成：

```text
接案 → 开盒 → 选择接口 → 检查 → 收证
→ 选择询问 → 选择具体证据 → 提问
→ 进入交易 → 输入 50 → 正式报价 → 买下 → 复盘
```

观察结果：

- 调查、证据结果、交易和复盘四次主阶段变化均有明确焦点落点；
- 具体证据下拉框具有可访问名称；
- 正式报价后“返回调查”控制数量为 0；
- 最终复盘标题为“真正掌眼”。

## 独立审查与修复

独立只读审查首次判定不宜直接交老师，指出：

1. 开发栏默认常显并提前剧透真实价值；
2. 阶段切换丢失焦点；
3. `80 → 65` 缺少紧邻原因；
4. 三组移动控件低于 44px；
5. 证据下拉框无可访问名称；
6. 非法报价无原因，调查切换使用了不完整 tabs 语义；
7. 正式报价后仍保留禁用的返回调查按钮。

上述问题均已修复，并增加 `hifi-accessibility.test.mjs`。该测试在修复前 `0/8` 通过，修复后 `8/8` 通过；真实浏览器复跑也验证了焦点、价格反馈、触控目标和信息解锁时机。

修复后由同一只读审查者进行有界独立复审，八项原问题全部通过，浏览器控制台与 `pageerror` 均为空，最终判定为 `pass`，并认为当前 HTML 可以用于老师演示。该结论只覆盖原阻塞项，不等同于数值平衡、真实微信环境或正式发布已经验收。
