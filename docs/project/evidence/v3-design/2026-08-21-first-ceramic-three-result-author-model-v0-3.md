# 第一器物三档作者模型 v0.3：档案关系轴与领域能力收窄

Status: Design Candidate / Independent structural-deterministic Pass / User author-spec approval pending

日期：2026-08-21

## 本版本解决什么

v0.2 已经证明“开放证据网可以汇合成 G1／G2／G3”，但限定领域复核发现两类源头问题：档案内容可能真实却不属于当前器物；若把 X 射线、试窗、材料分析和静态陈列写成黑箱动作，系统会得到现实方法无法负责支持的结论。

v0.3 不改变客观真相和三档含义。它把“档案是否属于本器”从一个隐藏布尔门改成玩家可感知的关系推理，并把四类检测结果限定到实际覆盖的区域、点位、材料层和使用条件。

本文件在以下主题上替代 [v0.2](2026-08-17-first-ceramic-three-result-author-model-v0-2.md)：档案语义、G2 档案证明路线、G3 三阶段档案路线、X 射线覆盖、试窗／表面外推、材料／层序分析和稳定性表述。12 个核心对象候选包、G1／G2／G3 基本含义、联合支持、早拿后懂、只计一次、反证范围、手动停手及所有未点名内容继续继承 v0.2。

## 三个必须记住的边界

1. **档案不是答案卡。** 原始照片、清单、票据和报告先作为候选记录出现；系统不得预先告诉玩家“这就是本器档案”。
2. **关系问题限制系统措辞，不限制玩家。** 玩家可在任何支持状态下相信直觉、继续调查、收手或报价；系统只对自己能否说“这段历史属于这件器物”负责。
3. **G2 是深档案调查的软转折。** 深档案不被阶段硬锁，但 G2 之后器物的潜在重要性更明确，系统才有理由常驻推荐更昂贵、更定向的档案工作。

## 档案、背景与对象假设分账

| 类型 | 作者侧含义 | 能否直接证明本器历史 |
|---|---|---|
| 背景知识 | 一般性的工艺、修复和检测规律 | 否 |
| 背景信息 | 收藏、时代、渠道或来源环境 | 只能改变注意方向和先验，不能单独证明 |
| 原始档案记录 | 具体照片、清单、票据、报告或图纸；内容和来源分别保存 | 否；先证明记录声称什么 |
| 候选档案组 | 系统按对象／事件线索暂时组织的记录集合 | 否；它不是认证答案 |
| 档案关系状态 | 记录之间、记录与现器、所述事件与物证之间的当前支持状态 | 只决定系统措辞资格 |
| 对象候选包 `h` | 身份 × 修复史 × 关键材料的 12 个互斥候选世界 | 继续保存本局联合后验 |

档案关系不是第二套扁平的“12 个世界”。同一记录可以内容真实但对象误归属，也可以只对应某一次修复；数份记录可以分别指向 T1、T2、T3，或者留下仍未解决的矛盾。因此作者模型保存的是对象候选包与关系主张之间的连接，而不是把“某份档案为真”压成一个对象标签。

## 三个持续更新的档案关系问题

每个候选事件组分别维护三个问题：

1. `recordCoherence`：这些记录彼此是什么关系，是否描述同一对象／事件，还是不同阶段被误并在一起？
2. `objectAttribution`：这些记录与当前器物是什么关系？对象编号、所有权链、独特损伤、制造瑕疵和稳定的非构图锚点是否一致？
3. `eventCorroboration`：记录声称的事故／处理与现器或跨时点物证是什么关系？所述范围、形态和后果能否在当前结构、表面或历史时点中得到印证？

每个问题使用以下作者侧状态：

| 状态 | 系统含义 |
|---|---|
| `unresolved` | 尚无足够关系信息；保留问题，不作否定 |
| `suggestive` | 存在线索或局部对应，可以影响后验、注意力和价值情景，但不能使用肯定归属措辞 |
| `established` | 具名来源、覆盖和独立关系角色足以让系统在本局证据范围内建立该关系 |
| `contested` | 存在直接冲突或更好的替代归属；系统必须显式保留争议 |

这些状态是**持续更新的关系摘要**，不是玩家要依次完成的三项任务，也不产生操作门禁。具体玩家侧如何表达要等知识工作台原型，本文件不批准进度条、打勾清单或精确概率。

## 档案证据的局部价值

候选记录在未完成对象归属时仍然有用：

- 它可以告诉玩家“某个时期确有一类重大事故／处理记录”，使部分对象候选相对更值得关注；
- 它可以暴露具名区域、时间、人物、编号或处理词汇，形成下一步调查方向；
- 它可以与已有观察产生微弱联动，或与另一份记录形成内部冲突；
- 它也可以只是重复、同源或对当前替代解释没有区分力的信息。

未归属档案不得被丢弃，也不得直接派生“本器发生过该事件”。档案内容因子仍可更新联合后验；阶段主张另外读取关系状态，因此“有影响”和“系统已经证明”分开。

## G2 的两条重大重组路线

G2 继续要求身份、重大重组、最低外观再整合和 `G2Core` 联合支持同时成立。重大重组至少由一条路线建立：

### `MAJOR_PHYSICAL`（首案主体验路线）

- 现器具名修复图；
- 预声明主要区域的多角度、逐区可读结构结果；
- 当前结构与早期／损坏时点之间的重大变化对应；
- 以上证据的来源与潜因正确折叠，且不存在命中必要区域的阻断反证。

这条路线允许玩家主要依靠器物本身抵达“平庸但完整的 G2”，使深档案自然成为 G2 后是否继续投入的选择。

### `MAJOR_DOCUMENTED`（开放但更长的替代路线）

- T2 候选记录组的 `recordCoherence = established`；
- T2 记录与现器的 `objectAttribution = established`；
- T2 所述事件与现器修复图或合法跨时点对应的 `eventCorroboration = established`；
- 记录明确声称重大损坏、重组及最低外观恢复，并与当前／跨时点物证相容；
- 没有尚未处理的对象归属或事件冲突。

单份票据、文件数量、通用构图相似、当前一处胶线、单次 X 射线或任意一个关系问题单独成立都不能建立这条路线。该路线不是禁止玩家早查档案，而是阻止系统把“记录存在”越权说成“本器历史已证实”。

## G3 的三阶段与深档案

G3 仍要求 G2、T1／T2／T3 先后关系、关键材料、表面、稳定性、档案边界和一致联合剖面。首案中：

- T1 历史图像必须先完成现器对象连续关系；
- 纯物证路线可以独立建立 G2；但首案若要把更深结论表述为 T1／T2／T3 三阶段历史，T2 仍需完成上述三个档案关系问题，使系统能够负责地把该阶段记录归于现器并与物证互证；
- T3 后期报告同样先作为候选记录组，分别建立记录内部关系、与现器归属、报告区域与现器区域对应；
- 报告只证明当时记录了什么处理，不能替代当前状态检查；
- 数份记录可以分别归属不同修复阶段，G3 奖励的是关系重建而不是找出唯一“真档案”。

因此深档案主要承担 G2 到 G3 的年代、归属、范围和价值边界收束；它可以早拿，但不被常驻提示提前渲染成唯一主线。

## 四类领域能力收窄

| 接口 | v0.2 风险 | v0.3 作者合同 | 分类 |
|---|---|---|---|
| X 射线 | 单次全器结果仿佛必然读清所有接缝和填补 | 保存投照角度、具名区域、可读／不可读覆盖；只有预声明主要区域达到多角度可读才进入物理重大重组证明 | `Borrow` 后采用 |
| 试窗／表面 | 一个点位层序被外推为整个区域 | 点位层序与区域综合分账；区域结论还需多点、修复边界或其他空间证据 | `Adopt` |
| 材料／层序 | “材料分析”一次同时给出基底类型和层间先后 | 点位基底识别与真实界面／横截面层序拆成两个观察；二者共同进入关键材料解释 | 旧黑箱 `Reject`，拆分接口 `Adopt` |
| 稳定性 | “可静态陈列”像脱离情境的永久属性 | 固定放置姿态、底托／支撑、搬动限制、检查覆盖和结论有效条件；报告不能替代当前检查 | `Borrow` 后采用 |

这些收窄允许结果为 `unresolved`。它们不保证每次专业检查都读出作者预想的边界，也不改变专业检测可以提前取得局部信息的开放性。

## 结构不变量增补

在 v0.2 的 15 条不变量之上新增：

16. 档案内容真实、档案属于当前器物、记录事件在现器留下物证三件事不得合并；
17. 候选档案早拿必须产生局部反馈，但不得因尚未归属而被丢弃或直接升格；
18. 三个档案关系问题只约束系统主张，不锁玩家调查、直觉、报价或停手；
19. 深档案的 G2 软转折改变推荐强度和投入理由，不改变行动可用性；
20. X 射线、表面点位、材料读数和稳定性只在声明覆盖与条件内生效；
21. G3 的 T2／T3 档案关系可以分别成立、争议或未知，不得用一份“总档案”覆盖多个阶段；
22. 纯物证 G2 路线不因档案关系轴新增而被收紧或删除。

## 确定性场景要求

修订后的隔离夹具至少覆盖：

- 候选 T2 档案提前取得，改变后验但不直接形成 G2；
- 候选记录内部相容、对象归属未决和事件印证仅为提示的不同组合；
- 对象归属出现直接冲突时保持 `contested`，系统不得升格；
- T2 三个关系问题成立后，当前修复图与跨时点对应两种事件印证均可恢复档案路线；
- 纯物证路线仍可独立形成 G2；
- T3 记录、对象归属和当前区域对应分别成立后才能进入三阶段主张；
- 多角度逐区 X 射线、点位材料／层序、表面点位／区域综合和有条件静态陈列全部进入 G3；
- 相同证据多重集换序后得到相同后验、关系摘要、主张和阶段；
- 玩家 STOP／CONTINUE 合同不读取档案关系状态。

## 尚未批准或验证

- 玩家侧关系图、候选档案组的具体视觉形式和提示文案；
- 玩家可见的粗概率形式；
- 深档案成本、出现时机、推荐强度和路线非支配；
- 正式似然、阶段阈值、价格、调查成本和市场参数；
- 无答案玩家理解、趣味、平衡和正式产品实现；
- 具名外部陶瓷／保护专家签字。

当前隔离求解器中的数值仅为夹具技术值。v0.3 只有在独立结构复核和确定性重放通过后，才能成为作者纸面规格交接输入。
