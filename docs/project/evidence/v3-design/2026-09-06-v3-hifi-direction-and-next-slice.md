# V3 高保真方向与下一切片

日期：2026-09-06。状态：用户已同意暂按悬空器物版推进；视觉与交互方向已采纳，可操作高保真实现尚未开始，体验待真人验证。

## 当前依据

用户先要求直接进入完整游戏成品画面的设计，随后采纳第一张完整画面为讨论基底，并提出悬空旋转、部位朝向显隐、文字调查入口、地图气质与顶栏调整。看到修订图后，用户明确说“暂时就先按照这一版来做”。本记录整理这些决定，不把生成图里的每个字、连线和刻度当作已批准规则。

当前画面：[悬空器物修订图](../../../portfolio/2026-09-06-final-game-screen-study/2026-09-06-zy-screen-floating-object-revision.png)。对照、完整提示词与来源见[过程资产](../../../portfolio/2026-09-06-final-game-screen-study/README.md)。两张均为 GPT Image 生成图，不是产品截图。

## 开发目标

制作具有成品观感的完整桌面游戏界面，把器物检查、已有信息的关联与最后判断接成清楚的一次鉴定。玩家知识地图辅助长线推理：保留已见信息及其来源、关系和未解之处，让新发现逐渐点亮认知、道路从已有认识延伸，旧信息能被后来证据重新理解。地图保持辅助地位，不因画幅扩大或信息平铺而抢走器物与判断的注意力。

“开放世界地图逐渐点亮”“道路延伸”及 Ron Gilbert 依赖图思路仍是设计启发；这次没有新增外部研究结论，也不把隐藏的作者依赖图直接展示给玩家。具体内容继续服从 [CONTEXT.md](../../../../CONTEXT.md) 与已有证明关系。

## 已采纳的方向

| 部分 | 本轮明确方向 |
|---|---|
| 完整画面 | 统一设计左、中、右及顶部。此前“只改中间”的执行范围已由用户后续“直接进入最终游戏画面设计”更新；保留三栏分工与地图辅助地位。 |
| 气质与器物 | 暂沿用修订图的纸色、墨色、细线条及器物材质表现。题材仍为已有的虚构“珠江商馆与帆船图外销瓷大碗”，没有更换为其他器物或照搬真实馆藏。 |
| 左侧比例 | 眼前之物与器物之外适当收窄；生成图和提示词中的具体百分比不作为正式布局值。 |
| 把玩器物 | 器物悬空，不放在桌面；鼠标拖动自由旋转。在相应部位面向玩家时，显示该部位可执行的调查手段。底足只是用户用来解释此规则的例子，不把所有调查都收束到碗底。 |
| 器物之外 | 手段显示更完整，以文字按钮和清楚分组呈现，移除占空间的图片卡片。图示十个入口仍须对应既有地点／手段集合，不能据图删除其他合法动作。 |
| 中间地图 | 已知与推理的字体、线条、分组更严肃清楚，保留路径延伸和探索感。证据、局部理解、已经成立的判断与未解之处可区分。 |
| 右侧判断 | 略增信息密度，呈现判断及其依据、仍未说清的内容；使用真实会话状态，不把示意文本固定写死。 |
| 顶部 | “收手，作出判断”移到“查看委托”左侧；调查机会也放在顶部，与查看委托、调查记录处于同一行高度。收手仍由玩家主动选择。 |

交互落地建议保持 Experimental：旋转到足够可见的朝向范围就稳定显示部位手段，避免精确角度找按钮；转动视角与执行调查明确分开。具体角度阈值、显隐缓冲、拖动／点击判定、缩放及键盘操作尚未定型，不因图中的“滚轮缩放”提示就视为全部交互已经批准或实现。

## 与既有系统的关系

- 继续按 DEC-033 只做桌面浏览器，不增加手机布局、断点或窄屏退路；本轮不触发重新询问移动端。
- 朝向影响部位手段的显示位置和时机，不改变作者真相、调查的语义条件或可达性。世界朝向与游戏调查状态需要分开保存。
- 作者真相与玩家知识严格分离；证据不等于结论，重复证据不重复计权，意义可以延迟形成。
- 未重新决定 G1/G2/G3、阶段结算、数值、费用制度、NPC 或其他核心循环。生成图里的五笔调查刻度不代表新的机会预算。
- 进入高保真意味着以完整画面和真实交互推进切片；不把历次低保真试玩未通过这一事实改写为通过，也不把这次画面采纳称为生产系统或发布验收。

## 接下来的顺序

1. 本轮先完成版本追踪与方向记录，不实施新界面代码。
2. 下一切片先让同一只碗在桌面高保真三栏界面中真实旋转，并在可见部位显示正确手段；选用能表现底足、内壁及遮挡关系的器物表示，不能用平面图片的旋转冒充自由把玩。渲染技术和可编辑资产制作方式先做最小可运行验证，不在本记录里预定库或模型来源。
3. 把现有调查入口和会话状态接回同一画面，打通“查看部位 → 执行调查 → 地图新增信息与关系 → 判断依据更新 → 顶部主动收手”。外部调查入口也消费同一组可用手段。
4. 用真实初始、中段、多信息及收手状态检查布局、文字与关系，而不是只还原一张中段静态图；机器核对接线，真人再判断把玩、理解和推理体验。

以上是实施顺序，不是新增关卡或强制玩家路线。当前最近的一步是第二项的小切片，不开展全局引擎重构。

## 尚未解决的具体问题

- 器物几何、纹理、旋转控制与性能的最小可行实现；目前只有生成图，尚无本轮可把玩的器物资产。
- 部位与动作的完整映射，朝向显隐和遮挡处理；不会让底足之外的调查永久丢失。
- 玩家地图节点／边／局部 Finding 的精确呈现与真实状态投影；图中的美术连线不作为关系定义。
- 右栏各条主张与依据的真实来源，以及机会／费用的完整反馈；修正生成图中的文字偏差。
- 具体比例、字体、字号、间距及显隐参数仍需渲染核对；产品影响参数按既有规则登记，当前未转正任何数值。
