# V3 物品真相拓扑设计证据包

状态：`Mixed / See each record`。这里保存 V3 启动前的用户原话、外部研究、候选过程资产、私有批注图，以及启动后的 Decision 输入与验证记录。各记录必须按自身 Status 和结论边界解释；本目录整体不构成统一批准，只有明确标为 Pass 的记录支持其限定验证结论，且均不自动成为产品实现。

## 使用规则

1. 原话回答“用户当时怎样构思”，研究回答“相邻实践怎样修正构思”；两者都不能单独授权实现；
2. 任何进入产品的节点、边、概率、经济结果或 UI 必须由 V3 Decision 明确 Adopt／Borrow／Reject／Unknown；
3. 作品集最终优先展示实现成果和玩家验证；本过程资产最多保留为一个前后转折节点。
