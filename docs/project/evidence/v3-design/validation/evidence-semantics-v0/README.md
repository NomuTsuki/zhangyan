# 情报语义文本 v0

给玩家读的那一层话。**这是内容,不是架构**;它不碰任何冻结字节,也不决定地图怎么画。

创建时间:2026-08-28。分支 `codex/v3-object-truth-topology`。

## 为什么有这个文件

2026-08-27 真人试玩 [知识地图可玩切片 v0](../knowledge-map-slice-v0/README.md) 的结论是「没玩明白」,提出的八条问题全部成立。其中最根本的一条不是布局问题:

> 我甚至都不知道下一步比方说「补绘到底压在哪一层上」所能代表的意义,或者说得知了补绘到底压在哪一层上,对我对这个东西的认知或是判断有什么影响。玩家不是古董鉴定专家,这些东西都需要补齐。

[DEC-032](../../../../decisions/DEC-032-v3-workbench-map-separation-and-guidance-division.md) 把这一块点名为**最大的一块剩余工作**,并明确它属内容而非架构。DEC-032 同时定下指引的权责:**系统提供领域知识,玩家保留意图** —— 这份文本就是「领域知识」的载体。系统靠它抹平玩家作为非专业人士的信息差,而不是靠它替玩家决定下一步做什么。

## 一个动手前的发现:边不用发明,它在数据里

写之前测绘冻结夹具,发现玩家侧要的「情报之间的逻辑连接」在作者规格里**已经存在**,而且不止一种。切片当初没画,是切片偷懒,不是规格没有。

**一、共享潜变量 —— 这几条在说同一件底层的事。** 每条观察都挂着 `sharedLatentIds`。两条情报挂同一条,就是在说同一件看不见的事实。22 个正典动作触及 15 条线索,其中 4 条连着多个动作,共 13 条可能的边:

| 底层线索 | 落在上面的动作 | 边 |
| --- | --- | --- |
| 这只碗是怎么做出来的 | 看整体形制、看底足修足、比语料、再调语料复核 | 6 |
| 它被修过哪里 | 看整体形制、逐区看纹饰色差、X 射线 | 3 |
| 表面这层是什么状况 | 紫外筛查、开试窗点位、表面区域综合 | 3 |
| 关键区是原片还是重建 | 点位材料基底、微观层序 | 1 |

其余 11 条是单例,也就是 11 个天然孤立点。**这恰好是用户描述的形状**:一个较大的簇、几个小簇、一些完全孤立的点。不是摆出来的,是规格自带的。

这一条也直接回答了试玩问题之三(「两个都探索过的地点之间没有连线」):看整体形制与看底足修足确实同挂 `latent.current-craft`,规格里那条线一直在。

**二、前置依赖 —— 没有那条,这条根本拿不到。** 比语料需要先有胎体面貌与底足工艺;核对稳定锚点需要先看过底足;追来源链需要先确认对象连续性。

**三、悬空后被接住。** 22 个动作里有两个天生如此:X 射线与找早期影像。它们到手时都是读不出结论的原始读数,要等「手里这只就是记录里那只」到位才**自动**激活。规格里叫 `requiresContextFacts` / `contextualFacts`。这正是用户从 Ron Gilbert 那张 DeathSpank 图里指出的机制。

**四、证明角色汇合 —— 局部结论与 G 地标从这儿来。** 10 个证明角色。核过求解器后有一处特别值得写进文本:G2 的物证路线硬性需要「可具名的干预分布图」,而它唯一来源是**全场最便宜的那个免费动作**。免费的第一眼不是热身,是贵路线上不可替代的一块 —— 这种事玩家绝对看不出来,必须由语义文本讲出来。

### 分层(用户 2026-08-28 定案)

`whyShort` 上决策面,一句话;`whyLong` 要看才展开。这与 [DEC-026](../../../../decisions/DEC-026-v3-progressive-player-knowledge-map-and-current-best-hint.md) 的三层指引一致:既抹平信息差,又不让决策面膨胀。被否掉的两个替代是「统一只给一句话」(非专业玩家仍读不懂为什么该花钱)与「统一给完整一段」(变教科书、玩家跳读)。

## 写作约束

**静态文本不得预设本案结局。** 这份文本在玩家动手之前就可读,所以它只能给领域常识,不能给这只碗的答案。可以枚举可能性 —— 例如试窗那条列出「压在原始釉面之上/压在重建基底之上/跨过两者的界线」三种情形及其含义,因为不讲这三种玩家就不知道为什么该做这个动作;但不得断言这只碗是哪一种。

**不许说黑话。** 试玩失败的直接原因之一是界面把内部 token 摆出来当情报。有一个例子特别典型:求解器输出的阻断未知里有一条内部键叫 `identity-whether-late18`,**键名本身就把候选答案念出来了**。这一层正是要拦住它 —— 它对玩家的说法是「身份方向还没定下来」。

**字数护栏:`whyShort` ≤ 60 全角字。** 这是防止决策面那一行随时间膨胀的 lint,**不是产品数值**(它不改变任何游戏行为),所以不进 `PARAMS.md`。当前实际最长 33 字,护栏尚未起作用;若将来普遍贴顶,说明该重新想决策面的信息密度而不是抬高护栏。

## 机器已验

```text
node check.mjs        # 输出留档在 check-out.txt
通过 15 项,失败 0 项
```

- **覆盖率 8 项:** 22 个动作、15 条可达线索、10 个证明角色、8 条登记未知、2 条路线、4 个阶段全部有文本;188 条文本无空串;反向检查确认没有描述不可达对象的多余条目。可达线索由 `outcome()` 在「无事实」与「全事实」两种输入下求并集得出,所以带分支的动作两条分支都算进去了。
- **泄题 6 项:** 不含 `expectedProfile` 六个轴值中的任何一个;不回音 `late18` 这类把答案写进键名的记法;不含阈值、`supports`、`posterior` 等夹具技术量;不含 `latent.*` / `PROOF.*` / `obs.*` / `RELATION.*` / 动作 id 等内部标识符;对照 49 个事实名确认无 camelCase 泄漏;未知的人话说法不复述内部键。
- **护栏 1 项:** `whyShort` 18–33 字(上限 60),`whyLong` 102–221 字、平均 156 字。

## 人工复核(机器查不到,不假装被覆盖)

1. **语义泄题。** 机械检查只能拦英文 token。「这段中文有没有暗示答案」需要人读。已知的边界情形是试窗那条枚举了三种情形,其中一种恰好是本案真相 —— 作者判断为必要且无暗示(三种并列、无倾向性措辞),但这是自报告,请复核。
2. **是否真的读懂了。** 这是全部工作的目的,而机器一概不能证明。非专业玩家读完「为什么重要」能不能说出该不该花这笔钱,只有真人测试能答。
3. **领域正确性。** 底足信噪比、紫外阴性的双重解释、点位不可外推、层序定因果这些说法来自项目此前的限定领域复核结论,但本文的具体措辞未经专业复核。
4. **火候。** 22 条 `whyLong` 是否长短一致、是否有几条写得像说明书,需要通读判断。

## 边界

- 不改任何冻结字节;只 `import` 求解器夹具与切片的 `case.mjs`,全部只读。
- 不决定地图怎么画。它给的是文本与关系语义,渲染是下一步的事。
- 不是数值工作。费用档位与调查机会仍在 `PARAMS.md`,与本文无关。
- `case.mjs` 的正典结局表决定每个动作在本案落到哪个事件,本文按该表写;若正典表变,本文要跟着改。
