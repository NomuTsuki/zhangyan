# 第一器物确定性作者场景夹具 v1

Status: Validation-only / Isolated from product code

这组文件把 v0.3 作者合同变成可执行反例和换序检查。v1 在历史 v0 夹具上重开领域阻断项并加入档案关系轴；负责人测试已运行，独立只读复核结论另见新的确定性 Evidence。它只回答“同一组规则输入会产生什么后果”，不回答玩法是否好玩、数值是否平衡、检测是否符合领域实践、玩家是否理解，亦不构成产品架构。

## 隔离边界

- 只使用 Node.js 内置模块；
- 不导入、不修改 `prototype/**` 或任何 V2／V3 正式产品模块；
- 324 个联合状态来自 `2 Identity × 3 RepairHistory × 2 KeyMaterial × 3 Surface × 3 Stability × 3 Documentation`；
- prior、相容权重和阈值都是 **fixture-only technical values**，只为触发通过／拒绝分支，不得复制成似然、价格、阶段门或平衡参数；
- 相同轴集合的因子先合并；最多七组不同轴集合时，夹具穷举其应用次序。若边际保持约束不能得到与次序无关的同一结果，求解器返回 `MODEL_CONFLICT`，不以依赖单元 ID 的字典序伪造答案；
- 不同依赖单元若仍共享 `sourceIds[]` 或 `sharedLatentIds[]`，求解器返回 `MODEL_CONFLICT`。当前工具不代替未来联合潜变量求解；它只拒绝把尚未联合建模的相关观察当成独立票；
- 负向观察的原始“未见信号”和能力充分后才允许派生的范围事实分账；每种动作／方法另有负向原始事实白名单，能力不足的阴性事件不能借 direct 通道偷渡证明事实；阻断反证还必须命中目标主张登记的对象、区域、时间、材料层和量词，否则只形成范围限定；
- G2 的“重大重组”不能由事件直接提交结论布尔量。档案路线分别保存 T2 记录内部关系、记录—现器归属、事件—物证印证；三者只限制系统能否建立主张，不限制玩家行动。现器修复图和合法跨时点对应仍是两种事件印证，纯物证路线继续需要现器具名修复图、多角度逐区可读结构结果与物理跨时点重大变化；证明角色只登记见证资格，不额外增加概率票；
- 候选 T2／T3 记录可以先产生局部内容和后验变化；未完成归属时保留为 `suggestive`。记录内部、记录—现器、事件—物证六个关系槽中的任一直接冲突都优先投影为 `contested`，即使正向证据同时存在也不能被伪装成系统已经证明；
- X 射线使用多角度具名区域覆盖；材料基底／层序、表面点位／区域综合分账；稳定性结果带静态陈列条件；
- [golden.mjs](golden.mjs) 是另行编写的 BigInt 有理数黄金预言机：不导入求解器或夹具、不从求解器输出生成，也没有 accept／update 路径。它与求解器运行时隔离，并接受独立只读复核；现有文件和测试不能证明历史上的先写顺序或预注册；
- 非法输入以 `MODEL_CONFLICT` 加专属 `reason` 失败，避免“因另一个错误失败”却被误计为通过；
- STOP 快照带冻结阶段；验证入口对冻结快照继续追加证据返回 `RUN_FROZEN`；
- 求解器只是验证参考实现，不获得未来生产架构权威。

精确来源、哈希、继承白名单、v0.3 优先级和禁止回流表面见 [manifest.json](manifest.json)。

## 覆盖场景

- G1、G2、G3 可达；
- G2 收手，以及继续取得重复／无区分力／阴性未决结果后仍回到 G2；
- 候选档案早拿有局部价值但不直接形成 G2；T2／T3 六个关系槽的正证＋冲突探针均证明争议优先，不能被系统升格；
- T2 三个关系问题＋（当前物证对应 **或** 跨时点对应）、以及现器修复图＋逐区结构读数＋物理跨时点重大变化的替代证明路线；其中无现器修复图的档案跨时点分支具有两条已声明合法换序；
- T3 记录内部、对象归属和当前区域对应分别进入三阶段证明；
- T1／T2／T3 时间顺序出现直接冲突时只阻断三阶段 G3，不抹除已经成立的 G2；
- 点位基底／层序、表面点位／区域综合和条件化静态陈列进入 G3；
- 专业检测提前取得、后续上下文化、只计一次；
- 同源折叠、独立印证和依赖单元冲突；
- 共享来源／潜因被错误拆到第二依赖单元时 fail-closed；
- 相关 prior 下的跨轴边际保持更新若依赖内部 ID 次序时 fail-closed；
- 阴性结果能力门；
- 能力不足的反向结果不能派生“不存在”事实；命中错误范围的负向结果只能收窄而不能阻断主张；
- 表面／稳定性坏消息不越轴击穿 G2；
- 抽象作用域硬反证使 G2 合法降级，同时保留未被命中的身份／G1 事实；
- `weakens`、`bounds/refines`、`hard-counterevidence` 与 `logical-refutation` 分账；硬反证的 `contested` 和逻辑反驳的 `logicallyRefuted` 不混成同一状态；
- 两个边际过线但联合不足时拒绝假性 G2；
- 单项高级检测、单条胶线和单份文档在接近完成的上下文里仍不能成为答案键；单次 X 光即使覆盖重大范围也不能替代跨时点见证，单一来源、额外来源、错误覆盖、缺证明角色或缺原子事实也不能伪造档案跨时点槽；新增 OR 不放宽物理路线；
- G3 在具名非关键未知仍存在时成立，任一登记的决策关键未知则阻断 G3；
- 每个场景、每条已声明合法换序都逐一比对另行编写的黄金预言机：324 个状态、支持度、主张、冲突、事实分栏、事实来源见证、上下文激活见证、证明组、证明角色、重大证明路线、阶段和停手状态；
- 黄金预言机不独立覆盖诊断用途的完整 `marginals` 和完整 `evidence` 元数据；这些表面由换序全快照相等与定向断言覆盖，因此不得把黄金比对表述为“完整输出的独立预言”；
- prior、阈值、因子、动作／方法／事实分栏、反证关系／目标、依赖划分和场景顺序的非法输入均有 fail-closed 探针。

## 执行

在本目录运行：

```powershell
node --test .\contract.test.mjs
```

测试只向标准输出打印简短摘要，不生成或覆盖结果文件。通过仅表示当前夹具对 v0.3 候选规则产生了预期结构后果；它不证明数值平衡、领域准确、玩家理解或趣味，也不等于独立复核 Pass。
