# 试玩清单 — 知识地图切片 v0(约 10 分钟)

**怎么打开:** 双击 `slice.html`。不需要本地服务,不联网。

**这一轮要检验的是:自由探索这件事本身站不站得住。** 请不要照着下面的顺序玩,
**先自己乱点一局**,玩完再回来对照。你的第一反应比正确答案有价值。

## 变了什么(玩家能看见的话)

- 你可以按任意顺序调查,系统不给你唯一的下一步,也不锁流程。
- 刚查完的地点会变成一个「路口」,画出几条通向别处的路;那些路不标好坏。
- 有些地点去了什么也换不到。钱和机会照扣。
- 你自己决定什么时候收手。系统永远不会替你结束这一局。

## 请试这四件事,每件对应一个问题

1. **先自己乱点一局,直到你想收手。** 收手前先别看右边的阶段。
   → 你在收手的那一刻,**知道自己在赌什么**吗?(知道 / 不知道 / 说不清)

2. **重开一局,第一步就点最贵的「X 射线」。** 看右边「挂起与阴性」。
   → 那条「已经付过钱、但现在还读不出意义」的提示,是让你觉得**亏了**,
   还是让你觉得**这钱以后会兑现**?(亏了 / 会兑现 / 没看懂)

3. **点「紫外筛查补绘」和「再调一批语料复核」。** 看「足迹」里的计数。
   → 这两步没换到东西,你读成**「这条路不通,换个地方」**,
   还是读成**「系统在惩罚我」**?(换地方 / 惩罚 / 没感觉)

4. **用页面顶部的「路口层 开/关」各玩两三步。**
   → 关掉之后,你是觉得**更自由**了,还是觉得**没方向**了?(更自由 / 没方向 / 没差别)

## 另外三个问题

5. 「你现在能主张什么」这块,你**信**它吗?还是觉得它在藏东西?
6. 12 次调查机会:**太多 / 太少 / 差不多**?你有没有真正感到取舍压力?
7. 费用只写「免费／低／中／高」,你有没有想知道具体多少钱?(想 / 不需要)

## 请忽略

- **美术、配色、排版、动效** —— 全是占位,不是视觉方向。
- **地图上的文字重叠**(如果有)—— 已知,不影响这轮结论。
- **没有报价、没有市场、没有结局** —— 本切片只做到「收手」为止,后面还没做。
- **档案(T1／T2／T3)一开局就能查** —— 这是规则核的既有设定,不是这轮要评的东西。
- **「当前最优调查」推荐没有做** —— 故意的,理由见 README。你可以说你想要它,
  但不用把它的缺席当成 bug。
