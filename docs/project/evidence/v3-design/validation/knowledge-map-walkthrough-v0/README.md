## 为什么是两份而不是一份

`author-map.html` 里用**金色／青色**分账：金色是玩家最终可能看到的，青色是作者独有、永不透出。
这个分账就是 DEC-026 第 33 行禁令的可视化。两份文件并排看，可以直接检查"玩家侧有没有透题"。

## 修正了 sketches-v0 的什么问题

`../knowledge-map-sketches-v0/sketches.html` 把迷雾画成了**右侧一块渐变**并在右上角标注"未探索"，
读起来像"左边已探索、右边未探索"的时间轴。本版改为：

- 迷雾是**整体渐晕**（从中心向四周变暗），玩家在未知的中间，不是未知在右边；
- 无名暗区**散布在上、下、左、右五个方向**，且**没有标签**——给它们标签就等于提前描出作者隐藏节点轮廓；
- 地点坐标**全程固定**，任何一拍的同一个地点都在同一像素上（DEC-028：地图是玩家的记忆，搬动会破坏记忆）；
- 前沿画成**弧线**，长距离的开放问题不再横穿整图冒充通路。

## 2026-08-26 增补：站位与"通出去的路"

用户走查后指出：探测完一个节点，视觉上没有"温和导向"，缺少**站在路口**的感觉。
诊断是这样的——原版前沿总是连接**两个你已经知道的东西**（例如 `G2 → 材料分析`），
所以它读起来是"一张网上缺了一条边"，是**填空题**；而且地图上完全没有"你刚才站在哪"这个概念，
每一拍都像鸟瞰全图。改动分三层：

- **站位**：这一拍刚查完的地点画一个细圈。地标本身就是站位的最好例子——DEC-028 把 G 画在道路汇合口，
  所以站上 G2 时脚下天然有四条路；
- **通出去的路**：从站位辐射 1–4 条。通到**你已经知道存在的地方**的路直接连过去，不写字（那个地方自己有名字）；
  通向黑处的路只是一段伸进迷雾的短路，末端一个 `?`，旁边写**它可能回答什么问题**。
  费用、难度、成功率、那边有没有 Finding，一律不写；
- **别处的前沿变暗但不消失**：这一条是保住"你可以去任何地方"的关键。亮暗只表示你现在站在哪，**不表示哪条路更值得走**。

三个刻意保留的反例：第 4 拍的重复调查画成**一个没有路通出去的路口**（浪费一步最直白的样子，地图不骂人，只是不给路）；
第 6 拍的系统点名是**金色虚圈**，只在你按下那一拍出现，下一拍消失，永不变成常驻箭头（DEC-026 明确否决常驻唯一行动箭头）；
第 12 拍站在 T2 而通向 G2 的路被标为争议。

### 这一层已由 DEC-031 定案为设计思路

执行者当时把它标为待定案，理由是"按新近度重排醒目度"不在 DEC-026／029 授权范围内，
且有把玩家推向连锁式顺序探索的风险。用户 2026-08-26 给出定位，落成 [DEC-031](../../../../decisions/DEC-031-v3-exploration-rhythm-is-player-chosen-dead-ends-and-degree-are-the-lever.md)：

- 设计目标**既不是**跳跃式探索，**也不是**连锁式顺序探索，而是玩家**自发地在该连续时连续、该跳跃时跳跃**；
- 路口层作为**呈现**成立，但醒目度**不进入价值计算、不缩小排序定义域**（DEC-029 不变），路也不标价、不排序、不预告结果；
- 真正让玩家自发换地方的不是系统推荐，而是**玩家自己撞到的墙**——所以"没有路通出去的路口"不只是代价，它是节奏设计的主要材料（与 DEC-030 互补）；
- 指定杠杆是**死路出现频率**与**每个节点的连接边数（度数）**，但**现在不调**：复杂度膨胀、认知负荷升高、推理链条超长而失去扫雷那种精确感，三项风险已登记在案。

## 2026-08-26 修正：一处与作者答案键冲突的表述

第 12／14 拍原先写「T2 记录内容真实但**对象误归属**」，同时又写客观真相是 `THREE_PHASE`。
这两句自相矛盾——`THREE_PHASE` 的含义就是 T2 与 T3 都是**本器**真实的修复阶段，所以 T2 不可能是误归属。
冲突是在为切片读 `fixtures.mjs` 的 `expectedProfile`（作者答案键）时发现的：

```
Identity LATE18_EXPORT · RepairHistory THREE_PHASE · KeyMaterial KEY_MATERIAL_PRESERVED
Surface MIXED_CROSS_OVERPAINT · Stability DISPLAYABLE_LOCAL_RISK · Documentation COHERENT_PARTIAL
```

已按答案键改正：那组记录**确实是这只碗的**，系统整局标「争议」是因为玩家**没有建立起对象链接**。
改正后反而是更强的一课——**「系统建立不起来」和「事实为假」是两件事，系统只报前者**。

## 这两份文件不能证明什么

好不好玩、玩家看不看得懂、有没有能动性、路线成本是否支配——**一律未验证**。
