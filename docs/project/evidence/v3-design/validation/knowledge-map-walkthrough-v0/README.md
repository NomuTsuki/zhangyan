## 为什么是两份而不是一份

`author-map.html` 里用**金色／青色**分账：金色是玩家最终可能看到的，青色是作者独有、永不透出。
这个分账就是 DEC-026 第 33 行禁令的可视化。两份文件并排看，可以直接检查"玩家侧有没有透题"。

## 修正了 sketches-v0 的什么问题

`../knowledge-map-sketches-v0/sketches.html` 把迷雾画成了**右侧一块渐变**并在右上角标注"未探索"，
读起来像"左边已探索、右边未探索"的时间轴。本版改为：

- 迷雾是**整体渐晕**（从中心向四周变暗），玩家在未知的中间，不是未知在右边；
- 无名暗区**散布在上、下、左、右五个方向**，且**没有标签**——给它们标签就等于提前描出作者隐藏节点轮廓；
- 地点坐标**全程固定**，任何一拍的同一个地点都在同一像素上（DEC-028：地图是玩家的记忆，搬动会破坏记忆）；
- 前沿画成**弧线**，长距离的开放问题不再横穿整图冒充通路。

## 这两份文件不能证明什么

好不好玩、玩家看不看得懂、有没有能动性、路线成本是否支配——**一律未验证**。
文件里每一条"代价"都是结构性推论，不是观测到的玩家行为。只有无答案真人测试能举证。
