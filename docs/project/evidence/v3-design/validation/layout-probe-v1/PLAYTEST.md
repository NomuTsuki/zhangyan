# 三分钟布局对照

改变：v1 让结论靠近支持它的证据，并显式减少长线、交叉和边穿文字；没有改变节点、关系或结论内容。
到达：双击本目录 `prototype.html`；默认是“完整内容 / v1：结论牵引星座”。
对照：顶部可在“v0：逻辑岛”和“v1：结论牵引星座”之间来回切换。

1. 在 v0 点“这只碗就是档案里记的那一只”，再切 v1 点同一结论。
   问：v1 是否明显更容易在一个视野内找全它的依据？（是 / 否 / 看不出）
2. 在 v1 依次点“这只碗被大改过”和“改动分三次发生,不是一次”。
   问：两组依据能否逐条追踪，且共享证据的位置看起来合理？（是 / 否 / 看不出）
3. 点“显示全部关系”，比较 v0 与 v1 的完整图。
   问：v1 是否更像自由形成的知识地图，而不是流程图、题目步骤或四块分类？（更像地图 / 更像流程 / 没区别）
4. 在 v1 按“少量内容 → 关系成形 → 完整内容”切换，再倒序切回。
   问：虽然布局会调整，你是否还能找回先前的结论和局部关系？（能 / 不能 / 部分能）
5. 最后任选一个你觉得仍然最乱的结论。
   问：问题主要是距离、交叉、文字遮挡，还是节点分组本身不合理？（选一项或说没有）

暂时忽略：左右工作台、行动名称、费用、结算、G1/G2/G3 和正式美术；这轮只裁决中间知识图的空间组织。
