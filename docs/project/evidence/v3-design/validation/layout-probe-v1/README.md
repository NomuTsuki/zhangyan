# “已知与推理”结论牵引星座布局对照 v1

Status: **Experimental / validation only**

这不是新产品界面，也不是对地图语义的新决定。它只回答一个问题：

> 在保留自由节点图的前提下，让支持关系真正参与节点放置，能否使玩家更容易从结论找回依据，同时减少跨图长线、交叉和穿过文字？

## 打开

双击 `prototype.html`。页面是单文件、离线、电脑浏览器尺寸，默认显示完整内容的 v1 候选。

页面可以切换：

- 少量内容（6 条情报）、关系成形（12 条）和完整内容（22 条）三个同局快照；
- 被否决的 v0 逻辑岛布局与 v1 结论牵引星座布局；
- 点击任意节点，只看与它直接相连的关系；
- “显示全部关系”返回全图。

快照按钮只用于比较同一张图怎样长大，不是产品进度条，也不参与空间排序。

## 数据和语义没有换

快照由当前 `workbench-map-v0/session.mjs` 与 `projection.mjs` 合法重放。22 个行动全部通过 `take()`；任何一步被规则拒绝，构建会直接失败。

| 快照 | 情报 | Finding | 已查实结论 | 关系 |
|---|---:|---:|---:|---:|
| 少量内容 | 6 | 2 | 1 | 14 |
| 关系成形 | 12 | 2 | 2 | 21 |
| 完整内容 | 22 | 4 | 4 | 43 |

两种布局消费相同的节点、文字与 `latent / prereq / caught / supports` 四类关系，只比较坐标。没有复制共享证据，没有匿名中转点，没有分栏、时序轴、问题泳道或边捆绑。

## v1 的空间原语

1. 四类关系全部进入布局；`supports` 不再是画完布局才补上的装饰线。
2. 支持边有较短理想距离，超过阈值后附加二次长尾惩罚；结论支持度只做有下限的归一化，避免高连接结论吸塌全图，但不会把支持引力削弱到失效。
3. 同时支持多个结论的观察节点受到多个结论共同牵引，自然落在它们之间的折中区域。
4. 每轮先做确定性弹簧求解，再显式计算边交叉、浅角交叉和边穿非端点标签，对局部坐标做确定性 refinement。
5. 节点圆点、完整可见文字和留白共同构成碰撞矩形；标签互压与越界不靠视觉猜测。
6. 旧节点继承上一状态坐标。变化端点及邻域可动性较高，远端节点只受软锚；最后用共同旧节点做刚性平移/旋转对齐，不按出现时间永久钉死。
7. 相同图再次求解直接返回原坐标；节点和边数组顺序不改变结果。

这里直接实现并验证“受约束 stress / 弹簧 + crossing polish”的目标，不把 fCoSE、WebCola 或任何图库认定为产品依赖。若这个空间原语通过真人比较，再单独决定正式实现使用现有求解器还是图库。

## Experimental 参数边界

所有弹簧长度、强度、长尾阈值、碰撞留白、软锚、交叉惩罚与迭代次数集中在 `params.mjs`，身份均为 `experimental-default`：

- affects：节点间距、支持星座紧凑度、交叉、标签避让与旧图稳定性；
- does NOT affect：证据内容、结论成立条件、行动可用性、步数、费用与结算；
- status：experimental；
- reopen when：任一结论仍出现跨越大半画布的支持线、关系难以逐条追踪、或新增内容使旧地图失去方位。

这些数值不是产品默认值，因此不写入正式 `PARAMS.md`。

## 构建与检查

在本目录运行：

```text
node build.mjs
node check.mjs
```

- `probe-data.mjs`：从现有规则合法重放同一局；
- `params.mjs`：只属于本探针的 Experimental 参数；
- `layout.mjs`：星座布局、交叉 refinement、标签避让和诊断指标；
- `build.mjs`：生成三个快照与 v0/v1 对照，记录来源 SHA-256，输出 `prototype.html`；
- `check.mjs`：检查语义不变、全部边参与、确定性、矩形安全、共享证据距离和满图相对改善；
- `PLAYTEST.md`：三分钟真人布局对照；
- `template.html`：两种坐标共用的节点与直线关系 renderer；
- `prototype.html`：生成物，不手改。

## 真人判断边界

这份探针只等待玩家回答：结论及其依据是否终于形成可追踪的局部星座；共享证据是否看起来确实处在相关结论之间；地图是否仍像自由探索出的知识图，而不是流程图；切换快照后是否还能找回原来的局部结构。

不在范围内：修改 workbench、冻结求解器或夹具、行动与数值、Finding 机械价值、G1/G2/G3、地点层、正式视觉方向，以及证明游戏已经好玩或零背景试玩已经通过。
