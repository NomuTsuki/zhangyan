# 两段道路 · 两分钟尝试

变化：旧照片与现器核验后接入历史；先取得的差异报告能在后来的归属核验后接通。材料、原报告与位置保留。

入口：[prototype.html](prototype.html)，桌面浏览器；两个例子在上方切换。

对照：[之前的小示意](../xray-photo-logic-study-v0/prototype.html)把照片与核验并排放在条件汇合处；这一版把待核验关系放在材料之间。

1. 第一例先拍 X 射线，再找照片。留意当前结构是否已经有内容，照片的疑问是否只涉及它自己的归属。
2. 观察现器对应特征，再点“演示对象核验”。留意能否看出新接通的是照片的历史用途，材料位置和取得记录没有重来。
3. 第二例先点“演示区域比较”，再点“演示对象核验”。留意“记录间有差异”到“本器发生变化”的区别。
4. 重来第二例，交换两次报告的顺序。留意原报告是否仍能回查，以及是否接到相同的地方。
5. 可选：重来，展开“换一种报告结果”，选“未见可确认差异”，再做比较与核验。留意它是否保留报告而不强行生成变化。

反馈只需说哪里让你误会、哪一步看不出接通位置；不用逐条回答或复述逻辑。
