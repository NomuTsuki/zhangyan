# 前沿接续短复测（约三分钟）

本版：旧虚线朝实际接续位置生长，补通后退问句；互补与调查联系用无箭头细线，仍可探索的方向与能力限制保留。
入口：[当前高保真页](prototype.html)，构建 `11ea710e`，分支 `codex/xray-photo-local-study`。刷新旧标签页后开始；设置中关闭“减少动态效果”以观察过程。
对照：修订前 `370fc2c1` 的失败表现是新材料到达后旧虚线直接消失；[前后画面](../../../../../portfolio/2026-09-13-frontier-continuity/README.md)保留，不要求重新打开旧构建。

1. 新开一局，材料化验先“查各层的先后顺序”，再“化验要紧几处的底子”。旧虚线是否朝新材料的方向延伸，接通后才退问句？（是／否／看不清）
2. 重开，交换这两项顺序。是否仍能认出同一条路，并从先取得的一端长出？（是／否／看不清）
3. 重开，事故记录先“查有没有出过事的记录”，再“看事故记录说的是不是这只碗”，暂不观察整器。是否能看出旧问题接到了核验报告，而“实物相符”仍待调查？（是／否／看不清）
4. 任一局做“紫外检查”，再做试窗与区域综合。能力限制是否被保留，且没有被读成“已经证明不存在补绘”？（是／否／看不清）
5. 任一接通过程中缩小地图或切换语言。是否立即结束临时动效、保留正确结果，之后镜头不自行跳回？（是／否／看不清）

本轮不评价新增案件、交易系统或美术方向。机器结果与真人回答分别记录；已有失败反馈不被本次自动检查覆盖。
