# 高保真工作台 · 简短试玩

入口：[prototype.html](prototype.html)。电脑浏览器，建议先用常用窗口大小；从新局开始即可。
不用逐题作答，只反馈实际遇到的问题；下面提供容易暴露差异的操作，不要求沿它完成游戏。

1. 拖动碗，把底足转向自己，打开底足手段；再转回去，感受部位入口的出现和消失是否自然。
2. 先找更早的影像，再观察底足并核对没被改动的特征。留意核验飞到哪里，以及旧照片怎样接入历史用途；也可以先拍 X 射线，看看当前结构是否立即可读。
3. 自己挑几种碗外调查。看飞入、拉近、拉远接通这段反馈是否帮助定位，有没有晃动、过慢或打断思考。
4. 点一次信息、道路、疑问或判断，查看右栏；再取消选择。留意文字与路线是否分开、路是否好追踪，以及地图会不会抢走器物的注意力。
5. 打开已取得材料和调查记录，随后回到当前局。任何时候都可以收手，不必为了测试把所有判断做满。

如果发现问题，告诉我发生前做了什么、哪里让你停住即可。机器已检查的“可运行”不代表这些体验已经通过。
