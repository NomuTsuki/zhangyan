## 运行

`prototype.html` 已包含脚本、样式与绘画贴图，可在支持 WebGL 的桌面 Edge / Chrome 中直接打开。需要修改源码时，在本目录执行：

```sh
npm install
npm run dev
npm run build
node scripts/check-contract.mjs
node scripts/check-browser.mjs --offline --suite=all
```

本机 PowerShell 使用 `npm.cmd`。开发地址为 `http://127.0.0.1:4260/`。构建先执行 TypeScript 检查，再生成离线单文件与 `build-stamp.json`。浏览器检查脚本使用本机已有 Playwright 缓存路径；其他机器需要调整脚本中的运行时路径，不需要改游戏源码。

## 这版可以操作什么

- 拖动真实三维碗旋转；键盘方向键转动，Home 恢复朝向。只有朝向玩家的调查部位显示入口，底足须转出来。所有 5 个碗上入口、10 个碗外入口和 22 个手段来自既有动作表。
- 执行调查后，从左侧飞入实际取得位置，地图拉近，再拉远并生长真实关系。核验报告落到关系上；旧材料后来获得解释时留在原位。重复调查沿用原计费，不重新取得或重复飞入。
- 点击信息、道路、缺口、判断与共同条件汇流处，查看其真实依据及相关调查；悬停仅临时强调。点击空白、再次点击同项或 Escape 清除选择。
- 检视已取得的旧影像、现物、核验两端、结构示意与比较报告；回看调查历史，保留当时实际选择的比较材料。
- 右栏常驻四项判断概况，其余内容随选择展开。顶栏查看委托、调查记录、剩余机会及手动收手；机会耗尽不会替玩家结束。

## 规则、道路与文字分别负责什么

`src/engine.ts` 直接接入融合版 `local-session.mjs`、`graph.mjs` 与 `selection.mjs`。调查是否可做、怎样计费、取得什么、关系何时成立，全部读这些既有模型。高保真没有另写一套规则。

`src/map-layout.mjs` 先依据图中真实关系放置节点与道路，再为文字寻找空位。它从基础布局取位置时不传入标题，因此改文案不会把道路挤弯；选择也不会重排节点。真实的共同条件使用汇流菱形，替代证明路线各有入路。关系的显示细分保留原 `edgeIds`，不生成新的游戏证据。

`src/MapView.tsx` 只改变看地图的镜头。飞线不是永久关系，镜头移动也不改变节点的世界位置。会话先可靠落定，再播放可被打断的反馈；拖动、缩放、历史、重开、收手和弹窗都会取消旧镜头回调。这样保留空间记忆，同时让玩家看见这一步接通了哪里。

`src/BowlScene.tsx` 与 `src/MaterialViewer.tsx` 共用 `bowl-art.ts` 的三维器型和绘画贴图。旧影像与当前器物使用同一主体；阶段差异由额外修补表现区分。它们是本案的合成游戏材料，结构视图也是示意，不是真实历史照片或科学检测结果。素材来源见 [资产说明](src/assets/README.md)。

## 当前边界

此版支持 1280、1440、1920 桌面检查，没有手机布局。全览用于观察整体，详细阅读可缩放或点击右栏回查；最密集的全览状态下文字较小，不能据机器检查宣称可读性通过。极端调查顺序的标签位置仍可能离圆点偏远。

绘画、器型、镜头节奏、转动灵敏度与曲线幅度均为本轮 Experimental 呈现；相应参数记在项目 `PARAMS.md`。当前页不新增交易数值或市场结算系统，也没有改动冻结求解器、旧原型或旧测试。

新增自动检查与实现时的呈现参数选择触发 **review required**。机器证据、限定独立复核与真人体验分开记录；本目录随用户批准的高保真本地检查点保存，没有推送或部署。
