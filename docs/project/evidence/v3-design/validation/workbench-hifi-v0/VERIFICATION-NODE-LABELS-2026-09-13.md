## Scenarios covered

在 Edge headless 中通过真实碗上入口／器物外按钮执行调查，快照接口仅用于读取。以第1、8、16、22次调查为检查点，中英各在1280、1440、1920×1080检查，共24组渲染状态；44次实际调查包含全部22种手段，区域比较使用照片基底。逐一检查所有普通信息及报告名称、实际DOM文字框、报告圆点和图注。

对实际SVG路径独立采样，计入SVG遮罩，只检查已经显露的道路；核验文字不与道路相交、文字框无相互重叠或内容溢出。对全部抽样状态比较修订前后真实节点坐标和道路路径字符串，完全一致。四个报告短名逐一悬停、点击、Escape恢复，并比对会话序列化值，选择未改变调查进度。

来源专项额外覆盖先报告、后原记录、再整器的三步路径，以及报告收纳移动中收手／重开／换语言。最小缩放为20%；这些是当前设备上有限路径的回归结果。
