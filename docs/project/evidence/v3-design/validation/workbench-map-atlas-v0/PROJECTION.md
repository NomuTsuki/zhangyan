# 已知信息与关系生长投影

状态：Experimental。用户于 2026-09-05 批准整体修正后的独立对照；本文件记录本轮实际实现的语义，不将其升格为正式机制。

## 接口与信息边界

`buildGraph(solved, session?)` 返回 `nodes / edges / questions / stage / observations`。所有节点与关系的 `sourceIds` 都是本局观测 ID，表示可以回查的依据，不是独立证据数量。作者来源 ID 只保存在原始观测元数据 `originalSourceIds` 中。

- 节点采用稳定观测 ID，已成立判断采用 `claim:identity` 等稳定 ID。`group` 只描述已知内容的语义，供邻近与配色参考，不生成固定区域、话题包络或未来节点。
- `observations` 保留全部本局观测，含取得步骤、重复次数、动作、适用范围、状态、回查节点与关系 ID。同一观测被重复取得时保留多个 `steps`，不复制节点。
- 归属和实物对应报告可以在线上表达；只有原始档案与整体观察均已出现时才折入连接。任一端缺失，报告继续作为独立信息存在。不能为了连线生造作者已知、玩家尚未取得的端点。
- `questions` 是附着已知节点的开放疑问，包含解释和可主动查看的方法；它们不作为目标节点或未点亮的关卡。
- `stage` 直接翻译原求解器的当前 G 读数，不创建未来 G 节点，不改变 G1/G2/G3 含义。
- 图只读观测、事实见证、证明角色见证、语境激活见证、档案关系、完整路线状态、主张状态、冲突与已登记未知。它不使用旧 `proofWitnesses` 扁平槽位，不读取概率、隐藏后验、作者目标配置或事件因子，也不读取获取前置来造边。

## 22 个动作取得的内容

| 已有内容 | 图上的表达与边界 |
| --- | --- |
| 整体形制与可见修补 | 一个信息节点。肉眼修补分布不能自动推出重大重组 |
| 底足读数 | 一个信息节点。与整体制造特征共同用于身份判断 |
| 纹饰与色差 | 外观重整信息，不能等同结构大改 |
| 同期真品比对 | 比较信息；已取得的整体和底足向它连“参与比对”关系 |
| 比对复核 | 在已有比对身份中记录复核；原始复核观测仍可回查，不变成独立加分证据 |
| 对象连续性 | 独立核验信息，表示稳定特征对应；不能等同“全部档案属于此碗” |
| 多角度射线 | 先保存读数；缺解释前提时为 pending，补足后为 known |
| 紫外未检出 | limited 状态，说明检测能力不足以推出“没有补绘”；后续表面解释成立也不抹掉本次阴性记录 |
| 事故记录组 | 保留档案原文性质；摘要分别报告内部一致、对象归属、事件对应状态 |
| 事故归属核验 | 两端已知时进入档案—整体的有来源连接；否则保留独立报告 |
| 事故现器对应 | 同上，并明确“事件相符”和“归属此碗”是不同关系 |
| 较早影像 | 保留读数；对象连续性使它可用为较早时间锚点 |
| 跨时点比较 | 保留比较结果；物证入口与档案入口是不同报告，完整路线状态由原求解器决定 |
| 后期处理记录 | 与事故组分别判断内部、归属、对应关系，不能把后期局部处理都计到早先事件 |
| 后期归属核验 | 仅对应后期记录组，不代替事故归属 |
| 后期现器对应 | 仅对应声明的后期处理范围 |
| 关键点位基底 | 保留取样点位范围；不外推为整区化验 |
| 关键界面层序 | 保留形成先后；不能代替基底材质 |
| 试窗层压关系 | 点位关系，不自动外推为区域覆盖 |
| 表面区域综合 | 点位与区域综合间显示关系；保留覆盖范围与边界 |
| 承力与陈列条件 | 保留评估路径和静态陈列范围，不写成“这只碗结实” |
| 流转链 | 保留已追溯段的一致性和边界，不代替物证身份判断 |

## 明确关系的形成条件

| 可见关系 | 形成条件 | 不能推出的内容 |
| --- | --- | --- |
| 整体/底足参与比对 | 对应两份观测均已取得。该关联是本轮明确编写的比较语义，未由通用获取前置生成 | 单个工艺读数直接证明身份 |
| 补足解释前提 | 目标在 `contextualizedObservationIds`，且 `contextActivationWitnesses` 指出已取得的来源观测 | 仅有动作前置就能算解释关系；重新取得或重复计权 |
| 记录属于此碗 | 对应档案关系 `objectAttribution === established`，存在有效证明角色见证，档案与整体节点均已知 | 事件内容也已经得到物证确认 |
| 所述事件与实物相符 | `eventCorroboration === established` 且存在当前/跨时点对应角色见证；两端已知 | 档案对象归属也一定成立 |
| 归属与实物对应已确认 | 上述两项分别成立后合并为一条紧凑连接，两个报告均保留在来源与详情 | 三个核验维度可以相互替代 |
| 档案提供历史参照 | 已取得档案与档案入口跨时点比较，详情保留归属要求 | 档案路线已经完整成立 |
| 逐区结构用于跨时点比较 | 已有可解释射线与实物跨时点读数 | 两份读数就是两份独立证据单元 |
| 点位读数按区综合 | 试窗与区域综合均已取得 | 点位本身已覆盖整区 |
| 冲突/范围限制 | 原求解器冲突输出，或已取得档案关系冲突事实；存在已知端点 | 所有不利结果都能推翻阶段；范围外反证能改写本器结论 |

关系观测先取得、档案或整体后取得时，点会在两端齐备后转入连接。这次紧凑化会减少节点数，界面应保留取得归因与回查入口；这不是删除本局经历。

## 成果与共同条件

本轮不强制插入 Finding 层，也不根据“共享话题 + 两条观察”生成判断。局部认识主要体现在信息摘要与关系上。独立中间判断的额外种类留待对照反馈，不作为本轮实现前置。

只有原求解器判定已成立的主张显示 established；受到已取得反证或逻辑反驳的命题可以保留为 contested，不能显示为绿色成立。以下条件是详情中的解释，不是投影重新执行一套求解器。

| 成果 | 图如何解释依据 |
| --- | --- |
| 晚 18 世纪外销瓷方向 | 整体制造特征 **且** 底足读数 **且**（比对排除 **或** 对象连续性）。现器与档案是同一只的核验只是一路依据，不能取代身份命题本身 |
| 重大重组 | 完整档案路线 **或** 完整物证路线。档案路线包含记录内部一致、对象归属和事件对应的共同条件；当前对应与跨时点对应可替代。物证路线必须同时包含具体修补分布、可读逐区结构和跨时点变化 |
| 三阶段修复史 | 较早状态可解释，事故与后期记录组各自关系成立，且没有未解时序冲突。“三个阶段”不等于“做过恰好三次修补” |
| 可用于决策的连贯说明 | 原 G2、三阶段解释、关键基底与层序、表面点位与覆盖、承力和使用条件、流转链边界共同支持，并通过原求解器完整条件。不能只把材料、表面、稳定、来源四个非空槽位当成完整说明 |

主张边详情明确共同条件与替代路线。每个实际论证输入必须能通过可见关系接入：同期比对已有工艺输入关系；仅走对象连续性时，整体和底足分别直接连向身份，标明“共同条件”，不会被显示成孤岛。实物路线三项输入、三个历史时点以及整体说明的各项输入同样保留连接。

重大重组节点的来源只纳入原求解器确认完整的路线；不把另一条未完成路线的零散内容混入当前证明。归属报告虽然画在线上，仍必须出现在档案证明的来源中。

## 疑问怎样随已知生长

- 整体制造读数引出“放进历史参照会怎样”；可见修补另可引出纹饰、结构与记录等并行调查方向。
- 射线或影像尚不可解释时，把同一对象连续性疑问附着于这些已取得读数；前提补足后撤去这个疑问，保留新连接。
- 已取得档案只追问其中尚未成立或有冲突的关系。归属和实物对应全部成立后，不再提示重复核验。
- 仅有关系报告时，追问它所指原始记录是什么，而不预画原始记录或器物节点。
- 外观、阴性检测、试窗、基底或层序各引出它们自身能指明的解释边界。
- 已成立重大重组可以引出“这些改动发生在什么时点”；只提供未取得的早期影像/后期记录方法，不提前显示三阶段答案。它是可继续追问的历史问题，不是升级任务，也允许玩家带未知收手。
- 已登记允许保留的配方与非关键区域未知，仅在存在本局相关内容时显示；G3 不要求所有疑问消失。
- 本轮疑问是内容规则编写的有限集合，不是全图自动规划器；没有疑问不宣称世界已经查尽。方法显示和实际执行由工作台负责。
