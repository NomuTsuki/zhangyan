## 本轮范围

用户批准的方向是以已有信息、可读关系、开放疑问、可回溯成果组织同一张地图。取消统一的“证据 → Finding → 结论”强制层级；获取条件放回工作台；地图聚焦负责解释，不自动选择下一步意图。此处只批准独立可丢弃对照，不将新的呈现升格为正式产品机制。

本目录拥有新的地图投影、布局、界面、构建、检查及试玩说明。只读复用现有会话、动作、语义和冻结作者模型。不得改旧入口、冻结作者六文件、V1/V2、费用、步数范围、G1/G2/G3 含义。根目录治理文件不改；当前状态与行动记录只登记本次批准、产物及验证边界。

阶段仍显示原有语义的当前读数；地图里的绿色节点是本局已成立的具体判断，不预画未来 G 关卡。局部认识主要由明确关系与摘要承载，没有强制所有内容经过 Finding 层。可收拢只服务于一个已成立判断的依据，共享、跨处或仍有问题的内容继续可见；展开与历史返回会恢复已知位置。

## 实施合同

1. 明确观察、关系、当前判断与已知疑问的表达；每条可见联系保留证据来源，不把动作前置当支持关系。
2. 修正档案归属缺边与身份标签越界；关系来源读取本局输出与已取得事件，不把 proofWitnesses 当完整证明图。
3. 保留原始观察和共享证据身份。关系观察可以显示在线上，展开仍能回查。暂不可解释、阴性与重复不得被隐藏成未探索。
4. 问题仅依附本局已知，不预画隐藏目标或完整未来路线；共同条件与替代路线分开表达。
5. 同一画布内全貌、局部关系与详情配合；新结果只做归因提示，不代替玩家选择下一目标。已知节点尽量保持位置，允许有明确过渡的局部调整。
6. 使用真实桌面浏览器检查 1280、1440 与宽桌面；检查开局、档案接通、早拿后懂、满局、重复、重开、历史回看、收手与键盘交互。无手机断点或窄屏降级。

## 验证边界

机器检查只能证明限定投影、规则接线与界面行为。地图是否优雅、玩家是否理解、能否自然决定继续或收手，待真人验证。本轮新增检查，完成报告必须声明 `review required`，不自行作独立审查裁决。
