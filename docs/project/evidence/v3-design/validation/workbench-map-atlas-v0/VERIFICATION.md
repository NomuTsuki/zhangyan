# 已知与关系生长地图 v0：实现与验证

2026-09-05。用户批准的是整体修正后的独立 Experimental 对照，不是正式产品代码、数值或体验定案。

## Implemented

新投影以本局已知信息、明确关系、开放疑问和已成立判断组成一张地图。记录归属与实物印证变成可回查的联系；先取得的资料在获得上下文时接通；共同条件和替代路线保留解释与来源。修正旧身份、三阶段标签越界。工作台免费查看方法，实际调查沿用旧动作／会话；右侧解释选中内容，不自动派工。历史、收拢展开、重复、预算耗尽和收手保持可操作状态。

## Executed

在本目录执行（中文输出由 cmd.exe 重定向后以 UTF-8 读取）：

```text
node graph-check.mjs > graph-check-output.txt 2>&1
node layout-check.mjs > layout-check-output.txt 2>&1
node build.mjs > build-output.txt 2>&1
node check.mjs > check-output.txt 2>&1
```

另在冻结作者目录只读运行 `node --test contract.test.mjs`，输出复制保留为 `frozen-contract-output.txt`。根目录执行 `git diff --check`。没有运行会改写冻结 V2 成品的构建命令。

## Scenarios covered

- 投影：空局、六步档案 G2、连续性身份替代路线、早拿后懂、关系先取得、22个动作全部逐步状态、阴性、重复、范围、争议、反证与单证据反例；覆盖24个冻结场景及35个声明顺序。
- 布局：孤岛、桥接、多路汇合、冷图与逐步图、窗口缩窄、输入不变、最终 SVG 直线／圆角路径与节点文字几何。
- 浏览器：1280×900、1440×900、1920×1080的真实界面与22步满局；另外实跑两份旧资料接通、档案归属／印证来源、开放疑问按需显示手段、Enter操作、焦点回退、历史第0步／返回、收拢展开、重开、G2与G3收手。

## Observed result

`graph-check` **10/10**；`layout-check` **21/21**；冻结合同 **40/40**；构建与成品检查均 exit 0。旧入口和冻结作者文件共 **69份指纹一致**；`check.mjs`核对成品内联的7个模块及模板指纹，并扫描本目录文本的UTF-8、冲突标记与行末空白。

满局保留22项原始观察，显示21个节点与25条关系。共同来源不会复制成新的证据权重；被表达在线上的核对报告仍可从关系详情回查。

浏览器发现并修正的缺陷：历史工作台曾混入当前局状态；键盘操作重建DOM后曾丢焦点；复杂判断的多条边名曾有1对相交；道路端点曾被圆点遮住；历史返回及收拢展开曾改变旧位置。最终实跑确认：第0步不显示未来已做状态、历史禁执行；返回恢复22步与相同位置；展开恢复21节点和相同位置；Enter后焦点回到对应按钮或详情；选道路只显示该条关系名；箭头位于圆点外。控制台未捕获error。

## Residual risks

满局在较窄桌面需要地图内部滚动；长线、交叉和共线的阅读效果仍需反馈。进入明显不同的窗口尺寸会改变布局；同尺寸下的逐步调查、历史返回与纯收拢展开分别检查了位置稳定。动态疑问和共同条件措辞仍是Experimental。当前最小“收拢”仅隐藏只服务于一项判断、没有跨处关系及疑问的证据，不是完整的多层语义缩放系统。

**review required**：②新增测试，且根据浏览器箭头遮盖证据修改了布局端点的契约断言（圆心端点改为圆点外端点；没有放宽碰撞判定）；③执行中明确了疑问触发、共同条件连接、关系与观察合并等玩家投影细节；⑤界面的部分视图状态目前由直接浏览器检查覆盖，尚无持久自动UI回归。未改冻结规则核、旧测试、基线或容差。裁决留给用户转交的独立审查会话。
