# 三分钟试玩：五问共同聚焦 v0

1. 变化：右栏把一局收成五件可穿插调查的事；最后一件拆成关键材料／表面／稳定／来路边界四个状态。
2. 变化：点左侧位置或具体手段时，左、中、右会共同聚焦；实亮是直接回答，淡亮“牵连”是桥梁或前置。
3. 打开：电脑浏览器双击本目录 `prototype.html`，点“接了这活”；不要先看 README。
4. 对照：旧版是 `../workbench-map-layout-v1/prototype.html`，它没有常驻五问和三栏共同聚焦。
5. 先点“紫外照一照”，先别执行：能否一眼看出它跟右栏哪件事有关？（能／不能）
6. 执行“紫外筛查补绘”，再点右栏卡里的“在表面开几个小窗看层次”：你是否同时读懂“表面只有线索、不能当证据”，并看到三栏转到同一件事？（都清楚／语义不清／有栏断开）
7. 点“没被改动的特征”：一个问题实亮、相关问题淡亮“牵连”，这比全部同样高亮更好懂吗？（更好／更差／看不出）
8. 任意再走 3–5 步，再点五个问题和关键材料／表面／稳定／来路四格：它们像可以穿插调查的结构并减轻记忆，还是像五关加一张待办清单？（穿插且减负／仍像闯关／变成清单／说不清）
9. 最后按“收手”：你能否说出“我认为……因为……；……没查，所以我不敢说……”？如果不能，请告诉我最让你困惑的那一次点击。（能／不能）
10. 暂时忽略：黄色六边形 Finding 的去留、古董文字总量、最终美术、费用数值和手机布局；这些不在本轮。
