# 五问共同聚焦试玩 v0

Status: **Experimental / pending human verification**

这是不覆盖旧入口的独立试玩副本。它只验证两件事：玩家能否把一局理解成五件可以穿插调查的事；点击左侧位置或具体手段时，左侧工作台、中间“已知与推理”和右侧“现在该判断什么”能否自然指向同一件事。

## 打开

双击本目录的 `prototype.html`。它是单文件离线产物，只做电脑浏览器尺寸，不需要安装或启动服务。

对照入口是 `../workbench-map-layout-v1/prototype.html`。旧入口没有被本实验覆盖。

## 本入口改变的呈现

- 右栏常驻显示五个玩家问题；玩家可见层不使用 Q1–Q5 编号，并明确它们可以穿插着查，不是五关。
- 最后一问拆成“关键材料／表面／稳定／来路边界”四个小面，只读取既有求解事实，显示“未查／已有线索／已覆盖／暂时查不了”；这里的“已覆盖”只指这一面已有约定事实，不表示接手判断或 G3 已经完成。
- 点击左侧地点时聚焦该地点的全部手段，不替玩家暗选第一项；点击弹窗里的具体手段后再缩到这一项。
- 三栏共用同一份聚焦投影。右栏把“直接回答”与“只是桥梁或前置”画成实亮与淡亮；中间地图只高亮当前已经出现的节点及其直接一跳，不预告未来情报。
- `A.MAP.REGION_CONTINUITY` 按实际取得的观察分支显示关联：纯物证结果只指向重大重组，档案结果才额外牵连三阶段。

## 没有改变的东西

作者求解器与夹具、22 个手段、可用性、费用、步数、Finding、公理、地图布局、G1/G2/G3 含义均未修改。黄色 Finding 的机制价值和后续处置仍是已记录问题，不在本轮内解决。

## 构建与检查

在本目录运行：

```text
node check.mjs
node build.mjs
node harness.mjs
```

`check.mjs` 覆盖五问映射、Q5 四态、主要／牵连关系、条件分支、一跳边界和右栏匹配；`harness.mjs` 继续检查原有行动与语义投影没有漂移。机器检查不能证明这套联动自然或好用，最终判断必须来自真人试玩。
