# 三分钟试玩：主题背景与按需解释 v1

电脑浏览器双击 `prototype.html`，先别看 README；旧版对照是 `../workbench-map-focus-v0/prototype.html`。

1. 不展开开局卡的两个说明，你能否说出受托要判断什么、第一步该去哪里点？
2. 任意走 3–5 步：地图是否能自然读成“先有哪条，后来哪条才取得／才有意义”，而不是靠长线和交叉猜方向？
3. 节点背后的“相关：……”范围，你会读成同一问题下的归类，还是误读成已经成立的结论？点它时三栏聚焦是否一致？
4. 右栏卡和动作说明默认收起后，你是否更容易决定下一步？需要解释时，鼠标或键盘能否顺利展开，还是有重要信息藏得太深？
5. 最后按“收手”：你能否说出“我认为……因为……；……没查，所以我不敢说……”？
