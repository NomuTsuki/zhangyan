# 主题背景与按需解释试玩 v1

Status: **Experimental / pending human verification**

这是建立在 `workbench-map-focus-v0` 上的独立试玩入口，不覆盖 v0、`workbench-map-layout-v1` 或最早的 `workbench-map-v0`。它保留五问共同聚焦，并把用户点名的三项未办问题放进同一版真人对照：黄色 Finding、地图整体布局、古董文本负担。

## 打开

双击本目录的 `prototype.html`。它是桌面浏览器尺寸的离线单文件，不需要安装或启动服务。上一版对照入口是 `../workbench-map-focus-v0/prototype.html`。

## 本入口改变的呈现

1. **Finding 改为议题背景。** `graph.topics` 保存 `id / type / latentId / short / summary / memberIds`；其中 `type` 与 `latentId` 只供投影兼容和内部归类，不显示给玩家。议题在相关节点背后画低显著度包络，没有独立坐标，不进入边，也不冒充系统推出的结论。整块包络不抢节点点击，玩家点左上角的小标签才聚焦同一议题；提示始终说明“同一问题，不等于结论”。
2. **地图按逻辑关系整理。** 布局从已经查实的结论反向分层：直接支撑尽量靠近结论，多结论证据靠近几个目标的中间位置，前置／后来才有意义的关系继续往上展开。这里的上下是逻辑依赖，不是调查时序；节点仍会为整图可读性重新让位。布局只由 `layout.mjs` 返回 `positions / metrics`，主界面与历史回放共用同一结果。
3. **解释改为按需展开。** 开局首层只交代委托、核心问题、一步一手段和手动收手；三栏说明与“情报为何暂时没用”保留在折叠区。动作弹层先显示动作名、所问问题、步数费用与执行按钮，“为什么要紧”才展开短、长解释。右栏卡默认只显示状态、标题和可用手段数，点击或用键盘展开正文与手段；宽范围聚焦只高亮，精确聚焦某个动作时最多自动展开一张相关卡。地图图例与实验构建说明也不再常驻铺开。

## 这一版仍然欠什么

这不是“布局已经解决”的版本。实际入口尺寸 `1258 × 949` 的冷满图已经做到节点标签不互压、逻辑箭头不倒置，但仍量到 17 处连线交叉、24 处连线穿过其他标签；22 步渐进生长时个别旧节点仍可能大幅换位。它们是这次真人试玩要观察的残余，不是已经通过的指标。

## 没有改变的东西

作者求解器与夹具、22 个手段、行动可用性、费用、步数、证据计次、手动收手、双轨结算和 G1/G2/G3 含义都没有改变。议题背景与五问状态都只是玩家侧投影，不是新规则，也不替玩家作判断。

## 构建与检查

在本目录运行：

```text
node check.mjs
node build.mjs
node harness.mjs
```

机器检查只证明投影、布局接口和交互接线按约定工作，不能证明地图已经自然、文字已经足够轻。是否通过仍以 `PLAYTEST.md` 的真人上手结果为准。
