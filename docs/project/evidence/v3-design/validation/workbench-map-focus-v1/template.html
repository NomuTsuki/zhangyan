这一趟是受人委托

开局说明 · 随时可以从右上角「委托」再看一遍

你受人委托,替一位准备接手这只碗的人先看明白。

你要回答的是:它经历过什么,该不该接? 判断要说得出根据,也要说明哪些地方还不敢说。

  • 每用一个手段占 1 步;钱只记账,不限制你调查。
  • 觉得证据已经够了,就按右上角「收手」,由你亲自结束调查。
这三栏怎么配合

手上这只碗的疑点是:它像是被大改过。要把这件事说实,有两条路 —— 一条靠翻纸面记录,一条靠查实物本身。两条都能走通,也可以混着走; 走哪条取决于你的步数花在哪边。

  • 左边先列的是可以下手的位置和路子,不是具体动作。点开一处,才会看到这里能用的具体手段;上半对着碗本身看,下半查档案、送化验、比真品。
  • 中间那张图是你查到的东西和它们之间的关系,系统会自动替你连线,不额外收费。
  • 右边列着五件可以穿插着查的事。点左边一处,中间和右边会一起只亮相关内容;它不会替你排先后。
为什么有些情报暂时没用

有些情报刚买回来是读不出结论的,得等另一样东西到手才变得有用。这是常态,不是你买错了。
