可以先试这一小段：

1. 做“X 射线成像”，再做“更早的影像”。观察这两份内容是否各自能读懂，是否还感觉必须一起等待才能使用。
2. 看“底足与修足”。观察照片与现器之间的缺口，是否能分清先前缺材料、现在缺核验。
3. 在“没被改动的特征”中执行核验。看原路如何接通，再点照片下方出现的历史表述；留意是否误以为又得到了一份照片。
4. 点连接照片与现器的道路，再点右侧核验报告。留意能否自然回查这段关系的依据。

如继续试比较：先取得整器观察、X 射线和旧照片，在整器入口选择“用旧照片比较”，之后才观察底足并核验。也可重开后把核验放到比较之前；留意能否读懂两份报告分别贡献了什么。
