## 已核实的实现问题

当前冻结条件是 `X ∧ C → S` 与 `T ∧ C → H`：X 射线和早期影像分别与对象连续性共同满足各自的解释条件。X 射线不是 C 的获取前置，X 与 T 也不共同推出 C；两者的激活本身不等于最终判断成立。

fusion 把 X、T 的共同缺项画成二者汇向一个问号，形状容易被读成 `X ∧ T → C`。该问号只是界面中的相关问题，并非有明确运算的事实节点。黄色同时表达未解释材料、关系缺口和选择，外框也混用内容类型与选择反馈。紫线未把共同输入及输出完整呈现。

内容同样不足：材料标题与“解释前提”描述多为内部类别，没有交代玩家具体看到了什么，以及为什么这个前置在器物调查中必要。当前 X 射线的解释被 C 阻止，而 C 在玩家未主动取得早期影像时也可执行；其档案参照由事件自带，玩家侧没有充分说明。代码中存在这些约定，不构成其合理性的证明。
