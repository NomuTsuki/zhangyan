## Scenarios covered

1. 全部 22 个动作从 UI 可达；调查前置、费用、预算与重复调查沿用原会话；16 步真实 UI 路线使四项同时成立并达到 G3。
2. X 射线和早期影像先到，后补对象连续性，两份旧信息一起获得解释；图未把它们画成互相证明，没有复制获取。
3. 整器观察与事故记录先到，归属核对、实物印证分两次增强同一道路。变化检测包含同 ID 的语义增强。
4. 核验报告先于端点时只保留已取得报告；端点后来出现，道路可回查原始记录；没有未来信息节点。
5. 试窗点位到手产生范围问题，区域综合信息接续原前沿位置；基底与层序不会自动生成虚假的相互证明。
6. 六类选择、临时悬停、清除、Escape、键盘调查、历史恢复；回看不花机会，历史图与当前图不串状态；动画中重开／收手、减少动态效果均检查。
7. 1280、1440、1920 × 1000 的开局、中段与 22 动作状态；DOM 节点／问题框不重叠、标题无溢出、整页无横向溢出。地图自身保留正常滚动。缩放和滚动后选择判断，坐标、视野及缩放不变。
8. 图与选择纯检查覆盖冻结 24 场景、35 声明顺序；布局检查包括共同汇流、替代路线、前沿接续与实际多信息状态。没有用只有主路线能过的单一截图替代规则检查。

## Failures preserved and fixes

- [首次浏览器结果](browser-results-first-run.json)：曲线道路的包围盒中心可能落在另一节点上，自动点击没有命中道路。检查改为采样实际 SVG 曲线点并核对真实 DOM 命中目标；没有强制点击或放宽产品断言。
- [重复调查反馈失败](browser-results-repeat-feedback-fail.json)：重复事件在旧会话中可能归为 deadend，UI 只看 `kind=repeat` 会漏报。改按调查前已有 observation ID 检测，保留原节点并提示回看；未改会话分类或计费。
- 独立 P2 的历史返回修复：关闭旧浮层并清理悬停；键盘修复：重绘后恢复对应入口焦点并使用 `preventScroll`。已加入实际浏览器回归，独立复验通过。
- 连贯说明四方面补读既有 `stateLabel`，浏览器断言四项都有实际状态文字。
- 资产录屏首次缺少 Playwright FFmpeg，已安装其本地录屏依赖并补录成功；原先完成的四张 2x 截图保留，没有重新覆盖。此环境问题不计作产品故障。
