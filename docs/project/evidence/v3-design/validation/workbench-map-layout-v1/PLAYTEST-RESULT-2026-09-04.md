## 本轮总体判断

用户对新布局的评价是“现在比以前略好一点点了”。这只说明局部可读性出现了弱正向信号，不代表地图布局、推理逻辑或三栏结构通过。

当前新暴露的四组问题是：局部 Finding 名实不符；左、中、右三栏没有共同聚焦；地图没有把已有的有向逻辑整理成自然的自上而下结构；首案承载的古董概念和文字过重，遮住了本应更纯粹的长线推理。

## 1. 局部 Finding：主题分组冒充局部推论

### 用户问题

用户追问黄色六边形“系统自动连出来的”内容对推理到底有多少价值，并要求认真核实它对玩家认知的实际帮助。

### 已核实

- 当前投影只要至少两条非 suspended 观察共享一个 `sharedLatentId`，就生成一个黄色 Finding；它实际表达“这些线索属于同一潜在议题”。
- 它没有检查线索彼此相容还是矛盾，没有形成案件特定命题，也不进入 claims、阶段、动作解锁或结算。
- 原作者模型区分 `InferenceUnit` 与 `InferenceFinding`：前者组织共同依赖／议题，后者才是由多条观察只读派生、带适用范围和限制的局部结论。
- 因而当前六边形只有有限的归类、导航和记忆价值；它不能帮助玩家回答“这些证据合起来说明了什么”，显眼外观还可能制造“系统已经得出结论”的错觉。

### 已提出但未获批准的候选调整

- `sharedLatent` 只用于不可见布局聚类或低显著度主题提示，不再自动生成黄色结论节点。
- 真正 Finding 只有在系统能同时给出“现在可以说什么／因为哪些已得证据／还不能说什么”时出现。
- Finding 继承输入依赖，只压缩解释，不作为新证据重复计权；它与 G 的连线先只表达可追溯关系，不另造一套阶段判定。

用户本轮只要求先记录，**尚未批准实现这套候选机制**。

## 2. 三栏联动：一次点击应成为同一次认知聚焦

### 用户要求

点击左侧工作台的某个地点或手段——例如紫外线相关入口——中间“已知与推理”和右侧“现在该判断什么”应同时高亮与紫外线有关的内容。右侧推理桌不能继续像一份与工作台、地图分离的静态清单。

### 当前实现事实

- 点击左栏地点只打开动作浮层，不设置关注动作，也不重绘中栏或右栏。
- 执行动作后才会重算三栏并播放新证据飞入；这是状态更新，不是浏览时联动。
- 新布局唯一的聚焦状态是中栏 `focusedNodeId`：点击地图节点只突出其中一跳邻居，其余地图变暗；左栏和右栏不响应。
- 右栏只有一条较弱的反向路径：点击建议手段可按 `actionId → place` 打开左栏浮层，但地图不高亮。
- 所需主键已经存在：观察节点与右栏建议都携带 `actionId`。当前缺口是共享的“当前关注对象”状态，以及从这个对象向三栏展开关系的统一规则。

### 尚未裁决

- 高亮只覆盖直接相关项，还是展开完整的上下游推理链；
- 已取得证据、尚未执行的手段和右栏缺口是否采用不同醒目度；
- 从中栏或右栏点击时，是否完全对称地反向联动另外两栏。

## 3. 地图方向：逻辑自上而下，不是取得时间轴

### 用户要求

用户要的是接近 Ron Gilbert 依赖图的整洁逻辑感，同时保留本游戏没有固定时序、可以自由探索的性质。地图不应重新变成做题步骤或时间泳道，而应让已有因果／依赖关系自然形成大体自上而下的阅读顺序。

两种有向关系必须仅凭图示就能读懂：

- `prereq`：箭尾那条先到手，箭头那条才拿得到；
- `caught`：箭尾这条后来到手，才让箭头所指的早期线索获得意义。

二者箭头都表达逻辑作用方向，但取得时序含义不同；因此“自上而下”应按逻辑依赖分层，不能把纵轴直接解释成游戏时间。

### 当前实现事实

- 两类边在数据里已经有正确方向，渲染也有箭头。
- 当前自由布局只把它们当普通弹簧关系，没有把方向转成层级约束，所以箭头可能横向、斜向或来回穿插。
- `prereq` 只在目标观察已经取得后回顾显示；它目前不是一张预告“下一步还缺什么”的解锁图。
- 右侧判断项没有被纳入同一条视觉逻辑链，玩家不能自然读成“观察 → 局部推论 → 现在要判断的事”。

### 方向边界

需要探索的是“自由拓扑上的逻辑分层”，不是恢复泳道、时间轴、固定行动顺序或唯一正确路线。具体分层算法、G 是否成为视觉终点、节点允许移动多少，均未裁决。

## 4. 内容负担：不是再换一轮词，而是减少首案承载的概念

### 用户要求

当前与古董相关的内容太重，文本过多、过复杂。用户希望保留古董背景，但把首案整理成更纯粹、更容易追踪的长线逻辑推理。

这次反馈不是“把行业词再改得口语一点”。需要后续检查：首案同时要求玩家记住多少器物知识、材料层、档案关系、修复阶段和判断问题；哪些属于推理必要条件，哪些只是背景真实性或作者建模细节。正式删减哪些内容、保留多少领域密度、长线推理的主命题是什么，尚未裁决。

## 当前工作假设（不是决定）

四组问题可能共享一个更深的原因：左侧工作台、中间知识图和右侧判断桌正在分别投影作者模型，却没有呈现为同一条可聚焦、可追溯的玩家推理。后续候选结构可以围绕同一语义链验证：玩家从一个手段出发，能看到它产生或可能产生的观察、观察参与的局部推论，以及这些推论正在改变的判断与仍缺内容。

这条工作假设尚未获得用户确认，不能据此直接重构。
