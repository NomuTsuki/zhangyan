# 三分钟布局试玩

1. **改了什么**：中间地图现在让结论靠近支撑证据，并减少长线、交叉和穿字；玩法与文字没改。
2. **怎么打开**：双击 `workbench-map-layout-v1/prototype.html`，点「接了这活」；电脑浏览器最大化。
3. **和什么比**：另开 `workbench-map-v0/prototype.html`，做同样的手段；旧版常把支持证据留在远处。
4. **动作一**：依次做「看整体形制与胎釉」「看底足与修足」「拿同期真品比一比」，点击出现的绿色结论。
5. 问题一：它的三条支撑线是否比旧版更短、更容易一眼追完？答：是／否／更差／更好／看不出。
6. **动作二**：继续做「X 射线多角度逐区成像」和「核对那些没被改动过的特征」，观察第二拍重排。
7. 问题二：重排后是否仍认得刚才的结论与证据小簇？答：是／否／更差／更好／看不出。
8. **动作三**：加入事故记录路线的四个手段，让第二、第三个结论逐渐出现。
9. 问题三：共享证据是否自然位于相关结论之间，而不是被某一个结论独占？答：是／否／更差／更好／看不出。
10. **动作四**：分别点击一个高连接结论和一条共享证据，再点地图空白返回全图。
11. 问题四：聚焦时能否不跨越大半画布说出“我认为这是 X，因为……”？答：是／否／更差／更好／看不出。
12. **动作五**：打开「历史回放」，在前后两个记录间切换。
13. 问题五：旧结构是否还能被认回，同时新关系确实整理得更清楚？答：是／否／更差／更好／看不出。
14. **这轮忽略**：开局教学、行动命名、决策面文案、费用与 G 阶段；它们不是本次布局伤口。
