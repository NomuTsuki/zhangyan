# 工作台／心智地图 呈现变体 v0

2026-08-31。[DEC-032](../../../../decisions/DEC-032-v3-workbench-map-separation-and-guidance-division.md)
的第一个可玩实现:左侧工作台、右侧心智地图与决策面。

**双击 `prototype.html` 就能玩,不用挂服务、不联网。** 只做电脑浏览器尺寸(
[DEC-033](../../../../decisions/DEC-033-v3-desktop-only-for-the-formal-slice-mobile-out-of-stage-scope.md)),
窄屏会横向出现滚动条,这是有意的,不是缺陷。

这不是产品,也不是美术方向。它要回答的是一件事:**DEC-032 那套结构,做出来到底能不能站住。**

## 它凭什么不是又一张草图

2026-08-26 那个切片被真人试玩判为"没玩明白",随后三份静态草图前提全部失效。这一版换了做法:

- **规则一律来自冻结求解器**,自己不判定任何东西。玩家看到的阶段、主张、冲突、
  "还差什么",全部是 `solveFixture` 的输出经翻译而来;
- **界面之前先做无界面自检**。`harness.mjs` 40 项检查全过之后才动 HTML
  (见 `harness-out.txt`);
- **在浏览器里实跑过**,不是只看代码。截图见下。

## 拓扑:每一层都能在冻结数据里指出出处

| 层 | 是什么 | 出处 | 谁付钱 |
|---|---|---|---|
| 观察节点 | 玩家挣来的一条情报 | `evidence.observationIds` | **玩家**:一次机会 ＋ 费用 |
| 逻辑边 | 情报之间的逻辑关系 | 见下四种 | 系统,免费自动 |
| 局部 Finding | 同一潜变量上聚起 ≥2 条观察时自动成形 | `sharedLatentIds` | 系统,免费自动 |
| 公理 | 已成立且无争议的主张,坍缩成一行并钉住 | `claims[x].established && !contested` | 系统,免费自动 |
| G 阶段 | **不在地图上**,只作顶栏一行读数 | `stage` | —— |

四种逻辑边,全部是冻结夹具里既有的关系,不是新造的机制:

1. **`latent`——说的是同一件底层的事。** 事件级 `sharedLatentIds` 相交。这是地图的主要连接组织。
2. **`prereq`——没有前一条,后一条拿不到。** `acquisitionRequires` 的事实由另一条观察见证。
3. **`caught`——后来这条把先前悬空的那条接住了。** `coverage.contextActivationWitnesses`,出处明确。
4. **`supports`——支持一条已定的公理。** `coverage.proofWitnesses` → `factWitnesses` 反查。

## 三件在实现中查明的事实

**一、`minimumSourceCount` 数的是来源并集,不是 witness 个数。** 满局 9 个证明角色都只有
1 个 witness 却到达 G3,因为单个 witness 可以自带两个独立来源。若按 witness 个数判断
"还差一个独立来源",会在 G3 状态凭空造出 9 条假缺口。harness 有一条专门守这个。

**二、`g3BlockingUnknowns` 在实况会话里恒为空。** 它是从 `fixture.unknowns` 这个**声明字段**
推出来的,而实况夹具不声明它。所以 `unknownRegistry` 里 `identity-whether-late18` 那类
带候选答案的键**不会**在游戏中显示 —— 那是潜在缺陷(投影层原样透传,一旦夹具声明就会泄),
不是正在发生的泄题。"还差什么"因此不能靠这个字段推,本层改为从证明结构反推,反而更实在。

**三、器物侧也存在事实门槛。** DEC-032 第三节说器物侧"门槛只来自钱与调查机会",但
`A.MAP.REGION_CONTINUITY` 长在器物上、却要求先有第二个时点。这不是剧情解锁,是逻辑不可能
(没有第二个时点无从对照)。**两者不矛盾,但 DEC-032 的措辞盖不住这种情况**,记在这里备查。

## 决策面

只装 DEC-032 第八节那四类,已定案的坍缩成一行离场。每条缺口摆出若干手段、都标价、**不排序**;
输出里不含任何 rank / priority / score / weight 字段(harness 有检查)。

`whyShort` 摆在决策面上,`whyLong` 点"为什么要紧"才展开 —— 这是用户选的分层方案。

### 两处执行中的判断,需要裁决

**一、多加了一档 `gap`(`review required`)。** DEC-032 第八节原文只写"差一件就能合拢"。
按字面实现的结果是:主张一旦缺两块以上就什么都不显示,玩家在 G1／G2 面对一片空白决策面
—— 那正是 DEC-032 要治的病。所以放宽出一档"已经动起来了,还缺 N 块",列出已落定与未落定的
槽位。**这是对已批准决定的语义扩写,不是纯执行。**

**二、决策面允许清空,但必须明说理由。** 干净走到 G2 时四类确实都空。这里刻意**没有**
把"玩家还没动过的主张"列出来充数 —— 那就是 todolist。改为给一句话:
"没有悬而未决的东西了……收手是一个正当选择;想往下走,就得自己开一条新线 —— 开哪条由你定。"
理由是第七节:开不开新线是纯意图,那是玩家的活。

## 公理钉固与布局

力导向布局,目标边长按画布面积与节点数动态取(写死会让节点少时缩成一团)。
**公理一旦定案就钉住不动**,需要自由重排的只剩活跃区 —— DEC-032 第十二节。

**衰减机制仍未定。** 第十二节说的蛛网式(越古早活动范围越小)没有实现,当前是二值的
"公理钉死／其余全动"。这是 DEC-032 未决问题第 2 条,双方本来就没有满意方案。

## 两拍动画

第一拍归因:从左侧刚做的那个行动飞一条线到右侧新入场的情报,周围先不动。停顿 520ms。
第二拍后果:整图重组(620ms 缓动),被这条串起来的那些先亮一下再归位。

## 历史回放

顶栏"历史回放"开一个独立浮层,**同时**回放当时的心智地图**与**当时的决策面,拖动滑杆逐步看。
不占主界面布局;当前活跃的地图与决策面始终留在主界面 —— 否则飞线没有落点。

## 文件

| 文件 | 作用 |
|---|---|
| `probe.mjs` / `probe-out.txt` | 探针:把求解器中局输出的真实形状打出来,供投影层照着设计 |
| `session.mjs` | 一局的状态机。复用切片的 `case.mjs`,不改冻结字节 |
| `projection.mjs` | 心智地图 ＋ 决策面 ＋ 读数的投影层。**无测试覆盖**,是"先加投影层试"那个岔口的代价 |
| `harness.mjs` / `harness-out.txt` | 无界面自检 40 项 |
| `template.html` | 界面。改这个,不要改 `prototype.html` |
| `build.mjs` | 把 6 个模块内联成单文件,并把源文件 SHA-256 写进产物 |
| `prototype.html` | 构建产物。**可双击** |
| `shot-empty.png` / `shot-mid.png` / `shot-history.png` | 浏览器实跑截图 |

`session.mjs` 与切片的 `harness.mjs` 有一份重复的会话机制。原因:后者在模块顶层就跑自检
并 `process.exit`,没法当库导入;它是通过中的测试文件,又属于已被推翻的切片,改它要送审而
收益只有四十行。**往后以 `session.mjs` 为准。**

## 机器验过的(证据在 `harness-out.txt` 与截图)

1. 40 项自检全过,含标签覆盖、四种边各自出现、公理坍缩、不泄题、手段标价、不排序;
2. `SLOT_FACTS` 防漂移:手写的槽位→事实表与满局求解器输出逐条一致;
3. 空局右侧确实没有任何节点(不是隐名,是压根没有位置);
4. 只有一条观察时不产生局部 Finding —— 不预告玩家还没有的结构;
5. 决策面全程 ≤ 3 条(上限设 8),清空时必带明说理由;
6. 逻辑边全程 ≤ 21 条,不是毛球也不是散点;
7. 玩家可见文本扫过 119 段共 1986 字,不含作者答案键、内部标识符、camelCase 事实名;
8. 浏览器实跑 10 步到 G2:10 观察 / 2 局部 Finding / 2 公理 / 16 逻辑边 / 决策面 2 条;
9. 12 个节点标签零压叠(用 `getBoundingClientRect` 两两求交,不靠肉眼);
10. 历史回放拖到第 4 步,同时回出当时的 5 个节点与当时的 6 张决策卡。

## 机器证明不了的,必须真人玩(见 `PLAYTEST.md`)

1. 领域语义写得让非专业玩家真的读懂了没有 —— DEC-032 自评风险最高的一条;
2. 左右分区在实际界面上到底清爽不清爽;
3. 两拍动画的节奏(520ms 停顿、620ms 重组)是不是那个"看清了再看后果"的感觉;
4. 决策面读起来像"多个缺口任你选",还是仍然像派工;
5. 公理坍缩有没有让玩家反而讲不出理由(与目标效果直接冲突,是重新讨论触发条件之一);
6. 意外之喜有没有真的发生过一次;
7. 新加的 `gap` 一档是帮忙还是又变成了清单。

## 边界

不含正式视觉语言与美术;不含任何新数值(费用仍是四档定性、机会仍是 12,见 `PARAMS.md`);
不含力导向的最终参数与公理衰减规则;不含双轨结算的判断质量一轨;不含移动端。
