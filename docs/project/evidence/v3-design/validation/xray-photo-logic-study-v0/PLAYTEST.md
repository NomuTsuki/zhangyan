变化：X 射线直接给出当前信息；旧照片的共同条件直接画成 AND 的一条缺失输入。
入口：[prototype.html](prototype.html)，桌面浏览器，分支 `codex/xray-photo-local-study`。
对照：fusion v0 把两份材料汇向同一个问号，容易暗示它们共同推出对象相同。

1. 点“拍这只碗的 X 射线”，再点“找一张旧照片”。能否直接指出旧照片缺的哪一项？（能／不能／说不清）
2. 点“演示核验：是同一只”。能否看清补上的是另一条输入，以及它与旧照片共同通向哪个判断？（能／不能／说不清）
3. 点“撤回核验结果”。旧照片仍在原位，上方 X 射线仍可使用；这个变化是否符合你的理解？（符合／不符合／说不清）

本次先忽略最终美术、真实照片、具体器物特征、费用与完整游戏。核验按钮只是演示开关，不是实际核对任务。
