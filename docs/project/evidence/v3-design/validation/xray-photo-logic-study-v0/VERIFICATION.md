## Implemented

独立、可双击的单 HTML；三个内存状态；两种材料自由先后取得；核验结果显式演示与撤回；AND 缺失输入与结果接通；来源与输出分列。没有修改旧游戏规则、冻结模型或旧原型。

使用本机已安装 Playwright 与 headless Edge，通过 `file://` 打开实际 HTML。完成六条操作核对，以及 1280、1440、1920 × 1000 下的初始、缺项与接通状态检查。最终源文件 SHA-256：`50bb2aecd9230581e2b51ede76a0442c6812450a9ecc09c80304cad06cd76183`。机器结果见 [browser-results.json](browser-results.json)。

## Scenarios covered

- 初始无已得材料，不能核验不存在的照片。
- 先取得旧照片、再演示核验，未取得 X 射线也可以成立过去归属。
- 后补 X 射线时，当前信息独立出现，键盘焦点保留在可操作入口。
- 撤回核验恢复原输入缺口，旧照片不删除、不复制、不换位，当前 X 射线仍可用。
- 先取得 X 射线即可使用当前信息；再取得照片时只缺照片自己的核验条件。
- 补齐核验后，缺项入路与输出道路接通。

## Observed result

六条操作核对通过，六个桌面尺寸／前后状态组合无 SVG 文字越界、无整页横向溢出；页面运行错误 0。照片节点在条件变化前后的几何位置相同。实现者实际查看了缺项和接通后的画面。

首次核查命令在 Node REPL 跨 VM 对象的深相等检查中停止；随后对固定布尔状态进行 JSON 值比较后继续。此为检查运行环境问题，未更改产品状态或断言含义。核对中修正了“先照片、后拍片”时把焦点交给已禁用按钮的问题；最终代码重新执行上述路径通过。
