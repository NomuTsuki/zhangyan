# HYP-002: 分层混合价值模型能够同时保留极端惊喜与可学习推理

Status: Testing

日期：2026-07-23

## 假设内容

用“器物品级混合 + 各品级内部价值分布”代替每类器物的单一正态分布，可以表现多数普通品、少量赝品与极少绝世珍品；市场事件通过重配各品级权重提高两端概率，比只增加一个正态分布的方差更可解释。

原型候选结构为：

```text
品级 Z ~ Categorical(器物类别、市场状态对应的权重)
log(真实价值) | Z ~ Normal(品级与属性对应的参数)
```

证据通过似然更新各品级权重；系统可同时显示“典型估值”与“保守收购上限”。候选方案是以后验中位数描述典型估值，以 Q15—Q25 等后验下分位数生成低风险上限。

## 为什么重要

单一正态分布左右对称、可能产生负价值，而且均值、中位数与众数相同，不能自然表达多峰真假层级。混合模型可以让演绎证据把估值区间下侧逐步移出赝品区域，也能让日报明确提高骗子与珍品两端的遭遇概率。

## 当前证据

- 用户确认希望普通品占主体，低概率出现极端赝品和价值悬殊珍品；
- 用户确认市场日报可提高两端概率，但该规律需要玩家通过案件摸索；
- 用户确认参考系统追求低风险，并应避免被高价值尾部推高；
- 当前 20、65、130 三真相变体已证明隐藏真相可以与 NPC 对器物的认知分离，但尚未验证连续或混合分布。
- [EXP-006](../evidence/EXP-006-value-pricing-simulation-lab.md) 已用一类器物、五档混合与 10,000 局固定 seed 模拟验证：常态赝品/珍品为 `25%/3%`，市场扰动为 `35%/10%`；先验均值约 `123 → 205`，中位数约 `79 → 75`；默认 Q20 全样本覆盖 `79.9%`。

## 验证方法

先用一类器物完成五个品级、常态/市场扰动两种状态和三种证据质量的参数实验；再增加第二类器物与结构化试玩，比较均值、中位数、下分位数、极端遭遇率、推荐价变化和玩家对日报的学习。确认统计行为后，只把其中一类器物接入低保真原型。

## 成功与失败判据

- 成功：常态下中间品占主体，市场扰动同时提高两端但不使每局都极端；
- 成功：强证据排除赝品后，后验下分位数能够离开赝品价值区域；
- 成功：推荐价不会读取隐藏真相，且大部分时候低风险但不是必然成交；
- 成功：相同 seed 可复现真相、日报和后验轨迹；
- 失败：平均收益主要由极少数 jackpot 支撑，普通局选择失去意义；
- 失败：保守参考长期成为唯一合理选择，或长期完全没有成交可能；
- 失败：玩家无法从证据与日报理解分布为何变化。

## 验证成本

低。先做参数表和批量模拟，不需要真实市场数据库、第二案件或正式长期经济。

## 结果与影响

已进入测试。混合分布、两端市场扰动、全信号枚举、固定 seed 与 Qα 覆盖已通过技术验证；市场事件能否被玩家学习、极端收益是否会支配长期经济、不同器物类别是否需要不同分布结构仍未验证，因此暂不标记为 `Supported`。
