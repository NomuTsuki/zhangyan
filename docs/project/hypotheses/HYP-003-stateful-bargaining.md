# HYP-003: 受 NPC 状态约束的有限讨价还价能够增加深度而不退化为探底

Status: Testing

日期：2026-07-23

## 假设内容

讨价还价可以允许多轮，但轮数由 NPC 档案、谈判耐心、信任、成交意愿、压力、控制感、报价历史与证据支持共同约束。每轮报价同时改变 NPC 状态和后续接受线，使玩家不能无代价地反复二分搜索固定底价。

正式报价不再消耗调查行动点。调查预算约束检查、询问、证据对质和共同检测；正式议价使用独立的 NPC 谈判容量。该容量由 NPC 基础耐心、专业背景、性格、报价历史以及调查后形成的关系和证据状态共同决定。调试阶段显示精确容量，第一版参数有意较宽松；玩家仍可随时接受当前价或离开，不能因任一资源耗尽死锁。

证据与关系状态承担不同职责：共享证据更新 NPC 对器物价值的后验，可以触发事件驱动的明显重新估价；信任、压力、成交意愿和控制感主要改变合作、戒备、抵触等谈判档位、让步幅度和是否接受，不直接改变 NPC 对客观器物价值的判断。初始开价是有噪声的历史锚点，而不是唯一锚点或不可移动底价。

## 为什么重要

固定报价 60 只允许当前样片触发接受或还价，拒绝和离场在可达状态中几乎没有机会出现。完全禁止多轮报价会削弱人物与证据对交易过程的影响；无限报价则会把隐藏底价变成免费可测参数。

## 当前证据

- 用户认为讨价还价应同时是人物互动、演绎应用和状态干预，而不只是价格探测；
- 当前 NPC 四状态、历史惩罚和纺锤候选行为已经能承载逐轮变化；
- 当前交易终局已验证为零行动点可达，但多轮谈判容量尚未建模。
- [EXP-006](../evidence/EXP-006-value-pricing-simulation-lab.md) 已实现 1—3 轮人物耐心、逐轮状态更新、单调加价、证据只使用一次、四类回应状态空间与零 AP 终局；常态 10,000 局中，Q线上限内阶梯议价把平均成交价 `61.4 → 59.1`、成交后亏损 `9.0% → 7.6%`，成交率保持 `30.7%`。
- 用户确认 NPC 应承担自身信息不对称，开价可以高估、低估或缺失；玩家公开客观证据后，NPC 会更新认知并可能明显重新估价。
- 用户确认选择性披露不能跨 NPC 类型通用：行家或重视真诚的人物可能因片面披露迅速降低信任与成交意愿。
- 用户在 2026-07-27 明确否定正式报价继续消耗调查行动点，并要求以 NPC 设定、性格、此前演绎与当前状态计算独立议价空间。
- 用户在 2026-07-31 接受双资源和精确调试显示，并要求第一版议价容量先设得较宽松。

## 验证方法

已先枚举三类 NPC、三组关系状态、证据支持和六档报价比例，并模拟单次封顶报价与上限内阶梯加价。旧实验中的共享 AP 假设不再作为目标规则。下一步用较宽松容量接入高保真首案，验证“共享证据更新估值、关系档位改变让步、人物决定谈判容量”的分工和可读性。

## 成功与失败判据

- 成功：四类交易行为在合理档案和状态中都能触发；
- 成功：证据支持报价与无依据低报产生可解释的不同状态变化；
- 成功：玩家不能通过无限小步报价无代价反推底线；
- 成功：调查行动点与议价容量相互独立，任一耗尽后仍能进入合法终局；
- 失败：推荐价或固定加价序列成为支配策略；
- 失败：NPC 状态变化使接受线不断漂移但玩家无法理解原因；
- 失败：没有新共享信息时，NPC 估值仍被普通情绪微动频繁改写；
- 失败：谈判轮数引入新的死局，或第二套资源无法从 NPC 人物与演绎结果中解释。

## 验证成本

低至中。先做状态空间表和纯规则模拟，再决定是否进入 UI。

## 结果与影响

保持 `Testing`。双资源方向已经确认，既有实验仍能证明四类 NPC 回应可达和有限议价不会必然死锁，却不能证明新的独立议价容量合理。下一步先重写共享 AP 相关测试，再以较宽松容量进入玩家循环验证。
