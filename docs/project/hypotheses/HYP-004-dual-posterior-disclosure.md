# HYP-004: 双后验与有代价的信息公开能够形成多路径推理而不产生披露支配策略

Status: Testing

日期：2026-07-24

## 假设内容

在一个有限案件中分别维护玩家价值后验、NPC 价值后验和共享证据集合，并把证据分为私下观察、共同检测、选择性披露三种可见性，可以让玩家从模糊判断通过不同路径走向严谨判断。

信息量提升最快的路径通常要求公开关键证据、触发 NPC 口供或使用自动共享的检测，因此玩家需要在“提高自己的判断质量”和“让 NPC 同时重新估值”之间权衡。只公开利空信息不会对所有 NPC 都有效：外行可能接受玩家的解释，行家会识别证据的完整含义，重视真诚的 NPC 还可能因片面披露而显著降低信任与成交意愿。

对于缺少关键证据、价值分布较宽的器物，急售且风险规避的 NPC 可能更偏好立即、无条件的确定成交；掌握较好私有信息且愿意承担波动的玩家可以通过接走风险获得折价。但这种策略应当依赖证据质量、NPC 动机和玩家资金承受能力，而不是对所有未知器物都成立。

## 为什么重要

该假设决定《掌眼》的核心深度能否从“找证据后压价”提升为“管理双方认知、信息公开和风险归属”。如果只公开利空、全部保密、共同检测或立即买断中的任何一种长期支配其他路线，多路径演绎和人物差异都只会停留在文案层。

## 当前证据

- 用户明确接受 NPC 真诚但错误的记忆或判断；
- 用户确认快速降低不确定性的证据链更倾向要求公开证据并承担卖家重估风险；
- 用户确认选择性披露的效果应受 NPC 经验和性格影响；
- 用户提出对急售、风险规避 NPC 转移不确定性可以成为更优策略；
- 开发侧数值实验台已经实现双方动态后验、证据可见性迁移、真诚但可能错误的口供、事件驱动重新估价和立即买断风险转移；
- 固定 seed `20260724`、4,000 组配对案件的首轮参数中，五类代理死锁为 0、重复来源为 0，隐藏真相隔离回归通过；
- 首轮人物矩阵中，“只公开利空”在外行急售者和重真诚藏家上取得最高平均净结果，但在精明行家上由“按信息价值披露”领先，因此尚未形成跨三类人物的万能策略；
- 立即买断成交率在外行急售者、重真诚藏家、精明行家中分别约为 `57.9% / 36.6% / 25.3%`，方向符合风险转移集中于急售者，但行家命中率是否仍过高需要继续调参；
- 上述结果仅是纯规则自动代理的技术实验，不足以证明玩家能理解披露代价或真实选择会健康分布。

## 验证方法

先做一个不接玩家 UI 的最小双边信息实验：

- 只使用 1 类器物、4—5 个品质/价值假设；
- 配置 6—8 条证据、3 个证据族、3 条 NPC 私有事实或口供；
- 区分私下观察、共同检测、选择性披露；
- 配置外行、普通藏家、行家各至少一种专业背景，并叠加开放、重视真诚、风险规避等个性或动机参数；
- 让证据只按 ID 计权一次，同族相关证据使用递减信息增量；
- 固定 seed 比较全部保密、全部公开、只公开利空、按信息价值披露、立即买断转移风险五类自动测试代理；
- 记录双方后验熵、每点行动的信息增益、重新估价次数和幅度、信任与成交意愿变化、成交后亏损、判断质量、净结果、终局与死锁；
- 回归验证同一可见历史在不同隐藏真相下产生相同 NPC 决策。

## 成功与失败判据

- 成功：至少两条证据路径能把模糊判断推进到可交易的严谨程度；
- 成功：快速降不确定性路径确实付出共享信息、行动点、货币或价格重估中的至少一种代价；
- 成功：只公开利空不是跨 NPC 类型的长期支配策略；
- 成功：按信息价值披露能在判断质量、长期净结果或风险控制中至少一项稳定优于机械披露策略；
- 成功：风险转移只在急迫度、风险厌恶、证据宽度和报价条件适合时占优；
- 成功：所有报价模式和行动点边界均有零成本终局，不产生死锁；
- 失败：公开关键证据几乎总是使玩家处境更差，导致理性玩家回避证据链；
- 失败：行家 NPC 只是固定惩罚选择性披露，而不是基于其可见证据和个性作出反应；
- 失败：立即买断成为对高不确定性器物的无脑扫货策略；
- 失败：价格跳变无法从后验、动机或谈判档位中复现和解释。

## 验证成本

中。需要扩展现有数值实验台的数据结构和批量策略，但仍可限制在单器物、有限证据图与纯规则模拟，不需要先改教师演示 HTML。

## 结果与影响

进入 Testing。结构层已经实现并通过自动回归，首轮参数没有出现跨全部 NPC 的单一披露支配策略，但“只公开利空”在两类人物上仍偏强，立即买断对精明行家的成交率也可能偏高。下一步先让用户审阅开发实验台，再针对人物差异、口供价值、公开成本和买断门槛调参；在形成更稳定的策略翻转后，才选择一条最小路径接入玩家循环。
