# 《掌眼》判断质量评分修正规格

日期：2026-07-31

状态：已确认并实现（2026-07-31）

适用范围：首案规则核心、高保真教师演示、开发调试复盘

## 1. 问题与目标

当前判断分主要回答“玩家最终选择是否符合可见后验下的期望收益”，却把结果呈现为“证据充分”。只要一条证据把最大后验推过 `55%`，且玩家选择了当前期望收益较高的买入或拒绝，判断分就可能直接达到 `100 / SSS`。

本轮目标是：

- 保留“只读取玩家当时可见信息、不读取隐藏真相”的边界；
- 区分决策是否合理、后验是否收束、证据链是否稳健；
- 普通单条强证据不能再获得 SSS；
- 极少数真正锁定整案的决定性证据可以单独获得 SSS；
- 不在玩家主界面增加一排新数值，精确分项只进入开发复盘。

## 2. 已确认的等级政策

| 当前证据结构 | 判断质量最高档 |
|---|---:|
| 没有证据 | B |
| 单条弱或中等证据 | A |
| 单条普通强证据 | S |
| 单条局部锚点证据 | SS |
| 完成交叉验证 | SSS |
| 单条整案决定性证据 | 可以获得 SSS |

等级上限表示“最高可能达到”，不保证玩家一定得到该档。最终决策不合理、后验仍然分散或存在未解决冲突时，等级还会继续下降。

## 3. 证据语义

现有 `strength` 继续表达证据本身的诊断强度：

- `weak`
- `medium`
- `strong`
- `anchor`

本轮新增两个与强度不同的概念：

### 3.1 独立来源组

每条物证、检测或陈述信号属于一个 `sourceGroup`。同一来源组只取贡献最高的一项，不能通过重复检查、同源展示卡或同一 NPC 的多段改写重复加分。

首案可使用：

- 漆面；
- 底款；
- 接口；
- 锁扣；
- 内腔木胎；
- 隐蔽标记；
- 专项检测；
- NPC 陈述。

### 3.2 推理维度

每条信号标记其主要回答的一个或多个 `dimensions`。首案使用：

- 木胎与制作年代；
- 近现代修复；
- 年代与部件一致性；
- 来源与工艺身份；
- 价格背景。

两条来源不同、但只重复证明同一局部事实的证据可以增加可信度，却不能被当作已经覆盖整条演绎链。

### 3.3 整案决定性证据

新增严格的 `caseDecisiveFor` 标记。它只用于能够直接排除本案其他主要解释、锁定某一可见假设的极少数证据。

- “检测到合成胶”只确定存在现代胶，仍不能判断是整体仿制还是旧物重修，因此只是局部锚点；
- “现代板材生产批号”能够直接锁定整体现代制作，可以标记为整案决定性证据；
- 不因证据名为 `anchor` 就自动获得决定性资格。

决定性资格只在“该证据已经被玩家发现”且“当前可见后验的主导假设包含在 `caseDecisiveFor` 中”时成立。该比较不得读取本局 `truthVariantId`。

### 3.4 首案候选假设需要闭合的维度

以下表格描述玩家可见后验中的候选解释，不代表本局隐藏真相：

| 候选假设 | 获得完整稳健度所需关键维度 |
|---|---|
| 现代仿制品 | 木胎与制作年代 + 年代与部件一致性 |
| 旧胎重修真品 | 木胎与制作年代 + 近现代修复 |
| 被低估的珍品 | 木胎与制作年代 + 来源与工艺身份 |

“价格背景”可以影响玩家决策，却不能替代器物证据闭合上述关键维度。

### 3.6 首案 NPC 陈述映射

所有 NPC 陈述共享同一个 `NPC陈述` 来源组，因此同一人的多段回答不能构成交叉来源：

| 询问主题 | dimensions |
|---|---|
| 修复历史 | 近现代修复 |
| 来源 | 来源与工艺身份 |
| 开价依据 | 价格背景 |

陈述展示卡与其结构化信号仍然只计算一次。只有结构化陈述信号进入后验与稳健度，展示卡不重复计权。

## 4. 新判断质量模型

### 4.1 决策合理性 D

`D` 只评价玩家最终买入或拒绝相对当前可见后验下最佳选择的差距。

第一轮沿用现有 `utilityGap` 结构，保留重复低效行动与卖家离场的过程惩罚；原“无证据风险”和粗粒度“不确定性”不再混入 D，由 C 与 R 单独负责。

```text
D =
  clamp(
    round(
      100
      - utilityGap × 3
      - redundantPenalty
      - exitPenalty
    ),
    0,
    100
  )
```

本轮不同时重做不同价格尺度下的效用归一化；该问题留作后续单独平衡，避免一次改动混入两个变量。

### 4.2 后验确定性 C

使用归一化信息熵，而不是只判断最大后验有没有超过 `55%`：

```text
H(p) = -Σ p(v) × log2(p(v))

C =
  round(
    100 × (1 - H(p) / log2(真相变体数量))
  )
```

- 三种真相接近均匀时，C 接近 0；
- 后验集中到一个主要解释时，C 接近 100；
- 多条互相冲突的证据会维持较高信息熵，不能靠数量刷分。

### 4.3 证据稳健度 R

R 先按独立来源去重，再结合证据强度、推理维度覆盖和整案决定性判断。

只有 likelihood 对当前主导假设严格高于另外两个候选假设的可见信号，才算该假设的支持证据。反向或冲突信号继续参与后验 C，但不能反过来增加 R。

同一来源组只保留最高强度。NPC 陈述来源组的稳健度强度最高按 `medium` 计算，其具体 `confidence` 仍照常进入后验 C。两个以上来源要进入高稳健度档，必须满足：

- 每个用于闭合维度的来源至少为 `medium`；
- 其中至少一个来源为 `strong` 或 `anchor`。

第一版使用以下工作档位：

| 证据结构 | R |
|---|---:|
| 无可见信号 | 0 |
| 单一来源的弱或中等信号 | 30 |
| 单一来源的普通强信号 | 50 |
| 单一来源的局部锚点 | 70 |
| 两个以上独立来源，但未满足高稳健度最低强度 | 60 |
| 两个以上合格独立来源，但只覆盖一个关键推理维度 | 75 |
| 两个以上合格独立来源，覆盖多个关键维度但尚未全部闭合 | 90 |
| 两个以上合格独立来源闭合全部关键维度，或存在支持该假设的决定性证据 | 100 |

每个案件为三个候选假设配置所需的关键维度。评分使用玩家可见后验中的主导假设选择对应配置，不根据隐藏真相选择配置。

若两个候选假设后验概率相同，首案按“现代仿制品 → 旧胎重修真品 → 被低估的珍品”的固定候选顺序稳定选择主导假设；该顺序不得读取 `truthVariantId`。

### 4.4 综合判断分 J

```text
J = round(0.55 × D + 0.25 × C + 0.20 × R)
```

继续使用当前 D—SSS 数值阈值作为第一轮工作参数：

| J | 基础档位 |
|---|---|
| 0—39 | D |
| 40—54 | C |
| 55—69 | B |
| 70—79 | A |
| 80—87 | S |
| 88—94 | SS |
| 95—100 | SSS |

随后应用第 2 节的证据结构上限。

封顶后的判断档位是唯一允许进入综合成果等级计算的判断档位。原始 J、基础档位、证据上限和最终判断档位只在开发复盘中同时保留，不能让未封顶的基础档位继续抬高综合成果。

### 4.5 首案现有参数的预期变化

以下只是用首案当前 likelihood 手算的校验样例，不是承诺所有案件固定得到同一等级：

| 可见信息与合理决策 | C | R | J | 预期档位 |
|---|---:|---:|---:|---|
| 无证据 | 0 | 0 | 55 | B |
| 单条弱证据“新旧漆层断差” | 19 | 30 | 66 | B |
| 单条强证据“后刻底款” | 32 | 50 | 73 | A |
| 单条强证据“旧木胎氧化层” | 47 | 50 | 77 | A |
| 单条局部锚点“维修日期铅笔记” | 66 | 70 | 86 | S |
| 单条决定性证据“板材生产批号” | 94 | 100 | 99 | SSS |

表中 D 均假设为 `100`。如果玩家的最终选择不符合当时可见后验，D 与最终等级还会下降。

## 5. SSS 资格门槛

SSS 必须同时满足：

```text
J >= 95
D >= 95
C >= 85
R >= 90
```

并满足以下任意一条：

1. 当前主导假设的关键维度已经由至少两个独立来源完成交叉验证；
2. 玩家获得了一条明确支持当前主导假设的整案决定性证据。

因此：

- 普通单条强证据即使方向正确，也会显示为“方向合理，仍缺独立佐证”；
- 单条局部锚点可以得到优秀判断，但最高为 SS；
- 真正的整案决定性证据仍保留小概率直接锁定结论、获得 SSS 的乐趣。

## 6. 玩家界面与开发复盘

玩家结算继续只显示：

- 判断质量等级；
- 一句与实际限制对应的原因。

示例：

- `S：方向合理，但目前只由单点证据支撑`
- `SS：关键事实已经确认，主要替代解释仍待排除`
- `SSS：关键结论已锁定`

开发复盘展开显示：

- D、C、R 精确值；
- 独立来源组；
- 已覆盖与未覆盖的关键推理维度；
- 是否触发等级上限；
- 是否使用了整案决定性证据；
- 最终 J 与等级映射。

## 7. 回归边界

实现必须自动验证：

1. 无证据但碰巧作出正确方向选择，不能达到 SSS；
2. 单条弱、中、强和局部锚点分别受到预定上限；
3. 同源重复信息不能提高 R；
4. 多条冲突证据不能靠数量获得 SSS；
5. 两个独立来源覆盖关键维度后可以解锁 SSS；
6. 整案决定性证据在 D、C 达标时可以单独解锁 SSS；
7. 证据丰富但最终选择明显不合理时不能获得高判断质量；
8. 相同可见信息和相同决策在不同隐藏真相下得到相同判断质量；
9. 修改判断公式不能改变隐藏真相、真实价值、实际净收益和议价表现；
10. 玩家主界面不泄露隐藏真相或开发分项。

## 8. 本轮不做

- 不重新设计综合成果等级的品质、净收益和议价权重；
- 不同时平衡所有 NPC 状态与议价容量；
- 不扩写第二案件；
- 不把当前工作参数描述为已经完成长期数值平衡；
- 不把 D、C、R 永久加入玩家主界面。
