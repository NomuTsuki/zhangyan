# 固定地图接入：分段与动效交叉审阅

日期：2026-09-10。执行者：`fusion_road_geometry`（布局实现者，交叉审阅主线程的 `MapView.tsx` 与 `map-motion.mjs`；不是独立 QA 角色）。本轮只读产品源码，写入本目录的审阅脚本、截图和报告，没有改产品、规则或既有检查。

## 初始离线实测

初始离线页 SHA-256：`b11ff89d3a7866e8a689700e8c75425ecfdb8ca6898d8ad2c6b59b8711ea2656`。

在 1440 × 1000 的 Edge 页面，使用原生按钮执行整器、底足、旧照片、照片核验、事故记录、事故归属；随后在设置中关闭减少动态效果，再执行事故实物印证。没有注入会话状态、伪造点击回调、覆盖动画或使用假时钟。

初始证据：[完整数据](audit-initial-failure.json)、[接通阶段崩溃截图](initial-connect-crash.png)。

发现：

1. **进入 connect 阶段崩溃。** `RoadInk` 在 `phase === 'connect'` 时无条件读取 `timing.duration` / `timing.start`，而没有变化的旧路 `timing` 为 `undefined`。浏览器报告 `Cannot read properties of undefined (reading 'duration')`。因此本次没有到达原定 500ms / 900ms 接通采样；报告没有将缺失采样算作通过。
2. **旧汇流点被当成新内容隐藏。** 执行后 120ms，已有身份汇流点的 computed opacity 为 0。原因是动画计划把全部现有 junction 放入延迟表，而界面在 connect 前隐藏所有有延迟项的点。主线程在收到报告后已修源代码，尚待最终离线构建复验。
3. **已成立关系文字一起消失。** 同一 120ms 采样中，原有“归属已核实”与新“记载处理已有实物印证”的 opacity 都为 0。旧归属文字应保留；新增关系文字再随新段完成出现。
4. **增强遮罩从旧路起点开始扫。** 初始实际计划为 prior `[0,0.485]`、growth `[0.485,1]`、duration 1800ms。若 progress 仍在整条路上从 0 扫到 1，前约 873ms 只扫过已经成立的旧段，新半段没有生长。这一时长是根据实测计划与 SVG 遮罩公式推得；初始运行因崩溃未达到该时刻，不能当成已完成的 900ms 可视实测。
5. **命中范围仍可能覆盖未成立半段。** 初始 `MapView` 的 `road-hit` 使用完整 `d`，没有套入 `visibleSegments` 遮罩；静态判断其未显示的另一半仍可选中已有关系，而不是对应缺口。本项没有做浏览器专项点击，作为交互风险交给主线程，不冒充已复现结果。

正向结果：

- 初始实际 SVG 中，底衬和墨线都置于 prior mask 或 growth + progress 双层 mask 下，没有发现底衬脱离进度遮罩提前铺满的结构。
- 同一档案归属→印证过程的道路 `d` 完全相同。
- 实际 DOM 测量后的道路 `d` 与使用同一个真实图生成的固定布局一致，文字实测没有使道路重新布线。
- 120ms 时旧照片节点 opacity 为 1，旧材料没有作为新增节点再次淡入。

## 支持关系先后与取消：代码／函数核验

另用真实会话函数执行 16 步路线，将后期记录的实物印证留到最后；新增的只有三阶段判断与连贯说明判断。当前动画计划为：三阶段汇流 4240ms → 三阶段判断 5090ms → 连贯说明汇流 7390ms → 连贯说明判断 8240ms，结束 8500ms。逐条核对支持路起始时刻不早于来源新判断／汇流就绪，未发现逆序。旧照片取得次数仍为 1。此项是实际规则与动画规划函数的核验，不是整个 8.5 秒浏览器动画的视觉通过。

静态核对取消机制：`stopAnimation` 递增 token，取消 RAF，清理 timeout；延后回调和相机 RAF 都检查本次 token。测量结果不进入 `layoutMap` 的 useMemo 依赖，`placeMapLabels` 不改 route geometry。主线程负责原生 UI 的取消、重开与恢复回归，本审阅不重复其全套流程。
