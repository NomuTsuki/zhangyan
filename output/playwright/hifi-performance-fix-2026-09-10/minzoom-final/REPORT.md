# 修订页最小缩放专项复验

已覆盖 1280×1000 / DPR1、1440×1000 / DPR1、1920×1000 / DPR1、1920×1000 / DPR2，各自完成 0、5、17、22 份信息的检查与完整 22 次真实调查。16 个状态、77 个缩放/恢复/悬停/拖动窗口、16 次动画中缩小均完成；没有卡死、NaN/Infinity、页面空白、renderer crash 或 WebGL context loss。

输入锁定为独立 `final-prototype.html`，5,161,993 bytes，SHA-256 `10039aac47de84d8415c07db09c9d8d332c1ebc3fc42691565d845ec29730336`。旧 `minzoom-baseline/` 保持原样；本目录没有覆盖产品、原测试或构建。

## 范围与方法

每个视口首次从空局缩至20%，其后在5/17/22份信息状态做重复减号、3组Ctrl滚轮往返、全览恢复后缩至20%、固定标签位置悬停、空白处拖动与静止恢复。1920/DPR2完整图额外检查固定道路命中区悬停。

每个视口在第1/6/18/22步恢复正常动画，在结果计算结束、飞行开始后缩到最小；均回到idle，后续操作可继续。中间非检查步骤通过界面的“减少动态效果”缩短准备，未注入任何会话数据。所有调查都等待DOM `data-compute-busy=false` 和实际记录计数更新后才继续，不把Worker尚未返回当作页面无反应。

CDP累计指标、Long Task observer、仅记时间戳的RAF和地图DOM变更计数在有界窗口内采样；完整game snapshot只在检查点读取。截图在性能窗口结束后另行捕获。没有每帧克隆知识图。

| 1440×1000，DPR1 | 0/5/17/22 | 4次可取消、可继续 | 12.5ms | 0 / 0 / 0 |

- 77个纯缩放、悬停、恢复和拖动窗口没有Long Task条目。固定悬停及恢复后的静止窗口中，地图DOM变更、class变更、pointer反复进入/离开均为0，没有复现自发悬停闪烁。
- 16个包含真实调查结果接入的取消窗口有3条Long Task：**50、52、58ms**，均在第22步比较；其中最大RAF间隔62.5ms。不能把这些新结果接入的短任务称为稳定20%导致的持续阻塞，也不能将整套报告说成“完全没有长任务”。
- 所有最终状态都是22份信息、22个可见显示节点、`s=0.2`、`computeBusy=false`、`phase=idle`。完整图静态mask实测为**1个**，旧基线相同路线为34个；该结果证明渲染结构减少，不单独证明用户原始卡死的根因。
- 只有首次1280页出现一份Three.js shader浮点精度警告，没有页面异常或上下文丢失。

浏览器：Edge **152.0.4191.66**，headless；四个配置实际WebGL均为 **ANGLE / NVIDIA GeForce RTX 4080 Laptop GPU / Direct3D11**。完整GPU设备与featureStatus保存在`audit.json`。这些结果没有覆盖用户当时的前台窗口、集显/省电模式、其他进程或长期GPU资源占用，不能替代用户对首次卡死是否消失的再次体验。
