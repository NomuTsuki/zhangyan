# START HERE

## 项目

《掌眼》：2D 手机竖屏古玩鉴定与交易博弈游戏。

## 当前任务

先做低保真 UI 交互原型，不做正式美术，不批量生成内容。

## 需要打通的唯一关键路径

```text
来客上门
→ 查看古玩
→ 检查接口
→ 获得现代胶痕
→ 对照“从未修复”的陈述
→ 专业指出矛盾
→ NPC 改口
→ 送检后付款 / 风险折价 / 拒绝
→ 结算复盘
```
