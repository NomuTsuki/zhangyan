# 单局玩法与玩家体验

> 当前实现基线：2026-07-23。本文描述现行共享行动循环，不再把旧版“观察后进入一次态度对峙”的线性流程视为当前规则。

## 玩家核心动词

看、查、问、比、试探、出示、送检、报价、购买、放弃。

## 当前单局闭环

```text
接案与来客
→ 调查循环
   ├─ 观察器物：得到物证或检测方向
   ├─ 开放询问：固定 NPC 当前说法
   ├─ 引用证据追问/对质：改变证据链与 NPC 状态
   ├─ 付费专项检测：用更高行动与价值成本核验一个维度
   └─ 随时查看只读证据簿、背景知识或进入交易
→ 交易处置
   ├─ 按当前价格购买
   ├─ 提出折价
   └─ 拒绝交易
→ 局末双层复盘
   ├─ 客观结果：真实价值、实际净值、可达最优与机会损失
   └─ 判断质量：只根据当时可见证据判断该决策是否合理
```

调查和对话不是先后两个阶段。玩家可以“先看再问、问后再查、拿新证据追问、再回到交易”，证据与 NPC 状态会随历史持续变化。

## 共享行动预算

单局初始共有 6 点行动点，观察、询问/对质、送检和折价共用这一池资源。

| 动作 | 行动点成本 | 是否终局 | 主要产出 |
|---|---:|---|---|
| 观察一个位置 | 1 | 否 | 物证，可能附带小概率锚点线索 |
| 开放询问或引用证据追问 | 1 | 可能 | NPC 四状态变化、回应、陈述信号，可能触发 Storylet |
| 胶层专项检测 | 2 | 否 | 付 10 价值点费用，得到一个限定维度的检测证据 |
| 提出折价 | 1 | 可能 | 接受、还价、拒绝或离场 |
| 按当前价格购买 | 0 | 是 | 成交并结算 |
| 拒绝交易 | 0 | 是 | 不持有器物并结算 |
| 查看证据簿、知识卡或进入交易页 | 0 | 否 | 只改变浏览位置，不改变世界状态 |

购买与拒绝始终是零行动点终局动作。因此即使 6 点全部用于调查，玩家仍能合法结束案件，不会因“没有点数可交易”而死锁。

## 玩家需要共同管理的三类状态

- 行动点：只会线性下降，代表还可以付出多少调查和谈判成本；
- 证据：通过观察、检测和 NPC 陈述动态累积，改变玩家对三种真相的后验判断；
- NPC 状态：压力、信任、成交意愿、控制感会在每轮根据行动、证据相关性、表达方式和历史重复共同变化。

证据簿是只读信息仓库，不提供行动入口。实际观察、询问、送检和交易都从对应玩家页面发起。

## 一局怎样算“成功”

结局不能只看“买没买到”，而采用两个互不替代的维度：

1. **客观结果**回答“面对这件真实价值确定的器物，最终处置造成了多少实际得失，离完全知情时可做到的最好结果有多远”；
2. **判断质量**回答“只看玩家当时真正获得的证据和陈述，这个选择是否有合理依据”。

因此会出现四类有意义的结局：

| 客观结果 | 判断质量 | 结局含义 |
|---|---|---|
| 成功 | 高 | 真正掌眼 |
| 成功 | 低 | 侥幸得手 |
| 失手 | 高 | 判断合理，但客观失手 |
| 失手 | 低 | 看走眼 |

具体公式见 `03_NUMERIC_MODEL.md`。

## 调查的导向方式

- 每个观察位置提供背景知识与可验证事实，但不直接标注“下一步最优动作”；
- 线索使用“支持、削弱、需要与其他证据交叉验证”等温和表述；
- 小概率锚点证据允许早期幸运命中，但普通证据之间必须能形成可理解的后续方向；
- 无依据询问合法但通常效率较低；重复同一行动会继续消耗行动点并产生重复惩罚；
- 付费检测只回答一个限定维度，不能免费替代整局鉴定与交易决策。

## 不允许出现的体验

- 看到紧张表情即可判定撒谎；
- 全程强硬或全程温和成为无条件最优解；
- 没有证据也能靠刷同一对话逼出全部真相；
- 送检免费、无条件、一次性揭示整件器物价值；
- 行动点耗尽后无法购买或拒绝；
- NPC 回应直接读取隐藏物品真相，形成开发者视角的信息泄漏；
- 结局只看买没买到，或只看玩家主观推理是否合理；
- 调试公式、seed 和隐藏真相挤占手机玩家界面。
