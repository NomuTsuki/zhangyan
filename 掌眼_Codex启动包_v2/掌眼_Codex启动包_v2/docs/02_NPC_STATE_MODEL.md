# NPC 状态模型

> 当前实现基线：2026-07-23。NPC 采用“输入发散—数值归并—有限候选再发散—Storylet 收敛”的纺锤结构。

## 边界一：物品真相与 NPC 认知必须分离

同一局同时存在两个不同的信息层：

### 隐藏物品真相

- 决定器物的客观事实、观察结果、专项检测结果与真实价值；
- 当前首案有“现代仿制品 / 旧胎重修真品 / 被低估的珍品”三种变体；
- 只在局末向调试复盘完整解锁；
- 不直接决定 NPC 说哪一句话、接受什么价格或下一轮采取什么行为。

### 固定 NPC 认知档案

```ts
type NPCProfile = {
  id: string;
  label: string;
  beliefSummary: string;
  reservationPrice: number;
};
```

首案卖家的固定认知是“把家中旧物当普通老盒出售”：他知道来源说法不严谨，也不确定是否维修过，但不知道器物的客观真伪与准确价值。其底线价格为 55 价值点。

NPC 的回应读取认知档案、当前动态状态、玩家输入和历史；器物真相只通过玩家实际观察或检测进入证据链。这样可以保留戏剧性，又不会让 NPC 无意间泄漏他本不可能知道的真相。

## 动态四状态

```ts
type NPCState = {
  pressure: number;
  trust: number;
  dealIntent: number;
  control: number;
  phase: "relaxed" | "cautious" | "pressured" | "negotiating" | "exited";
};
```

- `pressure`：当前质疑和证据给 NPC 造成的应对压力；
- `trust`：NPC 对玩家沟通方式与交易诚意的信任；
- `dealIntent`：NPC 继续谈并完成交易的意愿；
- `control`：NPC 对当前叙事和谈判节奏的掌控程度。

四个数值都限制在 0—100。当前初始值为：

```text
压力 26 / 信任 58 / 成交意愿 72 / 控制感 68 / relaxed
```

常规对话后的阶段由状态派生：

```text
若已经 exited                    → exited
否则若 pressure >= 65           → pressured
否则若 pressure >= 42
      或 trust < 46             → cautious
否则                             → relaxed
```

报价期间显式进入 `negotiating`；只有行为解析最终选中“离场”时才进入 `exited` 并立即结算，不能仅因某个数值越界就把玩家留在无法操作的中间页。

## 历史层

每轮至少记录：

- 玩家动作、行动点成本与动作前后快照；
- 四状态逐项 `before / delta / after / reasons / formula`；
- 新增物证、检测证据和结构化陈述信号；
- 同一“问题 + 证据 + 态度”组合的重复次数；
- 所有候选行为、硬过滤原因、分项得分、基础分、seed 扰动和最终分；
- 选中的行为、Storylet 命中情况与最终回应；
- 累计检测费、当前价格、已触发 Storylet 与终局结算。

## 纺锤式处理链

```text
玩家输入与上下文发散
  问题 / 态度 / 引用证据 / 证据相关性 / 历史重复 / NPC认知
                    ↓
四状态 delta 归并
  pressure / trust / dealIntent / control
                    ↓
有限候选行为再次发散
  补充说明 / 模糊回应 / 部分承认 / 反向质疑 / 拒绝 / 离场
                    ↓
硬条件过滤
  去掉当前状态与历史下不合法的候选
                    ↓
分项评分 + 可复现近分扰动
  finalScore = Σcomponents + seededJitter
                    ↓
选择最高合法分
                    ↓
Storylet 与回应模板收敛
  一次性事实承认 / 有限回应 / 陈述信号 / 下一轮状态
```

这套结构允许同一问题因证据、状态和历史不同而产生不同演绎，但输出始终收敛到有限、可测试、可复现的行为集合，不会无限生成不可控剧情。

## 候选行为与硬过滤

| 行为 | 当前硬条件摘要 |
|---|---|
| 补充说明 | 信任至少 40 且成交意愿至少 25 |
| 模糊回应 | 控制感至少 22 |
| 部分承认 | 引用了相关且效力足够的证据，并且该主题的一次性承认尚未触发 |
| 反向质疑 | 压力至少 45，或玩家使用强硬表达 |
| 拒绝回答 | 压力至少 65，或完全重复同一行动组合 |
| 离场 | 成交意愿不高于 20，或压力至少 82 且信任不高于 32 |

候选评分的完整分项见 `03_NUMERIC_MODEL.md`。seed 只在合法候选的基础分附近提供 `[-1.5, +1.5]` 的轻微可复现扰动，不改变硬条件、不决定器物真相。

## Storylet 收敛

- Storylet 是状态、证据与历史满足条件后出现的一次性叙事收敛点；
- 当前对话主题的“部分承认”只触发一次，随后重复行动不能再次发放同一事实或证据；
- Storylet 可以写入新证据、陈述信号或阶段性承诺，但仍必须经过规则解析；
- 表现文本来自有限模板，内容依据 NPC 认知档案，不按隐藏真相切换台词。

## 陈述信号

每次 NPC 回应同时生成：

1. 面向玩家阅读的陈述文本或陈述卡；
2. 面向判断模型的结构化信号，包含唯一 `signalId` 和三种真相下的似然。

两者来自同一事件。后验只按唯一 `signalId` 计算一次，展示用陈述卡不会再作为第二份证据重复计权。

当前内容约束：每张 `kind: "statement"` 的展示卡必须由同一回合的 `StatementRecord signal` 配套生成；若以后需要没有结构化信号的独立口述材料，应新增明确来源类型，不能直接复用展示卡并期待其参与后验。

## 调试要求

局中桌面调试栏展示当前四状态、每项 delta、候选行为分项、硬过滤、seed 扰动、Storylet 与回应；手机玩家界面隐藏这些系统信息。

局末必须展示完整状态变化图和每轮公式，使以下链路可以逐项复核：

```text
输入依据 → 四状态变化 → 候选集合 → 过滤与评分 → Storylet → NPC回应 → 新证据/陈述
```
