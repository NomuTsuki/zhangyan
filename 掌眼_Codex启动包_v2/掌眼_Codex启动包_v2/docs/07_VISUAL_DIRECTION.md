# 视觉方向

## 推荐组合

现代新中式档案 UI + 暗色鉴定工作台 + 半写实古玩切片 + 风格化 NPC 胸像。

## 生产原则

- UI 用 Figma / SVG / 代码制作；
- AI 不直接生成带中文文字的最终界面；
- 固定一张店铺背景长期复用；
- 古玩采用孤立主体图和局部证据图；
- NPC 使用统一构图胸像和少量状态变体；
- 不要求人物与器物在连续场景中复杂互动。

## 颜色建议

- 象牙白：#F2EBDD
- 黛墨：#182522
- 漆褐：#3A2921
- 黛青：#294A52
- 朱砂：#A33A2B
- 旧铜金：#A67C3D
- 松柏绿：#45644D
- 正文墨黑：#272521

## 视觉优先级

1. 古玩与证据细节；
2. 信息清晰；
3. 对质阶段的状态变化；
4. NPC 人格；
5. 装饰与氛围。
