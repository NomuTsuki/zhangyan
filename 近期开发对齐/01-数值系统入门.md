# 数值系统入门：先只理解五件事

更新时间：2026-07-27

这份文档从你提出的“当前一共有多少数值系统”开始，但不要求一次记住所有公式。

## 第一层：只看五件事

现在的玩法可以先压缩成五个问题：

### 1. 这件东西客观上值多少

这是物品真相与真实价值。

当前演示只使用三个工作样例：

- 现代仿制品：20；
- 旧胎重修真品：65；
- 被低估的珍品：130。

这些数值是 Codex 为了验证流程自行设定的，不是已经确认的正式平衡。

### 2. 玩家和 NPC 分别知道什么

玩家与 NPC 各有一套独立判断：

- 玩家私下检查，只更新玩家自己的判断；
- 玩家公开证据或共同检测，NPC 才会得到这条信息；
- NPC 的真诚记忆和主观判断可能是错误的；
- NPC 不能偷看物品隐藏真相。

概率、似然和后验都服务于这一件事：表示“根据目前信息，各种真相分别有多可能”。

### 3. NPC 现在愿不愿意继续谈

当前用四个 0—100 的状态表示：

- 压力；
- 信任；
- 成交意愿；
- 控制感。

它们不决定物品真假，只决定 NPC 怎样回应、是否愿意检测、愿意让多少、是否离场。

目前不存在一组对所有 NPC 都最有利的固定区间。例如高信任通常有利，但高控制感对某些人物可能让其更从容，对另一些人物可能让其更坚持；压力过低可能方便沟通，适度压力也可能促成急售。具体方向必须结合人物性格和玩家动作验证，当前权重还没有通过设计验收。

### 4. 玩家还剩多少资源

先区分“可消耗次数”和“货币成本”：

- 当前实现：一套共用点数池，加上检测费和最终成交价等货币成本；
- 目标结构：调查行动点、独立议价容量，再加上货币成本。

成交价和检测费是成本，不是“还能行动几次”的点数资源。当前“讨价还价也消耗调查行动点”已经被你指出不合理，尚未修改代码。

### 5. 最后到底做得怎么样

至少应该区分：

- 实际赚亏；
- 讨价还价表现；
- 当时的判断是否有理有据；
- 如果没有成交，是躲过损失还是错过机会。

当前原型把其中部分内容压成“客观分”，已经出现零利润也可能 100 分的问题，因此需要重新定义。

读到这里已经足够参与第一轮决策。下面是可选的第二层。

## 四个容易混淆的词

- **实际净收益**：真实价值减去成交价和明确货币成本；
- **路径内后悔值**：旧公式只在玩家已经走出的当前路径附近比较，不能代表整局经营水平；
- **议价容量**：NPC 人物与当前状态允许玩家进行多少次正式议价；
- **谨慎参考价**：系统只根据玩家已知信息给出的保守辅助价，不是 NPC 底价，也不保证成交。

## 第二层：当前12组数值模块

以下是按“有独立输入、状态或公式”的方式划分，不要求背诵。

| 模块 | 它回答的问题 | 当前状态 |
|---|---|---|
| 物品真相与价值 | 实际是什么、实际值多少 | 结构保留，具体值待调 |
| 证据参数 | 一条证据支持哪些解释 | 工作参数 |
| 玩家后验 | 玩家目前相信什么 | 技术已运行 |
| NPC 后验 | NPC 目前相信什么 | 技术已运行 |
| NPC 人物参数 | NPC 懂多少、急不急、怕不怕风险 | 大量参数由 Codex 自行设定 |
| NPC 四状态 | 当前关系与谈判状态 | 技术已运行，权重待调 |
| NPC 回应选择 | 合作、回避、承认、反击、拒答或离场 | 技术已运行，分数待调 |
| 调查行动预算 | 还能检查和询问多少次 | 当前为 6，未平衡 |
| 检测与交易成本 | 已经付出多少价值 | 当前检测为 10，未平衡 |
| NPC 定价 | 当前开价、接受线和买断线 | 公式待重新审阅 |
| 玩家参考报价 | 基于玩家信息给出保守参考 | 当前使用 Q20，未确认 |
| 结算 | 实际赚亏、机会损失与判断质量 | 已发现设计问题 |

固定 seed 是横向的随机控制工具，不单独算玩法系统。它只让幸运证据和少量 NPC 波动可以复现。

## 哪些必须保持独立

### 隐藏真相与 NPC 判断

NPC 不应该因为系统知道真相就自动知道真相。

### 玩家判断与 NPC 判断

玩家私下看到的信息，NPC 不应该自动得到。

### 玩家参考价与 NPC 接受价

系统给玩家的谨慎参考不是 NPC 底价；NPC 愿意接受的价格也不等于物品真实价值。

### 实际赚亏与判断质量

一个人可能判断合理但运气不好，也可能毫无依据却买到珍品。

### 调查点数与金钱

它们可以被同一个行动同时消耗，但不应该合并成一种资源。

## 哪些会耦合在一起

```text
私下观察
→ 玩家证据
→ 玩家判断
→ 玩家参考价与判断质量

玩家公开证据
→ NPC也知道这条事实
→ NPC重新判断物品
→ NPC可能改变开价和接受条件

询问方式、证据和历史
→ NPC四状态
→ NPC回应、议价耐心和离场风险

真实价值、成交价、检测费
→ 实际赚亏
```

最强的耦合点是“共同检测”和“公开证据”，因为它们会同时影响信息、关系、价格和成本。

## 数值实验台与原型不是一套东西

数值实验台当前有两个开发实验：

1. 厚尾价值与有限议价；
2. 双后验、信息公开与风险转移。

低保真原型只吸收了部分思想，又写了一套首案简化参数。实验台运行成功，不等于原型数值已经合理。

目前尚未正式进入玩家原型的系统包括：

- 低、中、高级场；
- 五档厚尾价值分布；
- 长期货币、资产和经验；
- 多类 NPC 人物矩阵；
- 市场日报事件；
- NPC 无法开价或只给区间。
