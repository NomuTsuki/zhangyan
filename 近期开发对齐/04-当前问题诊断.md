# 当前问题诊断

更新时间：2026-07-27

这份文档只描述已经发现的问题，不把建议方案写成已批准决定。

## 问题一：客观分把“当前路径没有后悔”误写成“客观满分”

### 当前公式

```text
实际净结果 = 真实价值 - 成交价 - 检测费

当前路径的参考最优 =
max(
  拒绝交易的净结果0,
  按开价购买的净结果,
  按当前动态买断线购买的净结果
)

机会损失 = max(0, 参考最优 - 实际净结果)

客观分 =
100 - 机会损失 ÷ max(开价, 真实价值) × 100
```

### 为什么65价值、65成交会得到100

假设：

- 真实价值65；
- 成交价65；
- 检测费0；
- 当时系统认为最低可达买断线也是65。

那么：

```text
实际净结果 = 65 - 65 = 0
参考最优 = max(拒绝0, 开价购买-15, 买断线购买0) = 0
机会损失 = 0
客观分 = 100
```

公式认为“你已经拿到了这条路径的最好结果”，于是给100。但从经营角度看，这只是没有赚钱也没有亏钱。

### 为什么60成交也可能100

如果当时动态买断线为60：

```text
实际净结果 = 65 - 60 = 5
参考最优 = 65 - 60 = 5
机会损失 = 0
客观分 = 100
```

它依然只在比较“是否达到当时系统算出的最低线”，没有评价利润率，也没有单独评价压价表现。

### 结论

这是设计定义错误，不是显示错误。

当前“客观分”更准确的名字是：

> 当前路径下的机会损失分。

它不能直接代表经营成绩。

### 推荐的重新拆分

先不要急着重新合成一个总分，分别显示：

1. **实际净收益**：`真实价值 - 成交价 - 检测费`；
2. **利润率**：`实际净收益 ÷ 真实价值`；
3. **议价表现**：玩家从可谈价格空间中争取到了多少；
4. **机会损失**：拒绝或成交相对另一项明确合法方案错过了多少；
5. **判断质量**：基于玩家当时可见信息，决策是否合理。

这样：

- 65价值、65总成本：净收益0，盈亏平衡，不可能被描述为经营满分；
- 65价值、60总成本：净收益5，优于65成交；
- 65价值、55总成本：净收益10，继续优于60成交。

等你理解并确认这些指标后，再决定是否需要一个合成总分。

## 问题二：“完整说明事实”和“只强调部分信息”难以理解

你在反馈中把第二项记作“只强调有利部分”，当前代码里的实际标签是“只强调不利部分”。这本身也说明按钮没有建立清楚、可记忆的含义。无论强调的是对玩家有利还是不利的信息，当前实现的核心问题相同。

### 当前代码实际上做了什么

两种选择都会：

- 公开同一条证据；
- 让 NPC 得到同一客观事实；
- 让 NPC 形成相同的物品后验。

区别只有：

- “只强调不利部分”可能额外降低信任；
- 可能额外降低成交意愿；
- 惩罚幅度受 NPC 专业度和真诚敏感度影响。

玩家界面没有清楚展示这种代价，也没有提供真正不同的陈述内容，所以这个选择看起来只是两个抽象按钮。

### 当前问题

- “完整”到底多说了什么，没有展示；
- “只强调不利”到底隐去了什么，没有展示；
- 同一条孤立证据有时根本不存在“完整与片面”的区别；
- 片面披露惩罚是 Codex 自行设计的公式，没有与你对齐；
- 玩家更自然的选择可能是“公开哪几条证据”，而不是先选一个抽象措辞。

### 推荐方向

暂时移除这个抽象二选一。

先让选择性披露自然来自：

- 玩家选择公开哪条证据；
- 玩家选择暂时保留哪条证据；
- 具体询问主题；
- 是否把互相矛盾的证据一起公开。

等案件真的出现“同一事实可以采用不同陈述方式”的场景，再提供具体台词，而不是“完整/片面”两个抽象标签。

## 问题三：调查和议价共用行动点

你此前确认的是：

> 检查与询问交叉进行，并共享调查预算。

Codex 随后把“正式报价”也放进同一个行动点池。这一步没有单独与你确认。

本轮你明确提出：

> 讨价还价应使用独立资源；可议价次数应由 NPC 设定、性格和此前演绎形成的数值共同决定。

推荐的新结构是：

```text
调查行动点
→ 检查、询问、证据对质、共同检测

议价容量
→ 正式报价、还价轮次
→ 由NPC人物基础值和调查后的关系状态计算
```

仍需确认的是：

- 议价容量是玩家可见的明确次数，还是只显示模糊状态；
- 哪些 NPC 状态增加或减少议价空间；
- 证据质量影响接受价格，还是也影响可议价次数；
- 玩家主动终止议价是否保留继续调查的机会。

## 问题四：风险转移被放得太重

你原本表达的是：

> 对某些急售、风险规避的 NPC，玩家可以用确定成交替 NPC 接走部分不确定性风险。

Codex 在实验台、交易按钮和试玩建议中把“无条件买断”放到了接近核心策略的位置。

本轮你已经明确：

- 它只是可能有效的措施；
- 不应该成为游戏核心；
- 核心仍然是鉴定、询问、证据链、人物判断和议价。

因此后续应把它降级为：

- 只在部分 NPC 或案件出现的交易条件；
- 不要求每局都展示；
- 不作为新手必须学习的第一层内容；
- 不用它来组织整个数值实验台。

## 问题五：数值实验台没有遵循渐进式披露

当前实验台一次呈现：

- 多档价值分布；
- 概率、分位数与后验；
- 三类 NPC；
- 四状态；
- 多种自动策略；
- 议价分支；
- 双后验与信息公开；
- 大量批量统计。

它适合开发者核对公式，不适合作为第一份学习材料。

后续建议分为：

1. 单个手算案例；
2. 一个参数变化会影响什么；
3. 两种策略的少量对比；
4. 最后才开放批量模拟和完整参数表。

在新的结算与行动资源对齐前，不继续扩充实验台。
